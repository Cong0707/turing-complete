# 候选电路生成器

## 2026-07-31 / 提交：功能：生成首批排行榜候选电路

## 提交目的

验证项目已经能够从“解析和分析”进入“可重复生成新电路”，同时坚持不启动游戏、
不写正式存档和不复制游戏提示方案。

## 生成框架

- 稳定永久 ID 由 `SHA-256(project namespace + level + logical name)` 派生。
- 布线路径由顶点序列生成，只接受水平、垂直和 45 度线段，相邻同方向自动合并。
- 候选继承该关 baseline 的容器头、custom ID 和 design，但元件及导线完全由配方重建。
- 固定端口从 `scaffold/immutable.json` 加载，保持游戏永久 ID。
- 写入 `candidate/circuit.data` 前必须满足：受支持元件、所有引脚连接、无组合环、
  v15 编码后反解析完全一致。

## 第一批关卡

- `or_gate_3`：两个 OR，声明 `2/2/4`。
- `and_gate_3`：两个 AND，声明 `2/2/4`。
- `xnor`：AND 与 NOR 并行后 OR，声明 `3/2/6`。

三项均达到总榜前 12 名公开 profile 联合样本中的最低能耗代表。每关的具体灵感、
布局和验证结果记录在自己的 `history/` 目录。

## 限制

容器内的 gate/delay 是声明值，不能替代游戏运行测试。候选只进入项目目录；正式存档
写回必须等用户明确验收阶段，并继续经过游戏未运行检查和原子替换。
