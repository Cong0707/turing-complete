# 当前存档编解码器

## 2026-07-31 / 提交：功能：实现 v15 编解码与安全写回

## 提交目的

实现可完整保存当前活跃方案的 v15 容器编解码，并把写回动作限制为明确选择的
`circuit.data` 目标。

## 修改点

- 使用纯标准库实现 raw Snappy 解压和确定性的 literal-only 压缩。
- 对 v15 头、Custom 固定 512 字节 design、元件附加字段、导线路径逐字段解析；
  读取有长度/计数边界检查，写出后立即反解析比较对象。
- 支持 JSON 导出和构建，便于让合成器、审查工具和人工修改共享同一个中间表示。
- 增加 v15 全字段 round-trip、非法导线和本机全部活跃方案只读解析测试。
