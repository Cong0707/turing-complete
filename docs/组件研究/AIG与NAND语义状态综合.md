# AIG 与 NAND 语义状态综合

## 2026-08-01 / 提交：研究：加入 AIG 与 NAND 精确综合器

## 目标

组件关不能只比较官方封装。`semantic_synthesis.py` 在完全离线的布尔层搜索一到四输入、
一个或多个输出的共享逻辑网络，同时保留门数与最大逻辑深度的 Pareto 前沿。该模块不依赖
存档格式、元件坐标或游戏进程，输出也不会自动写入正式存档。

## 真值表和网络表示

- 一个 N 输入函数使用 `2 ** N` 位整数表示，第 `assignment` 位就是该输入组合的输出。
- 输入 0 对应组合编号的最低位，`make_truth_tables` 可从 Python 函数确定性生成单输出或
  多输出目标。
- `LogicNetwork` 使用拓扑序门数组。源 0 是常量零，源 1 到 N 是主输入，其余源依次为
  门输出；输出仅保存对源的引用。
- AIG 门是二输入 AND，任意边允许免费反相。NAND 网络不允许免费反相，每个取反必须由
  `NAND(x, x)` 等真实门实现。

## 精确语义状态搜索

搜索状态不是坐标电路，而是“当前所有可用真值表到最小深度及代表节点”的映射。每一层给
所有状态增加一个门，并按以下规则合并：

1. AIG 把 `f` 与 `~f` 规范化为同一个相位类，因为二者只差一条免费反相边。
2. NAND 保留完整真值表，不把互补函数合并。
3. 同一门数层中，若两个网络拥有完全相同的“函数、最小深度”映射，则其后续可达函数和
   深度也相同，只保留一个确定性代表。
4. 多个目标同时存在于状态时生成候选，因此共享中间节点会自然计入，而不是把各输出的
   独立成本相加。
5. 候选移除所有输出锥之外的死门，再按 `(门数, 最大输出深度)` 删除支配点。

当 `state_limit=None`，或者实际搜索没有任何一层超过限制时，报告的 `exhaustive=True`，
表示在给定 `max_gates` 范围内完成穷举。设置有限状态上限后，算法会按目标覆盖数、真值表
汉明距离和深度确定性裁剪，报告同时记录 `truncated_layers`；这种结果只能作为候选，不能
直接宣称整个预算内最优。`exhaustive_through` 记录从零门开始连续完整搜索到的最后一层；
如果一个候选的门数不超过该层，则该候选仍保留自己的 `exhaustive=True`，后续层发生裁剪
不会抹掉已经完成的较小门数证明。

## 已验证的小型最优结构

离线测试覆盖以下可人工核验的结构：

| 目标 | 库 | 门数 | 深度 | 说明 |
| --- | --- | ---: | ---: | --- |
| NOT | AIG | 0 | 0 | 免费反相边 |
| NOT | NAND | 1 | 1 | `NAND(a, a)` |
| 半加器 XOR 与 AND | AIG | 3 | 2 | 两个输出共享 `a & b` |
| 半加器 XOR 与 AND | NAND | 5 | 3 | 两个输出共享首个 NAND |

这些是抽象门库结果，不等于游戏排行榜成绩。尤其 AIG 的免费反相边必须再技术映射到游戏
实际可用元件，映射后的 NOT 成本、扇出、线路以及自定义元件递归成本都必须重新计算。

## 四输入与多输出使用策略

完整状态数随门数指数增长。建议流程如下：

1. 一到三输入的小块先用 `state_limit=None` 求证精确最优。
2. 四输入先以有限状态上限寻找低门数、低深度候选，并记录发生裁剪的层。
3. 对接近排行榜上界的候选提高状态上限或拆成输出锥，再以不裁剪运行复核。
4. 对字级关卡先分解为四输入查找表、进位生成/传播或共享控制小块，再把这些小块映射成
   `foundry/codex` 自定义元件；不能把一个巨大的字级真值表直接交给本模块。

## 仍需扩展

- NPN 等价类只适合单输出预计算；多输出还需要输入置换、输入极性和输出置换的规范化。
- 当前状态合并优化门数和逻辑深度，没有纳入游戏不同门型的加权延迟。
- 后续可把结果转换为统一 XAG/AIG IR，接 ABC/Yosys 重写，并通过 SAT 对重要四输入块进行
  固定门数不可满足性证明。
- 正式候选仍需独立技术映射、几何布局、存档编码和游戏人工验收。
