# 电路几何分析器

## 2026-07-31 / 提交：功能：离线分析电路几何结构

## 提交目的

在接入元件引脚和逻辑等价验证之前，先建立不依赖游戏运行的可重复几何基线，防止
优化时只追求门数而产生难以维护的交叉、冗余和重复永久 ID。

## 修改点

- 新增 `tc-save analyze <circuit.data>`，报告声明门数/延迟、元件种类、immutable
  数量、重复永久 ID、元件包围盒。
- 导线报告展开后的总长度、最长导线、段数、弯折数、导线相交网络数、重叠点数、
  包围盒和 v7 断开导线数量。
- 新增 `tc-save analyze-examples`，为现有 92 个主线目录生成 `metrics.json`，架构
  关引用共享架构 baseline；没有 baseline 的关卡明确写 `null`，不伪造 0 分。
- 导线穿过元件占用格并不会被本模块误判成逻辑连接。引脚坐标、旋转规则和关键路径
  将在下一阶段作为独立、可审计的元件库接入。

## 安全边界

本次只读取项目 examples 并写入派生指标，没有启动游戏，没有修改正式存档，也没有
生成备份或写入 `levels.txt`。
