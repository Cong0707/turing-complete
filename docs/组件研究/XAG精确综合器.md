# XAG 精确综合器

## 2026-08-01 / 提交：研究：建立XAG精确综合器

### 研究范围

本模块只研究 1 至 4 输入、单输出的组合函数，逻辑基为 XOR、AND 和反相边。反相边在抽象模型中不计门数、延迟；常量 0 免费，常量 1 由常量 0 的反相边得到。它不读写存档，也不把抽象 XAG 直接伪装成可放入游戏的电路。

### 真值表与规范化

- 真值表使用 Python 整数保存，赋值编号对应结果位编号。
- 输入 0 是赋值编号的最低位。例如双输入时，输入 0 为 `0b1010`，输入 1 为 `0b1100`。
- `f` 与 `~f` 归入同一个互补函数类，代表取 `min(f, ~f)`，另存一位输出相位。
- XOR 输入相位全部推到输出：`(~a) XOR b = ~(a XOR b)`。这可以消除没有结构意义的重复。
- AND 保留两条输入边的相位；这正是 AND、NAND、OR、NOR 等形式的统一表示。
- 二元运算交换律通过对子字面量排序实现。
- 门节点以完整结构作为哈希键。两个子图结构相同就只计一次，因此枚举对象是 DAG，而不是把公共子表达式重复计算的树。

### 精确枚举算法

`enumerate_xags(n, k)` 按唯一门节点数从 0 到 `k` 枚举根式 XAG：

1. 第 0 层加入常量 0 和所有输入变量。
2. 第 `d` 层从所有小于 `d` 门的已知根式 DAG 中选两个根，添加 XOR 或带四种输入相位的 AND。
3. 合并左右子图的结构哈希集合，再加入新根；仅当唯一节点数恰为 `d` 时接纳。
4. 按互补函数类和规范化根结构去重。
5. 若新门的函数等于常量或任一子根（允许取反），该门可在所有使用位置被免费反相边替换，故只删除这种严格冗余结构。
6. 根节点的任意非冗余有限 XAG 都能分解为两个更小的根式 XAG；反过来组合又不会漏掉共享的相同子图。因此，只要枚举正常结束，数据库对门数上界内所有可能进入最小门数或成本/延迟 Pareto 前沿的规范化根式 XAG 是完整的。

枚举可能指数爆炸。`max_candidates` 是故障关闭式保护：触及上限会抛出 `XagSynthesisLimitError`，不会返回不完整数据库，也不会把截断结果称为精确结果。当前穷举器适合验证小元件、产生 SAT/SMT 综合器的最优性对照和回归样本；任意四输入函数的较深搜索应改用 SAT 编码，而不是无限抬高此上限。

### Pareto 定义

完整数据库可以按成本模型计算 `(gate_cost, delay)` 前沿。默认 AND/XOR 都按成本 1、延迟 1；`XagCostModel.turing_complete_primitives()` 使用当前项目已观察的 AND `1/1`、XOR `3/2`。

该 TC 成本模型只用于排序抽象 XAG。反相边并非已经证明可以在 TC 中免费实现：后续 lowering 必须根据 AND/NAND/OR/NOR 可覆盖的相位组合，必要时显式加入 NOT，并重新计算真实门数和关键路径。未经 lowering 验证的 XAG 分数不得写入关卡历史作为实测成绩。

### 可直接集成的数据边界

- `XagLiteral`：常量、输入或门输出的引用，以及反相相位。
- `XagNode`：`and` 或 `xor`，输入必须引用拓扑序中更早的源。
- `XagNetwork`：可独立求真值表和成本，不依赖存档模型。
- `XagDatabase.minimum()`：门数上界内的严格最小门数网络。
- `XagDatabase.pareto()`：给定非负成本模型的严格有界 Pareto 前沿。
- `truth_table_from_callable()`：把关卡规范转成统一整数表示。

建议后续建立独立 lowering 层：`XagNetwork -> 逻辑网络 IR -> TC Component/Wire`。不要让综合器直接依赖 `foundry.py` 或坐标几何；布局、引脚、布线、反相边实体化和存档写回应保持为后续阶段。

### 关键测试

- 输入位序、函数互补规范化。
- NOT 在反相边模型中为 0 门，AND、OR、XOR 为 1 门。
- 双输入 16 个函数恰好归并为 8 个互补类，并在两门上界内全部覆盖。
- 公共成本模型下返回的 Pareto 点互不支配，且每个候选重新求值后等于目标真值表。
- 四输入一门函数可枚举，证明位宽实现没有写死在两三输入。
- 候选保护阈值触发异常，禁止静默返回伪精确结果。
