# 精确逻辑综合器

## 2026-08-01 / 提交：功能：建立小规模精确逻辑综合器

## 目标

为一至四输入的组合逻辑建立与游戏存档无关的布尔网络搜索层。它用于回答“在明确的门库和
有限边界内，是否还存在门数更少或深度更低的结构”，不会直接修改正式存档，也不会启动
游戏。

## 真值表约定

- 真值表使用 Python 整数紧凑保存，第 `assignment` 位是该输入向量的输出。
- 输入 `x0` 对应向量整数的最低位，`x1` 对应下一位。
- `truth_table_from_callable(n, function)` 可从 `function(x0, x1, ...)` 生成目标真值表。
- 当前严格限制为一至四输入，因此完整函数最多占 16 位。

## 门库与计费边界

三种门库不能混用成绩：

- `nand`：每个二输入 NAND 计一个门、一级深度；没有免费反相边。
- `aig`：每个二输入 AND 计一个门、一级深度；输入、节点输出和最终输出的反相边免费。
- `xag`：每个二输入 AND 或 XOR 均计一个门、一级深度；反相边免费。
- 统一精确入口不隐式提供常量；常量必须由输入和门构造，避免把免费常量错误带入游戏成本。

AIG/XAG 是综合研究用的抽象成本模型，并不等于 Turing Complete 的真实门数。特别是免费
反相边必须在后续映射为游戏元件时重新计费；除非自定义元件和游戏计分实测证明可以免费，
否则不能把抽象前沿直接写成排行榜成绩。

## 精确搜索方法

搜索按门数逐层枚举拓扑有序的直线网络。每加入一个门，就根据全部输入向量计算该节点的
完整真值表。以下合并不损失有限边界内的最优解：

- 同一网络不重复生成已经可用的语义信号；最小门数网络中的重复信号可由原信号替代。
- 两个状态拥有相同的语义信号集合时，只保留节点深度逐项不劣的状态。
- AIG/XAG 将函数与其补函数归为同一语义类，因为免费反相边可在任何使用点选择相位。
- 最终只保留门数和输出最大深度互不支配的网络。

`max_gates` 和可选的 `max_depth` 定义严格的有限搜索域。`max_states` 只是资源保险；一旦
触发会抛出 `SearchLimitExceeded`，绝不会把截断结果冒充精确前沿。

## 使用示例

```python
from tc_save_lab.exact_synthesis import synthesize_exact, truth_table_from_callable

xor = truth_table_from_callable(2, lambda x, y: x ^ y)
carry = truth_table_from_callable(2, lambda x, y: x & y)

result = synthesize_exact(
    2,
    (xor, carry),
    basis="xag",
    max_gates=2,
)

for network in result.frontier:
    print(network.gate_count, network.depth, network.to_dict())
```

该例会联合综合半加器的 Sum 和 Carry，而不是分别搜索后再简单拼接，因此允许多输出共享
中间节点。

## 已验证基准

- NAND 一位非门：`1 门 / 深度 1`。
- NAND 二输入 XOR：`4 门 / 深度 3`。
- AIG 输入取反：`0 门 / 深度 0`，明确体现免费反相边模型。
- XAG 半加器双输出：`2 门 / 深度 1`。

这些结论由完整真值表测试和边界内状态穷举共同验证。更大的四输入目标会出现明显状态
爆炸，应先分解函数、收紧深度边界，或在后续接入 SAT 求解器；在没有完成全域搜索时必须
继续标记为候选上界，不能称为精确最优。

## SAT 扩展路线

四输入深层网络应切换为固定门数 SAT，而不是无限扩大语义状态表。推荐编码为：每个门对
所有更早信号的交换律输入对设置 exactly-one 选择变量，并为最多 16 个输入赋值分别设置门
值；多输出在同一个实例中选择驱动信号，才能搜索公共子表达式。优化顺序为：

1. 先从下界递增门数，首个 SAT 模型给出最小门数候选，之前的 UNSAT 构成证明。
2. 固定门数后递增最大深度，或枚举分层 DAG fence，得到该门数下的最小深度。
3. 扫描多个 `(门数, 深度)` 边界并删除支配点，形成完整 Pareto 前沿。
4. 对 SAT 模型再次执行完整真值表验证并裁掉死门；timeout 只能标记未知，不能当作 UNSAT。

安全的对称破除包括交换律输入排序、禁止相同门重复应用、要求所有门最终被输出锥使用，
以及对同层门描述符排序。NAND 必须保留 `NAND(x, x)`，因为它是真实的一门取反，不属于
可删除的平凡操作。

后续依赖可选 `python-sat`，但当前精确枚举器只使用 Python 标准库，因此本次不增加运行时
依赖。SAT 后端真正接入并有测试前，不应提前写入 `requirements.txt`。

## 论文路线与适用边界

- IncSyn 通过复用既有综合任务知识构造增量 SAT，论文报告最高约 `15x` 加速；它适合大量
  相近 cut 的连续求解，但“部分 12 输入基准可解”不代表任意 12 输入函数都可精确综合。
- BESWAC 优化初值、编码器与 SAT 调用顺序，报告约 `1.79x` 加速；启用 early-exit 后只能
  产出候选，不能给最优性证明。
- 2026 年 TGSyn 用 Transformer 预测 topology 成功概率。只要仍穷尽全部 topology，它改变
  的只是检查顺序，不破坏精确性；只查预测 top-k 就会退化为启发式。
- 2025 年 TeaRW 强调按目标技术映射后的成本评价重写候选。这与本项目最相关：外部 AIG、
  XAG 或 NAND 结构都必须统一按游戏递归门数和真实关键路径重新排序。

NPN 规范化可把四输入全部函数压缩为 222 个等价类，适合预计算 cut 库；五输入已有
616126 类，只应按需缓存。输入/输出反相在游戏中未证明免费，因此 NPN 模板还原后必须重新
计入相位实体化成本。多输出函数也不能逐输出独立 NPN 化，否则会破坏共享输入变换和公共
子表达式。

求解状态必须严格区分 `SAT`、`UNSAT` 和 `UNKNOWN`。超时、冲突上限、后端异常、只检查
预测 topology、普通 ABC/Yosys/Espresso 优化，以及“XAG 最少 AND”都不能记录为已证明的
游戏总门数最优。重要 UNSAT 结论后续应保存求解器版本，并在后端支持时保存 DRAT/LRAT
证明以便重放。

## 交叉验证

除定向单元测试外，开发阶段还使用不做语义状态合并、允许重复信号的朴素直线网络枚举器，
逐一比较全部 16 个二输入函数。NAND 至 4 门、AIG 至 3 门、XAG 至 2 门的所有可达函数及
`(门数, 深度)` Pareto 点均完全一致，验证了当前状态等价合并没有在这些边界内漏解。
