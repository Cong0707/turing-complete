# 逻辑网络重写器

## 2026-08-01 / 提交：研究：建立AIG、XAG与NAND网络重写器

## 目标

本组件为排行榜候选提供一个不依赖坐标、引脚和存档格式的布尔网络层。它解决以下问题：

- 多个输出共用同一个中间表达式时只计一次成本；
- 使用结构哈希消除重复门；
- 在 XAG、AIG 和显式 NAND 网络之间进行可穷举验证的变换；
- 同时保留低门数、低延迟和低能耗候选，而不是只优化一个标量；
- 明确区分 AIG 的抽象反相边和游戏中的真实非门成本。

本次没有启动游戏，没有读取或写入正式存档，也没有生成 Foundry 电路。实现位于 `src/tc_save_lab/logic_network.py`，验证位于 `tests/test_logic_network.py`。

## 现有工具结论

仓库中的 `.research/yosys-techlib` 可参考 Yosys/ABC 的接入方法，但不能作为当前游戏成本真相：

- `turing_complete_area_focus_tech.lib` 将多数门统一写成 area 12；
- `turing_complete_nand_focus_tech.lib` 将 OR、OR3 写成 area 0；
- 两份 Liberty 都没有当前版本可验证的完整延迟弧；
- 它们不能表达“同一实例多个输出只付一次成本”。

当前候选和排行榜样本支持以下一位局部成本：

```text
NOT / AND / NAND / OR / NOR = 1 gate / 1 delay
XOR 的三基本门实现           = 3 gate / 2 delay
XOR 与 XNOR 同时需要         = 4 gate / 2 delay
```

因此不能用“每个 XAG 节点成本相同”的论文目标直接排序游戏候选。XOR 节点在当前 TC 映射中明显比 AND 节点昂贵。

## 中间表示

`LogicNetwork` 使用 append-only、拓扑有序的节点数组：

```text
node 0 = constant false
INPUT  = 命名输入
AND    = 两输入与节点
XOR    = 两输入异或节点
Signal = node id + inverted phase
output = name + Signal
```

关键约束：

- AND、XOR 的输入按稳定顺序规范化，保证结构哈希确定性；
- XOR 输入反相被推到输出相位，避免同一线性函数产生多个结构；
- 多个命名输出保存在同一个图中；
- 只计算从任意输出可达的节点；
- 输入和输出名称必须唯一；
- 所有引用只能指向更早节点，组合环不能进入 IR。

真值表按二进制计数顺序打包，第 `row` 位对应一组输入；本模块的 `truth_tables()` 主要用于小网络穷举验收。大网络应使用现有组合模拟器或位并行差分验证。

## 已实现重写

构造阶段会立即应用以下恒等式：

```text
x & 0 = 0                 x XOR 0 = x
x & 1 = x                 x XOR x = 0
x & x = x                 x XOR ~x = 1
x & ~x = 0                ~x XOR y = ~(x XOR y)

x & (x & y) = x & y
x & ~(x & y) = x & ~y
x & (x XOR y) = x & ~y
x XOR (x & y) = x & ~y
(x & y) XOR (x & z) = x & (y XOR z)
```

最后三类规则针对当前 TC 加权成本尤其重要。例如：

```text
(x & y) XOR (x & z)
原结构：2 AND + 1 XOR = 5 gate
提因子：1 AND + 1 XOR = 4 gate
```

`rewrite_network()` 还会扁平化同类 AND/XOR 锥、消除重复项，并按平衡树重建。四输入串行 AND 的抽象深度可由 3 降到 2。调用者也可以关闭平衡，以保留可能对其他输出有利的链式共享候选。

这些规则是确定性局部规则，不宣称构成完备最小化算法。DAG-aware 重写必须结合 MFFC 或“受影响全部输出锥”的可达实例并集，不能只比较单个根节点的树面积。

## AIG与NAND

`rewrite_network(..., basis="aig")` 使用三 AND 节点和反相边展开 XOR，生成不含 XOR 节点的 AIG。每次展开后都可通过全真值表比较验证语义。

`lower_to_nand()` 进一步生成只包含显式二输入 NAND 的 `NandNetwork`：

- `NOT(x) = NAND(x, x)`；
- AND 的负相位直接由一个 NAND 产生；
- AND 的正相位复用该 NAND，再自 NAND 一次；
- XOR 使用标准四 NAND 结构；
- 相同 NAND 输入对进行结构哈希；
- 同一节点的正负相位跨全部输出共享。

常量不是假定免费。若输出确实需要常量，纯 NAND 降级会用第一个输入合成 0/1；无输入常量网络会失败关闭。

## 相位合法化

AIG 的补边在抽象模型中免费，但游戏中只有部分相位组合可被一个原生门吸收：

```text
AND(a,b)                 -> AND
~AND(a,b)                -> NAND
AND(~a,~b)               -> NOR
~AND(~a,~b)              -> OR
```

单输入反相的 ANDNOT/ORNOT 没有对应的一门官方元件。因此 AIG 门数只能作为下界或重写搜索指标，不能直接写成排行榜 gate/delay。

`estimate_turing_cost()` 做了第一层相位感知映射：

- AND 正相位用 AND，负相位用 NAND；
- 同时需要 `a&b` 和 `~(a&b)` 时计 `2 gate / 1 delay`，不会误报为免费补边的 `1/1`；
- XOR 或 XNOR 单相位计 `3/2`；
- 两种 XOR 相位同时需要时共享前两项，计 `4/2`；
- 输入负相位计一个 NOT；
- 多输出共享节点只付一次。

该映射仍是局部上界。它尚未识别跨节点的复合超门，例如已有 `AND(a,b)` 时复用 XOR 内部同一项，或将 `ab XOR ac XOR bc` 映射为 majority。最终候选必须降到具体 TC 元件网、删除不可达实例、重新计算成本并经游戏实测。

## 多输出共享

`merge_networks()` 会按输入名称合并多个独立网络，再对全部输出统一结构哈希。映射键作为输出命名空间，防止同名根冲突。

两个已知的共享目标说明逐输出综合为什么会失败。

半加器：

```text
n0    = NOR(a, b)
carry = AND(a, b)
sum   = NOR(n0, carry)
```

总成本为 `3 gate / 2 delay / 6 energy`。`carry` 同时作为输出和 `sum` 的中间项。

全加器低门候选：

```text
ab0   = NOR(a, b)
ab1   = AND(a, b)
p     = NOR(ab0, ab1)
pc0   = NOR(p, c)
pc1   = AND(p, c)
sum   = NOR(pc0, pc1)
carry = OR(ab1, pc1)
```

总成本为 `7 gate / 4 delay / 28 energy`，与公开样本的低门 Pareto 点一致。原生 FullAdder 的 `14/3/42` 是另一非支配点，两者都必须保留。

后续统一 IR 还需要支持多输出原生实例（hypernode）。例如 FullAdder 和 Decoder 的多个输出来自一次付费的同一元件，不能拆成多个单输出节点重复计价。

## Pareto目标

`CostPoint` 保存：

```text
gates
delay
energy = gates * delay
label
```

`pareto_front()` 删除满足以下条件的候选：

```text
存在另一候选 gates <= 当前 gates
且 delay <= 当前 delay
且至少一项严格更小
```

返回顺序按 `energy, delay, gates, label` 稳定排序。标签不参与支配，只用于保留可复现的候选身份。

对关卡最终根，`(gate, max_output_delay)` 足以形成排行榜层面的二维前沿。对准备封装到 `foundry/codex` 的多输出自定义元件，仅保存最大延迟不够；未来应保存每个输出对每个输入的 max-plus 延迟弧矩阵。两个候选即使 `gate/max_delay` 相同，输出角色不同也可能在父电路中形成不同关键路径。

## NPN与cut重写计划

下一阶段建议对 4 输入 feasible cuts 建立 NPN 规范库：

- 真值表键必须包含输入数和固定版本，例如 `npn-lsb-v1:4:xxxx`；
- 规范化同时枚举输入置换、输入反相和输出反相；
- 必须保留全部等价 witness，而不是只留一个置换；
- 输入到达时间不对称时，从多个 witness 中选择关键路径最短的映射；
- NPN 规范化发生在抽象补边网络层，不能提前宣称 NOT 免费；
- 多输出函数不能逐输出独立改变输入置换，必须使用共同输入变换。

四输入布尔函数共有 222 个 NPN 类，适合建立小型、多结构的 Pareto 重写库。每个模板至少应保留 area-first、depth-first 和零面积增量三类结构。

## 综合接入建议

短期流水线：

```text
Verilog / 手写布尔式
        -> 联合多输出 XAG/AIG
        -> 结构哈希与局部重写
        -> k-cut / NPN 候选替换
        -> 相位感知 TC 技术映射
        -> 具体元件网络与 DCE
        -> gate/delay Pareto
        -> 现有组合模拟器穷举
        -> 电路布局与游戏实测
```

小于等于 4 至 6 个输入的窗口应使用具体门库 SAT/SMT 精确综合，门槽直接允许 NOT、AND、NAND、NOR、OR、XOR、XNOR、AND3、OR3 和多输出原生元件。这样可以从约束层面正确处理共享和真实极性，不必事后修补免费反相边。

中大型电路使用 portfolio：同一个 Verilog module 同时声明全部输出，分别运行 AIG、XAG、NAND 以及不同 `balance/rewrite/refactor/resub` 顺序；导回统一 IR 后使用相同 TC mapper 复评。禁止逐输出调用综合器后简单拼接。

## 验证结果

本次新增测试覆盖：

- 常量、幂等、互补和交换规范化；
- AND/XOR 吸收与公共因子提取；
- 多输出真值表与共享节点计数；
- 四输入 AND 平衡后深度从 3 降到 2；
- XAG 到 AIG 的全真值表等价；
- 50 组固定种子随机网络在 XAG、AIG、纯 NAND 三种表示下的差分等价；
- 独立网络合并后的跨输出共享；
- 抽象免费反相和显式 NOT 成本的差异；
- NAND 原生相位吸收、XOR/XNOR 双相位成本；
- 纯 NAND 降级、多输出共享和常量失败关闭；
- Pareto 支配、去重和确定性排序。

本组件独立测试共 16 项通过；并发模块落盘后又执行项目全套测试，共 90 项全部通过。

## 已知边界

- 当前 IR 只处理二值组合逻辑，不处理 0/1/Z、三态总线、时钟和状态元件；
- 当前 TC mapper 是局部相位映射，不是完整 cut technology mapping；
- 结构平衡可能破坏对其他输出有价值的链式共享，因此平衡与保留结构都应进入候选集；
- 尚未实现 MFFC、NPN 规范库、SAT cut resynthesis 或输出延迟弧矩阵；
- 模块不负责坐标、布线、Foundry 封装、存档写回或排行榜提交；
- 未经具体元件网验证和游戏实测的数值不得标为世界纪录。
