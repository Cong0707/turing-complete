# 安全写回器

## 2026-07-31 / 提交：功能：实现 v15 编解码与安全写回

### 写回流程

- `apply` 只接受经过严格解析和重编码一致性校验的 v15 候选。
- 写回前检查 `Turing Complete.exe`，游戏运行时拒绝操作。
- 使用目标目录内临时文件、`fsync`、`os.replace` 和写后反解析，避免半写文件。
- 按项目约定不保留持久备份，也不遗留临时文件。

### 不做的事

- 不写入 `levels.txt` 的 Pareto 记录，也不伪造排行榜成绩；真实成绩必须由游戏测试产生。
- 不解析或覆盖关卡根目录的 `.tc` 导入包。
- 未经用户验收，不把项目中的候选写入正式存档。
