# 组合逻辑模拟器

## 2026-07-31 / 提交：功能：使用穷举模拟验证候选电路

## 问题

只检查“所有引脚已连接”和“没有组合环”不能证明电路功能正确。线路接反、输入顺序错误、
逻辑门选错仍可能通过结构检查，因此候选生成必须增加行为门槛。

## 修改

- 新增严格的离线组合逻辑模拟器，网络连接规则与当前分析器一致：公共导线端点才连接，
  路径内部交叉不自动形成节点。
- 首批只实现已经核对过引脚和语义的基础位门、字门、全加器、拆分/合并、比较、取负、
  加法与多路选择器。
- 未知元件、未连接引脚、冲突驱动和无法求值的环路全部直接报错，不生成猜测结果。
- `or_gate_3`、`and_gate_3`、`xnor`、`bit_inverter` 和 `decoder_1` 在写入候选前分别穷举
  8、8、4、4、2 个输入向量。

## 结果

首批候选均通过完整真值表。此验证仍不是游戏成绩证明：游戏对真实门数、延迟、可用元件
及提交资格的最终判定，必须留到用户验收时在游戏中完成。

## 2026-07-31 / 提交：功能：扩展多输入验证并生成第二批候选

## 多输入穷举

- 新接口接收 `输入标签 -> 位宽` 映射，可验证多个独立关卡输入。
- 电路端点网络只编译一次，再复用到全部输入向量；避免在 `byte_mux` 的 131072 组输入中
  重复分析布线。
- 新增一位、二位、三位解码器语义，并核对 Disable 为 1 时三位解码器八路全零。

## 本轮覆盖

- `byte_mux`：131072 个输入向量。
- `byte_xor`：65536 个输入向量。
- `decoder_2`、`decoder_3`：分别 4 和 16 个输入向量。
- `signed_negator`：256 个输入向量。

所有候选仍先经过连通性、组合环和 v15 往返校验，再允许写入项目的 `candidate/`。

## 2026-08-01 / 提交：功能：生成第三批候选并校正一位非门

## 严格输入与多输出

- 穷举输入标签和位宽现在必须与电路固定输入完全一致，防止只测低位子集却误称完整穷举。
- `output_label` 可接收多个输出标签；全加器会在同一向量中同时验证 Sum 与 Carry。
- 新增字常量、LSL 和 LSR 的已审查组合语义。

本轮新增验证量：有符号比较 65536 组、逻辑右移 2048 组、全加器 8 组、独热编码 8 组。
