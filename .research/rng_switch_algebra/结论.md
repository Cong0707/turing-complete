# RNG 开关代数与相位反转研究

## 2026-08-03：提交“研究：撤回错误的非零初态候选”

### 撤回结论

**以下 `396 / 9 / 66` 相位反转方案已经撤回，禁止部署或提交。**

离线模拟器的 `initial_clocked_memory()` 接受了 Delay Bit 的 `init_data=1`，但当前游戏引擎实机不会把这个非零初态作为首周期高电平。既有实机记录已经测试过完全相同的控制拓扑：首拍 `phase=0`，因此输入端口关闭、输出端口开启，电路没有读取 seed 就提交 `0`，立即验证失败。

决定性实机证据：

```text
examples/rng/research/archive/rng_single_output_protocol/2026-08-02-单输出协议与零初态初始化.md
```

该记录同时给出当前安装版哈希、关卡脚本证据以及正确的零初态 66 周期协议。运行时证据优先于离线模拟结果，所以本目录中的：

```text
phase_reversed_396_9_66.data
derive_phase_reversed_candidate.py
```

仅作为“离线模拟器错误信任非零寄存器初态”的回归反例保留。`phase_reversed_396_9_66.json` 已标记为 `RETRACTED` 和 `deployment_allowed=false`。

后续候选必须满足：

- 所有 Delay Bit 的 `init_data=0`；
- 66 周期方案首拍输入开启、输出关闭；
- 或按持续读取同一 seed 的协议重新综合合法 65 周期网络；
- 离线测试显式模拟当前引擎的零初态，而不是从存档恢复非零寄存器值。

## 2026-08-03：已撤回的“无 RAM RNG 九延迟候选”

### 结论

现有已经实机通过的 `396 / 10 / 66` 编码状态网络不需要改动随机数核。第十层延迟只来自加载相位控制的极性：

```text
phase Delay(4)
  -> NOT(1)
  -> Architecture Input
  -> mode OR(1)
  -> 两层 XOR(4)
= 10
```

把相位 Delay 的初值设为 `1`、下一状态固定为 `0`，然后交换输入、输出端口的控制极性：

```text
phase.out      -> Architecture Input.control
NOT(phase.out) -> Architecture Output.control
```

在错误的离线初态模型下，会得到表面上的 `396 / 9 / 66` 结果，预测能耗为：

```text
396 * 9 * 66 = 235224
```

这个数值不能由当前游戏运行时实现，不能与参考成绩比较。

### 时序证明

加载周期 `tick 0`：

- `phase=1`，唯一输入端口开启，唯一输出端口关闭；
- 编码状态寄存器捕获 `T(seed)`；
- 相位寄存器捕获常量 `0`。

运行周期 `tick 1+`：

- `phase=0`，输入端口进入高阻态，输出端口开启；
- 编码状态按 `B` 矩阵持续更新；
- 输出解码为 `C(state)=A^n(seed)`。

最长有效路径为：

```text
state -> state:       Delay 4 + mode OR 1 + 两层 XOR 4 = 9
phase -> seed state:  Delay 4 + mode OR 1 + 两层 XOR 4 = 9
state -> output:      Delay 4 + mode OR 1 + 两层 XOR 4 = 9
phase -> output enable: Delay 4 + NOT 1 = 5
```

原方案的 `NOT -> Architecture Input` 不再位于加载数据路径中，因此结构延迟从 `10` 降到 `9`，门数和周期数不变。

### 被排除的局部 Switch 路线

`search_critical_band.py` 对规范网络中造成第三层 XOR 的 `y12..y26` 做了精确 RC2 优化，并同时计入：

- XOR2：`3 gate / 2 delay`；
- 四 Switch XOR3 数据面：`8 gate`；
- 可全局共享的 AND/NOR 控制；
- 固定 XOR2 与新 XOR2 免费暴露的内部 AND/NOR。

精确最优结果记录在 `critical_band_optimum.json`：

```text
固定 34 XOR2                 = 102 gate
临界带最优新增成本           = 198 gate
组合核                       = 300 gate
加现有 198 gate 外壳         = 498 / 9 / 66
```

因此，只重综合临界输出带的 cancellation-free XOR2/Switch-XOR3 路线明显弱于相位反转候选，不应继续在这个局部模型上消耗搜索时间。

此前出现的 `shared_control_233` 也不是已知可行前沿：它属于 cancellation-free 两层 XOR2/四 Switch XOR3 模型，而既有精确 RC2 结果已经证明，即使所有 AND/NOR 控制免费，组合核仍至少为 `262 / 4`。求解器的 `UNKNOWN(timeout)` 不能视作存在 `233` 门构造的证据。

### 后续方向

不得继续部署 `396 / 9 / 66` 相位反转结构。下一步应在全零寄存器初态约束下研究跨全部 32 个输出与 32 个状态的联合基变换、合法 65 周期模型、允许消去的非局部 Switch 网络，或者让同一组高阻控制同时承担加载选择和 XOR 数据面；局部修补规范 xorshift 的 15 位临界带已被精确结果否定。
