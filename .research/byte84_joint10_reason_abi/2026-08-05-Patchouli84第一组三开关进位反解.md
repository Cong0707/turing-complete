# Patchouli 84/6 第一组三 Switch 进位 owner 反解

日期：2026-08-05

## 结论

`02-upper-mid.png` 顶部第一组纵向三只 Switch 不是 `joint10` 的慢 `C2@3`，而是与
当前 `85/6` 权威 DAG 完全相同的严格 `C2@2` owner：

```text
T0 = BUS(SW(a0,cin), SW(b0,cin))                   4 gate @1
G0 = a0 AND b0                                     1 gate @1
C1 = T0 OR G0                                      1 gate @2

V1 = a1 OR b1                                      1 gate @1
G1 = a1 AND b1                                     1 gate @1

C2 = BUS(
  SW(T0,V1),
  SW(G0,V1),
  SW(G1,V1)
)                                                   6 gate @2
```

完整 `32` 行三态重放结果：

```text
C1 mismatch                 0
C2 mismatch                 0
S1 mismatch                 0
C2 BUS conflict             0
C2 active one              16
C2 active zero              4
C2 Z                       12
```

因此公开 `84/6/504` 图中的低两位仍是严格的 `23 gate` 前端。排行榜方案少掉的一门
不在 `bits0:1`，也没有使用此前研究的 `20 gate joint10 + slow C2@3`。后续截图反解
应优先寻找当前 `85` 与该图在中高位 owner 中的单门差异。

## Cofactor 唯一性

把 bit1 分成 `K/P/G` 三态，三 Switch owner 的行为是：

| bit1 状态 | `V1` | `G1` | `C1=0` | `C1=1` | `C2` |
|---|---:|---:|---|---|---|
| K (`00`) | 0 | 0 | Z | active 0 | 0 |
| P (`01/10`) | 1 | 0 | Z | active 1 | `C1` |
| G (`11`) | 1 | 1 | active 1 | active 1 | 1 |

所以：

```text
C2 = V1 * (T0 OR G0 OR G1)
   = V1 * (C1 OR G1)
   = G1 OR V1*C1
```

最后一步利用 `G1 -> V1`，恰好是全加器的严格 carry。该三类 cofactor 也是截图中
三只 common-data driver 的唯一自然解释。

## 前级与后级门

### 前级

第一组三 Switch 前面可见的结构与权威 DAG 对齐：

```text
bit0 两只 Switch      -> T0
bit0 AND              -> G0
T0 OR G0              -> C1
bit1 OR               -> V1
bit1 AND              -> G1
```

`T0` 和 `G0` 可以在 `a0=b0=cin=1` 时同时开启，但两者在 C2 owner 中都驱动相同
`V1`；`G1` 与任一路重叠时也仍驱动 `V1`，所以完整域没有 active-one/active-zero
对打。

### 后级

`C2` 从该 owner 直接扇出到三个后级区域的四个真实引脚：

```text
E1 = NAND(D1,C2)                    # S1 phase closure
R2 = NOR(C2,P2)                     # S2 零相位
T2 = AND(C2,P2)                     # S2 一相位
SW(enable=C2,data=N23)              # 下一组 B23 双 Switch owner
```

与权威 DAG 对齐的四门 `S1` 闭合为：

```text
D1 = NAND(G1,C1)                    @3
E1 = NAND(D1,C2)                    @4
O1 = OR(C1,V1)                      @3
S1 = AND(O1,E1)                     @5
```

该公式和图中 C2 owner 后方的四门相位块在成本、到达和扇出上均一致。小图中文字存在
抗锯齿模糊，但不影响三 Switch owner 的识别；脚本额外对该四门尾做了 32 行验证。

## 为什么不是 joint10

`joint10` 低两位的 carry owner 是：

```text
C2 = BUS(SW(C1,V1),SW(G1,V1))                 4 gate @3
```

它只有两只 Switch，而且第一只 enable 是已经到 `@2` 的完整 `C1`。截图却清楚显示三只
Switch，前两只分别直接接 bit0 的早期原因，正是为了跳过显式 `C1` 的一层：

```text
T0/G0/G1 @1 -> three-Switch owner -> C2@2
```

这也解释了图中后级为何仍能保持 `B23@3` 和全局 `D6`。把它误认成 joint10 会得到
不存在的低位三门节省，同时把 carry ABI 晚一层。

## 门数账本

截图中完整 bits0:1 为：

```text
T0 two-Switch owner                         4
G0/Q0/P0                                    3
G1/V1                                       2
C1 OR                                       1
C2 three-Switch owner                       6
S0 XOR physical closure                     3
S1 four-gate phase closure                  4
------------------------------------------------
total                                      23 gate

arrival: C1@2, C2@2, S0@4, S1@5
```

这与当前 `85/6` 权威低两位完全打平。`84/6` 的净减一必须位于 `bits2:7` 或跨位 owner
共享中。
