# 六十三异或与重复稳态行精确审计

## 结论

在固定 two-shear 状态编码、深度二 XOR2 数据 DAG、真实 pre/post OR 注入模型内，
以下两个恰好可达到 `400/9/67` 的剩余空间均已严格排除：

```text
x63: 172 shell + 63*3 XOR + OR<=39 = 400
x62: 172 shell + 62*3 XOR + OR<=42 = 400
```

全部求解结果均为确定的 UNSAT，没有 timeout 或 UNKNOWN：

```text
x63 / extra15 + two unit-final:  10 UNSAT
x63 / extra16 + one unit-final: 215 UNSAT
x63 / extra17 + direct units:    84 UNSAT
x62 / duplicate one pair node:   27 UNSAT
x63 / duplicate two pair nodes: 351 UNSAT
```

因此，本报告范围内没有可物化的 `<=400/9/67` 新候选，也没有改动候选电路或正式存档。

## 精确语义

SAT 模型同时允许两种真实九延迟种子注入路径：

```text
pre-xor: q -> OR(seed_i,q) -> XOR -> final XOR
raw-post: q_a,q_b -> raw XOR -> OR(seed_i,raw_pair) -> final XOR
```

每个 pre-XOR 输入引脚至多选择一个 seed bit；每个 raw-post 消费点至多选择一个
seed bit。同一个 `(seed,state)` 叶 OR 或 `(seed,pair)` 后置 OR 被多个消费者使用时，
按一个物理元件计费。32 条 B 行在 tick0 必须严格等于 T 行；C 只影响稳态 pair cover，
不虚构 tick0 标签。

`x63` 穷尽三个互斥计数家族：

1. 唯一 15-extra 最小 cover 加两个 unit-final，共 10 个拓扑。
2. 唯一 15-extra cover 加任意一个新 pair 和一个 unit-final，按 B 侧物理拓扑去重为
   215 个。
3. 17-extra cover 共 4,198 个 pair set、6,262 个完整 B/C 分解，去除 C-only 差异后
   为 84 个 B 拓扑。

`x62 duplicate` 则补上旧 row-deduplicated 证明明确遗漏的空间：在固定 61-XOR DAG 的
27 个 first-layer pair 中任选一个复制。两个物理 XOR 具有相同稳态行，但可携带独立
pre-label；每个 B 消费点选择其中一个副本，raw-post 仍可按消费者使用。全部 27 种复制
位置在 `OR<=42` 下均 UNSAT。

为排除编码过强导致的假 UNSAT，另以 `OR<=47` 对第一个 duplicate 案例做正向测试，
成功得到 `405/9/67` SAT 证书。即新增模型仍包含原 47-OR 可行基线。

同一模型进一步穷尽固定最小 DAG 上同时复制两个不同 first-layer pair 的全部
`C(27,2)=351` 种位置组合。门账为：

```text
172 + (61+2)*3 + OR<=39 = 400/9/67
```

结果为 `351 UNSAT / 0 UNKNOWN`。四个不重叠区间的索引并集经独立合并器验证恰好为
`0..350`，351 个复制位置对也全部不同。双复制 `OR<=47` 正向冒烟得到
`408/9/67 SAT`，确认复制数泛化后仍保留原可行基线。

## 边界

这些 UNSAT 只封闭固定 two-shear T 下的 row-deduplicated 深度二网表，以及固定最小 DAG
的一个或两个 pair 复制。它们不排除“新 pair cover 加复制”的混合 x63 DAG、不同 T、更深
的共享 XOR DAG、复制三个以上稳态节点、跨 tick 共享，或真实 Switch/Z 非线性网络。下一步
应转向不同 T 或更深共享 DAG，而不是继续顺序堆叠 row-deduplicated `x64`。
