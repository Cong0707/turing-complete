# RNG 原始异或对后置 OR 精确审计

日期：2026-08-03

## 结论

过去的 `joint_mediated_sat.py` 只允许一个 steady state pair 拥有一个全局 tick-zero
标签，并通过 XOR 两个输入端上的 `OR(seed_i,q_j)` 产生该标签。它没有覆盖以下合法的
九延迟结构：

```text
q_a,q_b arrival 4
  -> XOR2            arrival 6, 3 gates
  -> OR(seed_i,pair) arrival 7, 1 gate
  -> final XOR2      arrival 9, 3 gates
```

后置 OR 在装载时因 raw pair 为零而输出 `seed_i`，稳态时因 seed 为零而输出 raw pair。
同一 raw pair 可以建立多个 `(pair,seed_i)` 后置 OR，并让请求相同标签的消费者共享。

新模型完整加入这条路线后，固定 `402/9/67` 数据 DAG 的精确结果仍是：

```text
61 XOR + OR<=47   SAT
61 XOR + OR<=46   UNSAT
61 XOR + OR<=45   UNSAT
```

SAT47 证书最终选择 `47` 个 pre-XOR leaf OR、`0` 个 post-XOR OR，27 个 pair 全部为
pre-XOR 模式。也就是说后置 OR 确实在搜索域内，但在固定 61-XOR DAG 上没有降低最优值：

```text
fixed shell 172 + 61*3 + 47 = 402 gates
delay = 9
cycles = 67
```

## 模型覆盖

对固定 27 个一级 state pair，每个 pair 精确二选一：

1. `pre-xor`：两个输入引脚各至多绑定一个 seed bit，标签权重至多二；物理成本按不同
   `(seed,state)` OR 的并集支付。
2. `raw-post`：先计算不带 seed 的 raw XOR；每个 B 消费点可选择零标签或一个 seed bit，
   物理成本按不同 `(pair,seed)` 后置 OR 的并集支付。

32 条 B 行共有 51 个物理消费点。每一点的有效装载标签被逐位约束，两个 fanin 的标签
异或必须等于对应 `T` 行。C-only 消费点在装载时输出关闭，因此不施加虚假标签约束。
所有 OR 原子统一进入真实基数预算；没有抽象一门 XOR、RAM、非零 Delay 初态或伪造成绩。

独立验证器不调用 SAT 求解器，重新检查 27 个 pair 的 pre 标签与方向、每个 raw-post
消费点的零/单比特标签、leaf/post OR 精确并集、32 条 B 行标签等式以及总门账。复核输出：

```text
B rows      32
occurrences 51
leaf OR     47
post OR      0
total OR    47
XOR         61
total gate 402
```

## 62-XOR 邻域

随后对相邻 `x62` 前沿使用相同 pre/post 模型，目标为：

```text
172 + 62*3 + OR<=42 = 400/9/67
```

完整枚举固定 T 的 92 个 extra16 pair set、112 个 B/C 完整分解，去重为 102 个
`(pair set,B topology)`；另加入 5 个“固定 x61 pair cover + 一个 unit-final”结构。
结果为：

```text
UNSAT   107
SAT       0
UNKNOWN   0
elapsed 226.292 s
```

因此 row-deduplicated x62 pair-cover 与 unit-final 邻域也不能给出 `<=400/9/67`。这个
结论仍不覆盖 x62 中额外复制同一 steady row、但赋予不同 pre-label 的物理 XOR；raw pair
后置 OR 的多标签共享则已经完整覆盖。
