## 65 周期模型

固定 xorshift32 转移矩阵为 `A`，状态基底为可逆矩阵 `T`：

```text
B = T*A*T^-1
D = T*(A+I)
C = A*T^-1

q' = B*q XOR D*seed
y  = C*q XOR A*seed
```

输出必须在状态更新前采样。由 `q_0=0` 开始，第 `k` 拍状态满足：

```text
q_k = T*(A^k+I)*seed
y_k = A^(k+1)*seed
```

当前支持度最强中心取自：

```text
.research/rng_energy_alt_lift/persistent-t-tabu128.jsonl
```

按 `(over, excess, max, standalone, weight)` 选择最优记录：

```text
over / excess / max = 3 / 4 / 11
standalone          = 2445
total weight        = 495
```

仅输出矩阵 `C` 的第 12、17、18 行违反总支持度 9；对应目标支持度分别为
10、10、11。

## 专用精确 SAT

`solve_three_c_rows_sat.py` 不显式编码完整逆矩阵，而使用等价恒等式：

```text
C*B = A*C
C*D = A*(A+I)
```

`A*(A+I)` 在 GF(2) 上可逆，所以第二个恒等式保证 `C` 可逆，进而精确得到：

```text
B = C^-1*A*C
D = C^-1*A*(A+I)
T = C^-1*A
```

固定其余 `C` 行后，三行模型规模为：

```text
variables = 34,607
clauses   = 95,216
```

旧的全矩阵模型约有 168,366 个变量；专用模型将规模降到约五分之一。

### 支持度 9 的严格结果

1. 只释放必改行 `{12,17,18}`：精确 `UNSAT`。
2. 再释放任意一行：29 个四行邻域全部精确 `UNSAT`。
3. 再释放任意两行：406 个五行邻域首轮得到 397 个 `UNSAT`、9 个
   `UNKNOWN`；9 个未知项提高到 100 万冲突后全部转为精确 `UNSAT`。

因此，相对于当前中心，任何支持度不超过 9 的解必须至少同时改变 6 条
`C` 行。这个结论只约束该中心的行邻域，不是全局 support-9 不存在性证明。
