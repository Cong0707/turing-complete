# Switch 103/5 A/B 节点与接口结构差分

日期：2026-08-05

## 结论

两份人工样本都已由现有 derived audit 对全部 `131072` 个 `A/B/Cin` 输入重放：

```text
                         A                 B
gate / delay / energy   103 / 5 / 515     103 / 5 / 515
truth mismatch          0                 0
BUS conflict rows       0                 0
physical components     90                89
```

本轮节点级和接口级差分的确定结论是：

1. A/B 不是“同一 DAG 只换一门”。两者有 `69` 个相同 `permanent_id`，其中 `63` 个连输入/输出信号合同也相同；另有 `6` 个相同物理元件被重新接到不同的 C6/负原因接口。
2. A 独有 `21` 个物理元件，B 独有 `20` 个；但 A 独有块含 `4` 只 Switch，B 独有块含 `5` 只 Switch。按游戏成本两块均为严格 `25 gate`，不能把物理元件数 `21 -> 20` 误记成省一门。
3. A 的 producer/helper 中段确实比 B 少一门：`2` 对 `3`。B 的高侧 S5 completion 确实比 A 少一门：`6` 对 `7`。这两项不是独立收益；B 的六门 completion 消费了 B 三门 helper 中支付的 `HB`，所以不能和 A 的两门 helper 无条件相加成 `24 gate` 替换块。
4. 因此当前证据否决的是**零适配器、按现有边界直接拼成完整 `102/5`**。它不构成对重新联合设计或重新综合的任意 `102/5` 的下界。
5. 投影到权威 Patchouli `84/6/504` 后，没有得到确定性净省门，当前严格收益为 `0 gate`。能迁移的是若干已存在函数、条件早到相位和需额外付费的负原因副产物。

## 一、节点级差分

### 1. 共有物理骨架

```text
相同 permanent_id                         69
输入/输出信号合同也完全相同              63
相同物理元件但接口重接                     6
A-only 物理元件                            21
B-only 物理元件                            20
A-only 游戏门成本                          25
B-only 游戏门成本                          25
```

六个重接元件位于：

```text
Maker8                           ( 1,-51)
C8 末端 Switch                  (-8, 52)
S6 两只负原因/C6 Switch         (-8, 30), (-8, 32)
S7 两只负原因/C6 Switch         (-8, 48), (-8, 46)
```

其中 A/B 的 C6 布尔数据相同，但三态 driven 域不同：

```text
A C6 Z rows       24576
B C6 Z rows       36864
```

Maker 和最终 BUS owner 把这一区别归一化，故两份完整输出都无 mismatch、无冲突；但这证明它们的接口不是可按网络名直接互换的普通布尔 wire。

## 二、两个“一门”的真实来源

把 A/B 不同的 `25 gate` 窗口切成共同壳、helper producer 和 S5 completion：

| 部分 | A | B |
|---|---:|---:|
| 其余独有共同壳 | 16 | 16 |
| helper producer | 2 | 3 |
| S5 completion | 7 | 6 |
| 合计 | 25 | 25 |

### 2.1 A 的 helper 为何少一门

A 用一只共享 producer 同时服务 C6 enable 和 S5：

```text
EA = G4 OR NOT(P5)             # A74
RA = NOT(C4 OR EA)             # A83
```

成本为两只普通门。B 把职责拆成三个函数：

```text
EB = G4 OR G5                  # B42, C6 enable
RB = NOT(C4 OR EB)             # B53, negative reason
HB = NOT(Q4 OR P5)             # B83, S5 reason
```

成本为三只普通门。因此在这个 producer/helper 账本上，A 严格少 `1 gate`。

### 2.2 B 的高尾（S5 completion）为何少一门

这里沿用本次问题的切口，把跨 C6 producer 窗口的 S5 completion 记入“高侧/高尾”；它不是指 A/B 完全共有的 bit6:7 后缀。

A 的 S5 completion 在已经支付 `EA` 后，还需要：

```text
3 ordinary gates + 2 Switches = 3 + 4 = 7 gate
```

B 的 completion 是三只 Switch：

```text
3 Switches = 6 gate
```

因此 completion 本身 B 严格少 `1 gate`。但 B 的三只 Switch 不是只消费 A 的 `{EA,RA}`：它们还消费 `HB`、`Q4` 和 B 的 S4 相位 `n27B=C4 OR NOT(P4)`。

## 三、为何不能无条件得到 102/5

表面相加为：

```text
common shell 16 + A helper 2 + B completion 6 = 24
```

问题是这行漏付了 `HB`。`HB=NOT(Q4 OR P5)` 正是 B 三门 helper 中的第三门，也是 B completion 的真实 enable。把它补回至少恢复为：

```text
16 + 2 + 6 + 1 = 25
```

并且仍有两个接口差异不能按线名直连：

```text
B completion 要 Q4；A 物化的是 V4=NOT(Q4)
B completion 要 n27B=C4 OR NOT(P4)；A 使用另一对 S4 相位
```

固定 `18` 行 one-hot bit4/bit5/C4 真值验证还给出：

```text
A S5 mismatch                           0
B S5 mismatch                           0
A C6 mismatch                           0
B C6 mismatch                           0
RA 与 RB 不同的行                       2
P5*RA 与 P5*RB mismatch                 0
R0 OR RA 与 NOT(C6) mismatch            0
R0 OR RB 与 NOT(C6) mismatch            0
```

所以 `RA` 可以在 `SW(R,P5)` 的数据关心域内替代 `RB`，但这只解决一个 reason rail；它不会免费产生缺失的 `HB/Q4/n27B`。结论是：

```text
zero-adapter A-helper + B-completion splice   invalid
complete 102/5 obtained                       no
global 102/5 impossibility proved             no
```

## 四、可投影到权威 84/6 的函数

### 4.1 已经存在于 84/6 的同函数 producer

| 样本节点 | 函数 | 样本 arrival | 权威节点 | 权威 arrival | 结论 |
|---|---|---:|---:|---:|---|
| B51 | `V45=NOT(Q4 OR Q5)` | 2 | 66 | 2 | 完全同函数、同到达；权威已支付 |
| A82 / B79 | `D45=G5 OR V45` | 3 | 67 | 3 | 完全同函数、同到达；权威已支付 |
| B83 | `H5=NOT(Q4 OR P5)` | 3 | 73 | 3 | 完全同函数、同到达；权威已支付 |
| A28 | `P4` | 2 | 60 | 2 | 同函数，不带净节省 |
| A38 / B41 | `P5` | 2 | 63 | 2 | 同函数，不带净节省 |

这些节点可作为结构解释或替换实现，但不能再次从 `84` 门账本中扣除，因为权威 DAG 已经付费产生同一函数。

### 4.2 条件早到的 S4 相位

A 的 `T4/R4/S4` 与权威节点 `69/70/71` 同函数，A/B 的 `S4` 为 `@5`，权威为 `@6`。早一层的原因不是免费 producer，而是：

```text
103/5 样本 C4 @3
权威 84/6 C4 @4
```

因此这组只在同时迁移早到 `C4@3` 的低位前端时有价值；单独移植到当前权威边界会恢复到 D6。

### 4.3 新的、但需要付费的 reason 副产物

```text
R0 = NOT(D45)                    A84 / B80 @3
RB = NOT(B23 OR G345)            B53       @4
RA = P5 AND RB                   A83       @4
```

它们的用途是为 S6/S7 等消费者提供 `NOT(C6)` 的原因覆盖：

```text
R0 OR RA = NOT(C6)
R0 OR RB = NOT(C6)
```

但在权威 `84/6` 中：

```text
R0 需要从现有 D45 再付 1 gate
RB 需要从现有 B23/G345 再付 1 NOR
RA 是 consumer-restricted reason，不是完整 nC6
```

目前没有证明这些新增门能同时删除更多权威旧门，故不能记录确定性节省。
