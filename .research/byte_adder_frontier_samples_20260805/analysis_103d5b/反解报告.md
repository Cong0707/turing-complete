它是一套完整、独立、可从 `A[7:0] / B[7:0] / Cin` 直接得到

## 四、输入输出识别

不可变接口由 v15 标签和引脚共同确认：

```text
Input  A          U8
Input  B          U8
Input  Carry in   U1
Output Output     U8
Output Carry out  U1
```

两个 Splitter8 把 `A/B` 拆成 LSB-first 的 `A0..A7/B0..B7`。Maker8 按相同顺序
合并 `S0..S7`。

Carry out 前还有一对免费元件：

```text
Maker2(0, raw_C8) -> Splitter2.out1 -> Carry out
```

物理上故意悬空的两个 pin 为：

```text
Maker2.in0       悬空，作为数值 0
Splitter2.out0   不消费
```

这不是损坏。Maker 把悬空/Z 数据按数值 0 读入并输出 fully-driven U2，Splitter 再取
lane1，使 raw C8 的零态 Z 免费归一化为主动 0。

## 五、符号

每位定义：

```text
Gi = Ai AND Bi
Qi = NOR(Ai,Bi)
Vi = Ai OR Bi
Ni = NAND(Ai,Bi) = NOT Gi
Pi = Ai XOR Bi
Ci = 第 i 位 carry in
Si = Pi XOR Ci
```

Switch 写作：

```text
SW(enable,data)
```

同一导线上的多只 Switch 写作 `BUS(...)`。`enable=0` 输出 Z；普通逻辑或 Maker 读取
Z 时数值为 0；若两个 driver 同时主动输出不同值，则为真实冲突。

## 六、低两位：V/G carry 与四门 sum 后处理

### C1

```text
M0 = BUS(
  SW(A0,Cin),
  SW(B0,Cin)
)                                      4 gate / D1

C1 = G0 OR M0                          +1 gate / D2
```

数值上：

```text
M0 = Cin*V0
C1 = G0 OR Cin*V0
```

### S0

```text
K0 = NOR(V0,Cin)
T0 = NOR(C1,K0)
H0 = AND(Cin,G0)
S0 = OR(T0,H0)                         4 gate / D4
```

这是按 K/P/G 三态分区的 sum，不是先造 P0 再 XOR。

### C2

```text
C2 = BUS(
  SW(G1,V1),
  SW(G0,V1),
  SW(M0,V1)
)                                      6 gate / D2
```

由于第一路在 `G1=1` 时直接写 1，其余两路共同实现 `V1*C1`：

```text
C2 = G1 OR V1*C1
```

### S1

```text
K1 = NOR(V1,C1)
T1 = NOR(C2,K1)
H1 = AND(C1,G1)
S1 = OR(T1,H1)                         4 gate / D5
```

S0/S1 使用同一类四门后处理；C1/C2 carry 的 G/V 状态副产物被直接消费。

## 七、bit2:3：稀疏 C4 owner

局部状态：

```text
V2 = A2 OR B2
N2 = NAND(A2,B2)
P2 = V2 AND N2

G3 = A3 AND B3
V3 = A3 OR B3
N3 = NAND(A3,B3)
nP3 = NAND(V3,N3) = G3 OR Q3
```

### C3 与 S2

```text
X2 = NAND(C2,P2)
Y2 = OR(C2,P2)
S2 = AND(X2,Y2)                        3 gate / D4

C3 = NAND(X2,N2)                       +1 gate / D4
```

### C4

```text
W23 = BUS(
  SW(G3,V3),
  SW(V2,V3)
)                                      4 gate / D2

R23 = NAND(N2,N3) = G2 OR G3          1 gate / D2

C4 = BUS(
  SW(R23,W23),
  SW(C2,W23)
)                                      4 gate / D3
```

严格公式：

```text
W23 = V3*(G3 OR V2)
C4  = W23*(G2 OR G3 OR C2)
```

全 `131072` 行：

```text
C4 mismatch       0
BUS conflict      0
missing-one       0
raw Z rows        36864，全部属于 C4=0
```

### S3

```text
A3 = NOR(nP3,C4) = P3*nC4

S3 = BUS(
  SW(nP3,C3),
  SW(A3,A3)
)                                      5 gate / D5
```

当 bit3 非传播时，第一路直接输出 C3；当 bit3 传播时，第二路只对
`P3*nC4=1` 的行做 one-cover，其余目标零行保持 Z。

## 八、bit4:5：B 的关键状态重编码

局部状态：

```text
G4,Q4,nP4=G4 OR Q4
G5,Q5,P5=NOR(G5,Q5)
```

### S4

```text
U4 = C4 OR nP4
V4 = NAND(C4,nP4)
S4 = NAND(U4,V4)                       3 gate / D5
```

`U4` 不只是 S4 的 XOR 中间量，还被 S5 复用。

### D45/C6

```text
V45 = NOR(Q4,Q5)                       @2
D45 = G5 OR V45                       @3
E45 = G4 OR G5                        @2

C6 = BUS(
  SW(E45,D45),
  SW(C4,D45)
)                                      4 gate / D4
```

即：

```text
C6 = D45*(C4 OR G4 OR G5)
```

同时公开两条负进位 reason：

```text
K45 = NOR(V45,G5) = NOT D45           1 gate / D3
R1  = NOR(E45,C4)                     1 gate / D4

nC6 = K45 OR R1
```

它们不先经过 OR 合成完整 nC6，而是分别作为 S5/S6/S7 的 Switch enable，避免增加
一层延迟。

### 三 Switch S5 owner

```text
H5 = NOR(P5,Q4) = nP5*V4              @3

S5 = BUS(
  SW(Q4,P5),
  SW(H5,U4),
  SW(R1,P5)
)                                      6 gate / D5
```

三组重叠严格安全：

```text
Q4 与 H5             互斥
Q4 与 R1 重叠        两路 data 都是 P5
H5 与 R1 重叠        此时 P5=0 且 U4=0，两路都主动写 0
```

完整重放：

```text
S5 mismatch          0
BUS conflict         0
missing-one          0
raw Z rows           32768，全部属于 S5=0
```

## 九、bit6:7：直接消费 nC6 reason split

### S6

```text
P6  = NOR(Q6,G6)
nP6 = OR(Q6,G6)

S6 = BUS(
  SW(K45,P6),
  SW(R1,P6),
  SW(C6,nP6)
)                                      6 gate / D5
```

前两路共同实现 `P6*nC6`，第三路实现 `nP6*C6`。该 owner 每一行都主动驱动，
`Z rows=0`。

### S7 的两个 C6 cofactor

```text
nP7 = OR(Q7,G7)                        @2

X7  = NOR(nP7,Q6) = P7*V6             @3
Y7  = AND(nP7,Q6)                      @3
F7  = NOR(X7,Y7) = XNOR(P7,Q6)        @4

M7  = OR(G6,nP7)                       @3
N7  = NAND(G6,nP7)                     @3
L7  = NAND(M7,N7) = XOR(G6,P7)        @4

S7 = BUS(
  SW(K45,L7),
  SW(R1,L7),
  SW(C6,F7)
)                                      6 gate / D5
```

解释：

```text
C6=0 -> C7=G6       -> S7=XOR(G6,P7)=L7
C6=1 -> C7=NOT Q6   -> S7=XNOR(Q6,P7)=F7
```

### C8 与 S7 的跨输出共享

S7 内部的两条轨被 C8 直接复用：

```text
X7 = P7*V6                  同时进入 C8 data
M7 = G6 OR nP7              同时作为 C8 enable

B8 = G7 OR X7                        1 gate / D4

raw_C8 = BUS(
  SW(M7,B8),
  SW(C6,B8)
)                                      4 gate / D5
```

状态证明：

```text
bit7=G -> nP7=1，B8=1，输出 1
bit7=K -> nP7=1，B8=0，输出 0
bit7=P -> B8=V6，enable=G6 OR C6，乘积等于 C7
```

从已经支付的 S7 cofactor 看，C8 的边际成本只有：

```text
B8 OR               1
two-Switch owner     4
Maker2/Splitter2     0
----------------------
total                5 gate / D5
```

raw C8 有 `24576` 个 Z 行，全部为目标零；免费 Maker2/Splitter2 将其归一化。

## 十一、与同包 `Switch 103 5 A` 的差异

两份电路的低四位主干和高位 S6/S7/C8 架构基本相同；主要差异集中在 bit4:5 的相位
编码和 S5/C6 owner。

成本分布：

| 项目 | A | B | B-A |
|---|---:|---:|---:|
| AND | 14 | 12 | -2 |
| NAND | 15 | 10 | -5 |
| OR | 15 | 16 | +1 |
| NOR | 13 | 17 | +4 |
| Switch | 23 | 24 | +1 |
| 普通门 | 57 | 55 | -2 |
| Switch 加权 | 46 | 48 | +2 |
| **总门数** | **103** | **103** | **0** |

A 使用 `V/N/P` 相位和 fully-driven 两 Switch S5；B 使用 `G/Q/nP` 相位，把两只普通门
换成一只额外 Switch，得到带 Z 的三 Switch S5。两者都正确、D5、总成本相同。

A 的关键形式：

```text
EA = NAND(N4,P5) = G4 OR nP5
DA = NAND(NAND(V4,V5),N5) = G5 OR V4*V5
C6 = DA*(EA OR C4)
```

B 的关键形式：

```text
EB = G4 OR G5
DB = G5 OR V4*V5
C6 = DB*(EB OR C4)
```

`EA` 与 `EB` 不全等，但在 `D=1` 的 C6 data care domain 内等价；这是人类样本使用
care-domain 状态重编码，而不是普通等价门替换的直接证据。

owner 差异：

```text
A: 23 Switch；S5 两 driver、fully-driven；C6 raw Z=24576
B: 24 Switch；S5 三 driver、raw Z=32768；C6 raw Z=36864
```

## 十二、与仓库独立 `103/5` 的差异

仓库独立构造位于：

```text
.research/byte_adder_d5_frontier/patchouli103-d5-audit-v1.json
```

两者分数和输出 arrival 相同，但结构不同：

| 项目 | 人工 B | 仓库独立 103/5 |
|---|---:|---:|
| weighted gate | 103 | 103 |
| delay | 5 | 5 |
| 普通门加权 | 55 | 59 |
| Switch 数 | 24 | 22 |
| Switch 加权 | 48 | 44 |
| resolved BUS | 10 | 9 |
| XOR 元件 | 0 | 2 |
| raw S5 Z rows | 32768 | 32768 |
| raw C8 Z rows | 24576 | 36864 |

仓库独立方案保留 Patchouli 84 的 `B23/G345/D45` 脊柱，并用 `R0/R1` 将 nC6 分成两条
reason；人工 B 则先把 C4 提前到 D3，再用 `C4/G4/G5` 构造 C6。人工 B 用三门普通
逻辑实现两个 XOR/XNOR cofactor，仓库独立方案在两处直接按 XOR 成本 3 计费。

两者都复用 C6 的正负原因完成 S6/S7，但 C8 cofactor 不同：

```text
人工 B:
  B8 = G7 OR P7*V6
  C8 = B8*(C6 OR G6 OR nP7)

仓库独立:
  B8 = NOR(Q7,Q6*P7)
  C8 = B8*(C6 OR G6 OR G7)
```

因此，“同分数”不意味着同拓扑。人工 B 的结构签名与 A、仓库独立 DAG 均不同。

## 十三、迁移到 `84/6 -> 83/6` 的固定替换账本

### 13.1 B 的 C4 owner

当前 84 从已付 `Q2/G2/Q3/G3/C2` 到 C4：

```text
N23                 1
B23 two-Switch      4
C4 final OR         1
---------------------
total               6 gate / C4@4
```

B 的 producer：

```text
W23 two-Switch      4
R23                 1
C4 two-Switch       4
---------------------
total               9 gate / C4@3
```

固定真值：`mismatch=0, conflict=0, missing-one=0`。它买到一拍，但多 3 门。

### 13.2 B 的 D45/C6 owner

当前 84：

```text
K34                 1
G345                1
V45                 1
D45                 1
C6 two-Switch       4
---------------------
total               8 gate / C6@4
```

B 在 `C4@3` 前提下：

```text
E45=G4|G5           1
V45                 1
D45                 1
C6 two-Switch       4
---------------------
total               7 gate / C6@4
```

固定真值与冲突均为 0。局部确实省 1 门，但把当前 `C4@4` 直接接入时，C6 只能在 D5
产生；当前 84 的 S5/S6/S7/C8 高尾都依赖 `C6@4`，因此该 hybrid 不是合法 D6 替换。

合并必要 producer：

```text
current: C4 6 + C6 8 = 14
B:       C4 9 + C6 7 = 16
delta                        +2
```

B 的一门优势正是把 `C4@3` 当作已付边界后的条件优势，不能脱离 C4 producer 记账。

### 13.3 B 的三 Switch S5

当前 84：

```text
U45,H5,T5,J5,OR      5 gate / D6
```

B owner 若把 `U4/R1` 都乐观视为其他消费者已支付：

```text
H5                   1
three Switch         6
----------------------
total                 7 gate / D6
delta                +2
```

若从当前已付 `G/Q/P/C4` 独立构造，则还需 `nP4/U4/E45/R1`，总成本 11，净增 6。

因此 B 的三 Switch S5 是 D5 架构所需的时序换门手段，不是当前 D6 Patchouli 五门 S5
的门数优化。

## 十四、明确可迁移的子结构

虽然没有直接得到 83，以下结构值得纳入后续人工架构设计。

### 1. 两条 nC6 reason 不合流

```text
K45 = NOT D45                      1 gate / @3
R1  = NOT(C4 OR G4 OR G5)          1 gate / @4（B 边界）
nC6 = K45 OR R1
```

不支付最后 OR，而让 S5/S6/S7 分别消费两条 reason。该模式在当前 84 边界中变成
`R1@5`，仍可在 D6 进入最终 Switch，但只有同时删除多个旧 owner 才可能回本。

### 2. S7 cofactor 内部直接喂给 C8

```text
P7*V6            既是 F7 的 minterm，也是 C8 data 的一半
G6 OR nP7        既是 L7 的预计算，也是 C8 enable
```

这是样本 B 最明确的跨输出共享。任何新高尾都应把 S7/C8 联合看待，不应先单独完整
形成 C7、S7，再重新造 C8。

### 3. 免费终端 `Z -> 0` 归一化

```text
Maker2(0, may-Z signal) -> Splitter2.out1
cost 0 / delay 0
```

它允许最终 one-cover owner 在目标零行保持 Z，不必为了“主动写零”增加门。限制是：

- 只能把 Z 当数值 0；
- 不能把它当作可穿透后级 Switch 的第三逻辑态；
- active-0/active-1 冲突仍然非法；
- 对 U8 Output，Maker8 本身已经能完成同类 lane 归一化。

### 4. care-domain 相位重编码

A/B 的 C6 enable 不全等，但在共同 data `D45` 的有效域内等价。后续不应只找全域等价
rail；可以寻找：

```text
data=1 的 care domain 内等价
data=0 重叠时所有 driver 同为主动 0
其余行保持 Z
```

这比固定正负 carry 相位更接近人工 B 的真实设计方式。
