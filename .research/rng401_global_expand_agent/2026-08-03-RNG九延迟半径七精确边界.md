# RNG 九延迟 radius-7 精确边界

## 结论

在当前 `172 gate` 固定外壳、无 RAM、真实 `XOR2 = 3 gate / 2 delay` 的
canonical 深度二模型内，已对 radius-7 的 399 个唯一状态基底完成精确 SAT
审计：

| greedy XOR | 唯一 T | 结果 | T 集合 SHA-256 |
|---:|---:|---:|---|
| 58 | 75 | 75 UNSAT | `2aa92d477df10c72ff6d62912a724015ba0727dc644c2d3ad016fd271d6d6ec1` |
| 59 | 203 | 203 UNSAT | `6eac94a6eea053ba3b93dda8380fd588e6eecf37347d6ac7f2c444e5c1085b97` |
| 60 | 121 | 121 UNSAT | `5c7a6c1fbad2882d19a17997c5df33734c8e1c03592c5d073fa4977d48ee412e` |
| 合计 | 399 | 399 UNSAT，0 SAT，0 UNKNOWN | 见统一清单 |

审计预算为：

```text
总门数 = 172 + 3 * XOR2 + OR mapping
3 * XOR2 + OR mapping <= 229
目标 <= 401 / 9 / 67
```

因此这些候选在同一模型中也不可能达到更严格的 `<=400/9/67`。本结论没有
使用一门 XOR、RAM、伪造分数或服务端不可重算的行为。

## 计数纠正

`rng_401_verified_basis` 中三个 x60 输入文件是嵌套集合：

```text
x60-heavy41.jsonl  = heavy lower <= 41，共 36 个
x60-heavy42.jsonl  = heavy lower <= 42，共 45 个，不是新增 45 个
x60-heavy43.jsonl  = heavy lower <= 43，共 121 个，不是新增 121 个
```

所以已审计 x60 的唯一 T 数是 `121`，不是把 `36 + 45 + 121` 相加得到的
`202`。统一清单按 `T_sha256` 去重，并拒绝 SAT 或无最终结论的候选。

## exact 模型覆盖范围

模型文件：

```text
.research/rng_x56_or10_exact/joint_mediated_sat.py
SHA-256 9ddfcbe11b394ef416bab1789533c19e2d227c65d9f2863ba4f355274cdee448
```

模型对每个 T 执行以下工作：

- 先验证矩阵恒等式 `C*T=A` 与 `T*C=B`；
- 对每个不同的 weight-3/4 B/C 行枚举全部合法深度二分解；
- 对 B 的 weight-1/2 行允许 direct 与全部同函数 mediated 实现；
- 在同一个 CNF 中联合选择实际使用的 pair，而不是预先固定 greedy cover；
- 精确选择每个 pair 的 tick-zero seed 标签、引脚方向和
  `(seed bit, state bit)` OR 映射并集；
- 每个真实 XOR2 收取 3 gate，每个 OR mapping 收取 1 gate；
- 无 topology 数量上限、无 component/global beam、无抽样；
- 若找到 SAT，证书还必须通过 256 个官方 seed、每个 65 项输出回放。

这是一份定义清晰的精确子模型，不是所有合法开关电路的全局模型。它尚未表示：

- 三层或更深、可跨多个输出共享中间节点的 XOR DAG；
- 利用 Switch 高阻态直接合并网络函数的非 OR-mapping 拓扑；
- radius-7 以外的相似变换、不同状态维数或跨拍重定时；
- canonical 候选筛选之外的样本特化网络。

### 精确模型边界

本批使用与正文相同、SHA-256 已绑定的 `joint_mediated_sat.py`，但预算从
`logic<=229` 收紧为 `logic<=228`：

```text
solver script = .research/rng_x56_or10_exact/joint_mediated_sat.py
solver script SHA-256 = 9ddfcbe11b394ef416bab1789533c19e2d227c65d9f2863ba4f355274cdee448
fixed shell = 172 gate
logic       = 3 * physical XOR2 + exact OR mapping union <= 228 gate
target      = <=400 / 9 / 67
XOR2        = 3 gate / 2 delay
OR mapping  = 1 gate / 1 delay
solver      = CaDiCaL 1.9.5
cardinality = mtotalizer
timeout     = 30 秒/候选
```

模型仍完整联合选择深度二 heavy 分解、direct/mediated 低权反馈、实际 pair、
tick-zero 标签、引脚方向和 OR mapping 并集；没有 cover/topology/global beam。
它仍不覆盖正文列出的更深共享 DAG、Switch-Z 非 OR 网络和跨拍重定时，因此
`98 UNSAT` 是该 exact 子模型内的严格结论，不是所有游戏合法电路的全局反证。
