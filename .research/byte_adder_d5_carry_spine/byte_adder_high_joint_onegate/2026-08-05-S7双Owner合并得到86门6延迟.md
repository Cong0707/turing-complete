## 一、原始 S7/C8 付费轨

以下名称、组件索引和到达时间均来自上述实物：

```text
nP6  = OR(Q6,G6)                    component 60, @2
n207 = OR(C6,nP6)                   component 64, @5
P7   = NOR(Q7,G7)                   component 67, @2
n258 = AND(Q6,P7)                   component 70, @3
n278 = NOR(Q6,P7)                   component 73, @3
n285 = NOR(C6,OR(G7,G6))            component 74, @5
```

原始 `S7` 是一个三 driver 的完整 resolved owner：

```text
S7_old = BUS(
    SW(enable=n278, data=n207),      component 66
    SW(enable=Q6,   data=P7),        component 71
    SW(enable=n285, data=P7)         component 72
)
```

`n258=Q6 AND P7` 并非新付费节点；它已经由 `C8` 使用，必须保留：

```text
K76 = OR(n258,Q7)
C8  = NOR(n285,K76)
```

## 二、合并公式

新增一只普通 OR：

```text
U = OR(n278,n258)
  = (NOT Q6 AND NOT P7) OR (Q6 AND P7)
  = XNOR(Q6,P7)
```

然后把 `S7` 改成两 driver owner：

```text
S7_new = BUS(
    SW(enable=U,    data=n207),
    SW(enable=n285, data=P7)
)
```

成本变化：

```text
删除一只 Switch                 -2 gate
新增 U=OR(n278,n258)             +1 gate
-----------------------------------------
净变化                            -1 gate
87 -> 86
```

## 三、为什么第一路可以合并

`n278` 与 `n258` 是 `(Q6,P7)` 的两个对角状态，严格互斥：

```text
n278 = NOT Q6 AND NOT P7
n258 =     Q6 AND     P7
n278 AND n258 = 0
```

在 `n278=1` 的行上，新第一路与旧第一路完全相同。

在新增的 `n258=1` 域中：

```text
Q6=1  -> bit6 是 K 状态 -> P6=0 -> nP6=1
P7=1
n207 = C6 OR nP6 = 1
```

所以：

```text
SW(n258,n207) = SW(Q6 AND P7,1)
               = SW(Q6,P7) 的全部 active-one 行
```

旧 `SW(Q6,P7)` 在 `Q6=1,P7=0` 时只主动驱动 0。新 owner 可以在这些正确输出为
0 的行上变为 Z；最终关卡 `Maker8` 已有的零成本归一化会把该 lane 的 Z data-plane
读取为 0。这不会丢掉任何期望为 1 的驱动。

18 个状态中：

```text

active zero                    3
Z zero                         6

```

两路同时开启只可能落在两类状态：

```text

bit6=K, bit7=P, c=0: n207=1, P7=1
```

重叠时两路总是驱动相同数据，因此不会发生 `0/1` 冲突。

## 六、可直接编码的替换表

推荐保留所有组件索引，用原 `component 71` 的槽位替换为普通 OR。这可以避免删除
组件后引发全体索引和永久 ID 漂移，但布局器仍必须重新检查 sprite 与走线。

| 对象 | 原接线 | 新接线 |
|---|---|---|
| component 66 | `SW(n278,n207) -> S7` | `SW(U,n207) -> S7` |
| component 71 | `SW(Q6,P7) -> S7` | `OR(n278,n258) -> U` |
| component 72 | `SW(n285,P7) -> S7` | 不变 |
| component 70 | `AND(Q6,P7) -> n258 -> C8` | 保留原 C8 fanout，并新增到 U |
| S7 resolved network | drivers `66,71,72` | drivers `66,72` |

若复用 component 71 的原坐标 `(43,36)`、rotation 0，则 kind 7 的理论引脚坐标为：

```text
in0  (42,35)
in1  (42,37)
out  (45,36)
```

这只是编码提示，不是几何验收。最终物化必须重新路由并检查：

```text

wire interior foreign pin contact 0
unsafe multi-driver network       0

v15 roundtrip                  true
```
