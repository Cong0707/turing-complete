# 随机数六十五周期联合映射边界

日期：2026-08-03

## 结论

本轮转向 65 周期常开输入、常开输出协议，严格审计完整联合映射：

```text
q' = B*q XOR D*seed
y  = C65*q XOR A*seed

B   = T*A*T^-1
D   = T*(A+I)
C65 = A*T^-1
```

当前没有得到可物化的新电路。确定性结果如下：

1. 对任意可逆 `T`，完整 `64 x 64` 映射 `[B|D; C65|A]` 的秩恒为 64；
2. 64 个目标的 q 半部和 seed 半部均非零，也没有目标能直接别名到一个原始输入，故至少需要
   64 个不同的逻辑节点；
3. 纯 XOR2 在 q arrival 4、seed arrival 0、deadline 8 下，每行必须满足
   `4*wt(q)+wt(seed)<=16`；纯 XOR2 只有偶数延迟，所以总 delay 9 也没有额外 XOR 层；
4. 对 1733 个已有唯一状态基重新推导真实 65 周期矩阵，满足全部 64 行到达必要条件的数量为
   0；最接近记录仍为 `over=12 / excess=92 / max=34`；
5. tick 1 的 32 个反馈分裂对和 32 个输出分裂对全部具有完整四值真值表，逐输出把末级 XOR
   换为 OR、普通一/二门公式或单只 Bit Switch 均不成立。

这些结论排除了既有基底上的普通 XOR2 路线和逐输出局部开关替换，但不是任意 `T` 的全局
UNSAT，也不排除跨输出共享双轨、多个三态驱动器组成的合法 Z 网络。

此外，对 cancellation-free XOR2 DAG 得到一个全局门数下界：固定 seed 投影 `A` 的精确
最小子集 DAG 需要 61 个 XOR 节点；任意可逆 `C65` 又要求至少 32 个与前者类别不重叠的
q 注入节点。因此完整电路至少需要：

```text
61 + 32 = 93 XOR = 279 logic gate
160 + 279 = 439 total gate
```

这已经严格排除 `<=414 total gate / delay 9 / 65 cycles` 的全部 cancellation-free XOR2
电路；它仍低于八延迟预算 466 门，所以不能排除 `<=466/8/65`。

## 严格门数预算

65 周期外壳只有 32 个零初态 Delay Bit：

```text
fixed state gate = 32 * 5 = 160
```

按用户已经实机验收的 `402/9/67` 严格改善：

```text
delay 9: logic <= 254
delay 8: logic <= 306
```

若以仓库中的未再次实机确认研究前沿 `401/9/67` 为比较目标，则进一步收紧为：

```text
delay 9: logic <= 253
delay 8: logic <= 305
```

全部值都使用：

```text
floor((reference_energy - 1) / (delay * 65)) - 160
```

此前历史中的 `logic<=254` 若同时声称是在超过 `401/9/67`，属于取整口径错误；254 只对应
超过已验收的 402 门成绩。

## 联合映射秩

令自然状态为 `x=T^-1*q`。完整映射可分解为：

```text
M(T) = diag(T,A) * [[A,A+I],[I,I]] * diag(T^-1,I)
```

中间映射为：

```text
(x,seed) -> (A*x+(A+I)*seed, x+seed)
```

给定输出 `(u,v)` 可唯一恢复：

```text
seed = u + A*v
x    = v + seed
```

因此中间矩阵可逆，左右因子也可逆，`rank(M(T))=64`。脚本还独立重算
`rank(A)=rank(A+I)=32`。因为 `B,D,C65,A` 都可逆，每一个目标都同时依赖至少一个 q 位和
一个 seed 位；64 个互异目标均不可能是原始输入，所以任何二输入逻辑 DAG 至少有 64 个
目标节点。这个 64 是全局下界，但距离 84/85 个 XOR 的实际预算仍有差距，不能单独证明
门数不可达。

## 到达必要条件

把一个 XOR2 的 `2 delay` 记为一层：

```text
q leaf    level 2
seed leaf level 0
deadline  level 4
```

对任意目标锥展开为二叉树，每个 q 叶占用 deadline 容量 4，每个 seed 叶占用容量 1；重复
叶和抵消只会增加叶出现数，不会绕过容量。因此任意 XOR2 DAG 的每行必要条件为：

```text
4*wt(q_row) + wt(seed_row) <= 16
```

固定 `A` 的行权重为：

```text
weight 3:  5 rows
weight 4: 12 rows
weight 5:  3 rows
weight 6: 10 rows
weight 7:  2 rows
```

所以 `C65` 的 15 行权重最多为 2，其余 17 行最多为 3；反馈 `B` 也只能为 1 至 3 权，且
分别要求 `D` 权重不超过 12、8、4。对既有 1733 个唯一 `T` 的完整审计结果为：

```text
Kraft feasible     0
best over         12
best excess       92
best maximum      34
best target hash  069780cf9ffb120ded05f2780d997343fb49ed1a9c4630551d44547829cc8e8d
```

精确 CNF 已把全局必要条件编码为：

```text
D*A = B*D
C*D = A*(A+I)
```

但现有求解均为 UNKNOWN，不能把启发式前沿或超时误写为全局 UNSAT。

## 末级开关局部边界

tick 1 有 `q=D*seed`。反馈目标的两个直接半部为：

```text
left  = B*q    = D*A*seed
right = D*seed
left XOR right = D*(A+I)*seed
```

因为 `D`、`A`、`A+I` 均可逆，每一位的两条形式都非零且不相等。输出目标同理：

```text
left  = C65*q       = A*(A+I)*seed
right = A*seed
left XOR right      = A^2*seed
```

`A^2` 可逆，所以这 32 对也都由两个不同的非零线性形式组成。GF(2) 上两个不同非零形式线性
独立；即使关卡排除 seed 0，每一对仍有非零 seed 分别实现 `00/01/10/11`。证书保存了全部
64 对的四种 witness。

独立枚举 `NOT/AND/OR/NAND/NOR` 的二输入真值表闭包，XOR 最少仍需 3 门。单只 Bit Switch
成本为 2 门，关闭时输出 Z，不能作为完整主动二值 XOR；两只 Switch 已需 4 门。因此逐输出
局部替换不会比原生 `3/2` XOR 更省。真正开放的路线只有跨输出共享互补轨、共享控制或合法
多驱动 Z BUS，必须用完整 `(value,is_z)` 语义验证。

## Cancellation-free 九十三节点下界

先只投影完整电路的 seed 半部。对 cancellation-free 电路，任何有用中间形式必为至少一个
目标 `A_i` 支持集的非空子集；每个非单比特形式必须由两个不相交的已选子形式合并。脚本
完整生成 861 个候选形式、829 个非单比特形式和 5133 个无序二分解，用 RC2 精确最小化
所选非单比特形式数：

```text
L_cf(A) = 61 XOR nodes
```

这 61 是双输入均含 seed 的“seed merge”门下界。再把每个信号投影到 q 半部：q 信息第一次
从 seed-empty 区域进入 seed-nonempty 区域时，必经过一个恰有一个 seed-empty 输入的注入门。
全部输出 q 形式 `C65_i` 都在这些注入形式的线性张成中；`rank(C65)=32`，故至少需要 32 个
注入门。seed merge 有两个 seed-nonempty 输入，注入门恰有一个，两类物理门不相交，得到
全局 `61+32=93`。

该证明不依赖已枚举的 1733 个 T，也不假设某个固定 XOR tree；范围严格限于
cancellation-free XOR2。允许抵消、跨输出 Switch/Z 或只对可达样本正确的非线性网络仍开放。
