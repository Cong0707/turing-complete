# 随机数常开输入输出外壳审计

## 2026-08-03 / 研究：确认 65 与 66 周期的零成本输入路径

### 结论

当前 `2.1.281` 可执行文件及 RNG 关卡脚本下，`Constant On`、
`Architecture Input` 和 `Architecture Output` 均为 `0 gate / 0 delay`。
同一个 `Constant On` 可以合法扇出到输入和输出的控制引脚。因此 65 周期协议可以从
tick 0 起持续读取 seed 并持续检查输出，控制外壳严格为零成本：

```text
Constant On -> Architecture Input.control
Constant On -> Architecture Output.control

control = 0 gate / 0 delay
```

若用一只零初态 `Delay Bit` 抑制 tick 0 的输出，同时保持输入持续开启，则得到 66 周期
外壳：

```text
Constant On -> Architecture Input.control
Constant On -> ready Delay Bit.in
ready Delay Bit.out -> Architecture Output.control

control = 5 gate / 4 delay
```

这比经典的“一拍输入脉冲”外壳少一只 NOT，即少 1 gate；Architecture Input 的 value
到达时间也从 5 降为 0，使 seed 路径拥有完整的组合延迟预算。

### 计分边界

当前正常参考前沿为：

```text
401 * 9 * 67 = 241803
```

要严格低于该乘积，各外壳允许的最大总门数为：

| 协议 | 延迟 | 周期 | 最大总门数 | 32 位状态及控制 | 最大组合逻辑门数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 常开输入、常开输出 | 8 | 65 | 465 | 160 | 305 |
| 常开输入、常开输出 | 9 | 65 | 413 | 160 | 253 |
| 常开输入、延迟一拍输出 | 8 | 66 | 457 | 165 | 292 |

这里全部使用严格不等式计算：

```text
maximum_gate = floor((241803 - 1) / (delay * cycles))
```

上述数字只是可用于组合数据面的预算，并不代表已经存在对应门数和延迟的完整电路。

### 65 周期仿射状态机

记自然 xorshift32 线性变换为 `A`，可逆状态编码为 `T`，并定义：

```text
B   = T*A*T^-1
D   = T*(A+I)
C65 = A*T^-1
```

从全零状态开始，持续读取同一个 seed：

```text
q_next = B*q XOR D*seed
output = C65*q XOR A*seed
```

逐拍不变量为：

```text
q_t = T*(A^t+I)*seed
```

因此 tick `0..64` 的输出依次为 `A^1*seed .. A^65*seed`，正好在 65 拍内完成关卡要求的
65 次检查，不使用 RAM、非零 Delay 初态或计分字段修改。

### 66 周期持续 seed 状态机

保留同一状态递推，改用：

```text
C66   = T^-1
q_next = B*q XOR D*seed
output = C66*q XOR seed
```

tick 0 由 ready Delay 抑制输出并捕获第一份仿射状态；tick `1..65` 的输出依次为
`A^1*seed .. A^65*seed`。这条路线的状态路径组合预算为 4 delay，seed 路径组合预算为
8 delay；输出控制本身到达时间为 4，不会超过总延迟 8。

### 到达时间规则

静态运行时证据使用以下传播规则：

```text
component arrival = max(all input arrivals) + component delay
```

- `Architecture Input` 把 control 到达时间原样传播到 value，不额外增加延迟；
- `Architecture Output` 的终端到达时间取 control/value 的最大值，不额外增加延迟；
- `Constant On` 的到达时间为 0，并允许合法扇出；
- `Delay Bit` 为 `5 gate / 4 delay`；
- `Bit Switch` 为 `2 gate / 1 delay`；
- 普通 XOR 与 U1 Word XOR 都必须按 `3 gate / 2 delay` 计费。

### 独立重放

`audit_constant_io_shells.py` 对 293 个 seed 重放两种协议，每个 seed 各检查 65 个输出，
并验证以下矩阵恒等式：

```text
B*T   = T*A
C65*T = A
C66*T = I
D     = T*(A+I)
```

两种协议各完成 `293 * 65 = 19045` 次输出比较，全部通过。脚本还校验当前安装 EXE 的
SHA-256 与已反编译计分表记录一致，避免用旧版本成本解释当前运行时。
