# 随机数持续种子对易基底边界

## 2026-08-03 / 研究：排除全部对易状态基的 8/9 延迟 XOR2 实现

### 结论

对 65 周期和 66 周期的持续 seed 仿射状态机，若状态编码 `T` 与自然 xorshift32
变换 `A` 对易，则任何只使用普通二输入 XOR 的组合 DAG 都不可能达到总延迟 8 或 9。

这是一族一般性反证，不只针对某个具体矩阵。它覆盖：

- `T=A^k` 的全部循环重定时；
- `T` 为 `A` 的可逆多项式；
- 特别简洁的 `T=(A+I)^-1`；
- 其它任何满足 `T*A=A*T` 的可逆状态基。

因此后续普通 XOR2 搜索必须使用不与 `A` 对易的状态基。该结论不排除一延迟双轨 Switch
奇偶宏、跨输出非线性消去、冗余状态或其它非 XOR2 拓扑。

### 持续 seed 状态方程

两种常开协议共享反馈方程：

```text
q_next = B*q XOR D*seed
B      = T*A*T^-1
D      = T*(A+I)
```

65 周期直接从 tick 0 输出：

```text
output65 = A*T^-1*q XOR A*seed
```

66 周期用一只 ready Delay 抑制 tick 0：

```text
output66 = T^-1*q XOR seed
```

无论选择哪个输出协议，反馈路径都相同，所以只需在 `B/D` 中找到一个不满足到达时间的
状态行即可同时否决两种协议的 XOR2 实现。

### 混合 Kraft 必要条件

状态 Delay 输出到达时间为 4，持续 seed 到达时间为 0，普通 XOR2 的延迟为 2。在总延迟
8 或 9 内：

- 一个状态叶最多再经过 2 个 XOR；
- 一个 seed 叶最多再经过 4 个 XOR。

把共享 DAG 展开成二叉公式，任一反馈目标行必须满足：

```text
wt(B_i) / 4 + wt(D_i) / 16 <= 1
```

等价整数形式为：

```text
4*wt(B_i) + wt(D_i) <= 16
```

共享不能逃避该条件：每个目标所需的独立线性叶必须以奇数次出现；展开共享只会复制叶，
消去路径也不会降低必要叶的 Kraft 负载。

### 对易基底的解析反证

若 `T*A=A*T`：

```text
B = T*A*T^-1 = A
```

当前 xorshift32 矩阵 `A` 的行权分布为：

```text
weight 3:  5 rows
weight 4: 12 rows
weight 5:  3 rows
weight 6: 10 rows
weight 7:  2 rows
```

另一方面，`A+I` 可逆；`T` 也按状态编码要求可逆。因此：

```text
D = T*(A+I)
```

必然可逆，每一行至少含一个 seed 叶。于是所有 27 个 `wt(A_i)>=4` 的反馈行均满足：

```text
4*wt(B_i)+wt(D_i) >= 4*4+1 = 17 > 16
```

任取一行即构成严格时序反证。共有 27 个独立见证，不依赖门数预算，也不依赖某个启发式
综合结果。

### 简洁基底为何仍然失败

取：

```text
T = (A+I)^-1
```

可以得到非常简洁的代数形式：

```text
B   = A
D   = I
C66 = A+I

q_next  = A*q XOR seed
output66 = (A+I)*q XOR seed
         = q_next XOR q
```

该结构从零状态开始完全正确：tick 0 捕获 `q=seed` 并抑制输出；tick 1 至 65 依次输出
`A*seed .. A^65*seed`。但每个反馈行仍包含一个 seed 叶，`A` 的 27 个重行无法在状态到达
时间 4 之后用两层 XOR2 完成。因此“方程项数少”不等于满足实际关键路径。

同一基底的 65 周期输出为：

```text
C65 = A*(A+I)
```

脚本对 293 个 seed 分别重放两种协议，各检查 `293*65=19045` 个输出，全部正确；失败点只在
物理 XOR2 延迟，而不是协议数学。

### 后续范围

普通 XOR2 的有效搜索范围现已缩小为：

```text
T*A != A*T
```

并且必须同时满足全部反馈和输出行的混合 Kraft 条件。高阻 Switch 路线仍开放，但必须使用
真实的 `(value,is_z)` 总线模型；一个 affine Switch 不能凭 2 gate 生成新的线性行，真正
有意义的是用双轨以 4 gate / 1 delay 换取更短路径。后续应联合优化非对易 `T`、普通 XOR
节点数和少量必要的快速 Switch 奇偶节点，而不再扫描 `A` 的幂或其它对易多项式基底。
