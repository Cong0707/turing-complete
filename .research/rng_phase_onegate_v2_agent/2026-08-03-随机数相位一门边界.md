# 随机数相位一门边界

日期：2026-08-03

## 结论

在已实机通过的 `402 / 9 / 67` 固定数据面内，下面这部分已经达到严格门数下界：

```text
47 mode OR                         47 gate
2 phase Delay Bit                 10 gate
phase OR + NOT                     2 gate
                                    -------
mode + phase                       59 gate
```

不存在把它降到 `58` 门的合法原生实现，因此不能靠相位控制或与一个 mode OR 共用元件得到
`401 / 9 / 67`；要求净省两门同样不可能。固定数据面的完整下界正好等于当前成绩：

```text
32 state Delay Bit               160
61 XOR @ 3                       183
47 distinct mode functions        47
2 phase Delay Bit                 10
minimum phase combinational        2
                                    ---
strict total                      402 gate
```

本轮没有生成候选电路，因为没有比现有电路更小的可构造网表；没有启动游戏，也没有读取或
修改正式存档。

## 协议与状态下界

67 周期协议要求控制端逐拍为：

```text
tick 0       Input=0, Output=0
tick 1       Input=1, Output=0
tick 2..66   Input=0, Output=1
```

三个控制对彼此不同。一个确定性单比特状态机至多有两个状态，所以无论组合门多强，都至少
需要两个存储位。当前 Delay Bit 是 `5 gate / 4 delay`；U2 Delay Word 也是 `10 gate / 4
delay`，打包没有折扣。因此状态存储至少已经使用 `10 gate`，若总控制器要降到 `11 gate`
就只剩一个门。

初态固定为 `00`。两位状态的单一稳态编码共有六种：

```text
(idle, load, steady)
000,001,010   000,001,011
000,010,001   000,010,011
000,011,001   000,011,010
```

机器证书没有只检查这六种编码。它枚举完整转移接线，并允许第四个编码参与稳态循环；只要
从零初态出发的可达轨迹满足控制协议就会被接受。因此没有遗漏“双稳态编码轮换”一类方案。

三位存储的零初态编码共有 `7 * 6 = 42` 个不同的 load/steady 有序选择，但仅存储已经需要
`15 gate`，严格超过当前控制器的 `12 gate`，所以全部由成本下界直接排除。U3 Delay Word
同样是 `15 gate`，不存在打包捷径。

## 一门原生元件完整枚举

在两个 Delay 之后，`<=11 gate` 只允许零门或一个一门元件。当前可用且成本不超过一门的
逻辑全集是：

- 常量、直连、Maker、Splitter：零门，不产生新谓词；
- Bit NOT、AND、NAND、OR、NOR：一门、单输出；
- 对应 U1 Word 门：同一真值函数，不增加新情况；
- Decoder1：`1 / 1`，输出原始选择位的正反两相。

脚本对所有门输入从 `{0,1,q0,q1}` 取值、所有寄存器输入和两个端口控制从全部可用输出取值，
共枚举：

```text
physical topologies       49
wiring assignments     32940
SAT                         0
```

逐类分配数：

```text
no gate        256
NOT           2500
Decoder1      5184
AND           6250
NAND          6250
OR            6250
NOR           6250
```

Switch Bit 是 `2 / 1`，AND3/OR3 是 `2 / 2`，普通 XOR 与 U1 Word XOR 均是用户实机确认的
`3 / 2`；它们在放置前就已超过一门余量。当前档案中的 Decoder2 是 `11 / 2`，Decoder3 是
`79 / 12`，再加十门状态存储后也不可能改善。U2 按位门至少按两个独立 lane 计两门，不能
用 Maker/Splitter 获得折扣。

### 两个理想模型为何不能当候选

为了检查枚举边缘，脚本还故意加入了游戏中不存在的元件：

1. 任意单输出一门 LUT 会选择 `f=q0 AND NOT q1`，使用
   `q0'=1, q1'=q0, Input=f, Output=q1`，得到 `00 -> 01 -> 11 -> 11`；
2. 任意一门双相 LUT 会同时输出 `NOR(q0,q1)` 和 `OR(q0,q1)`，恰好复现当前控制器。

这两个 SAT 结果不是候选，而是精确指出缺少的物理能力。第一个 minterm 需要 NOT+AND 两门，
或使用当前成本 11 门的 Decoder2；第二个需要 OR+NOT 两门。Decoder1 只能对一个原始选择位
给出 `x/NOT x`，不能对任意二输入函数同时给出正反相。精确原生枚举已经单独覆盖 Decoder1
的两个输出并得到 UNSAT。

## 当前两门见证

令两个零初态 Delay 输出分别为 `p`、`o`：

```text
a  = p OR o
p' = NOT a
o' = a

Input.control  = p
Output.control = o
```

逐拍证书：

| tick | `(p,o)` | `a` | `(p',o')` | Input | Output |
| ---: | :---: | ---: | :---: | ---: | ---: |
| 0 | `00` | 0 | `10` | 0 | 0 |
| 1 | `10` | 1 | `01` | 1 | 0 |
| 2 | `01` | 1 | `01` | 0 | 1 |
| 3.. | `01` | 1 | `01` | 0 | 1 |

控制最长路径是 `Delay 4 + OR 1 + NOT 1 = 6`，远低于九延迟限制。结合一门边界 UNSAT，
控制器的精确最小值就是 `12 gate`。

## 47 个 mode OR 不能与控制器共门

固定数据面中的每个 mode 输出为：

```text
M(i,j) = seed_i OR q_j
```

装载拍 `q=0`，所以 `M(i,j)=seed_i`；稳态 Architecture Input 关闭，其数值面为零，所以
`M(i,j)=q_j`。证书中的 47 个 `(i,j)` 全部不同，编码矩阵 `T` 的 GF(2) 秩为 32：

- 若 `i` 不同，在装载拍用单位 seed 即可区分两个函数；
- 若 `i` 相同而 `j` 不同，`T` 可逆意味着稳态坐标 `q_j`、`q_k` 独立；
- 因而两个 mode 函数相同，当且仅当两个配对完全相同。

每个普通门只有一个逻辑输出。U2/U3 Word OR 的计费按 lane 线性增长，不比两个/三个 Bit OR
更便宜。Decoder1 虽有两个输出，但它们互补；所有 mode 函数在全零数据点都为 0，所以任意
两个 mode 函数都不可能是一对互补输出。Switch 只有一个三态输出且每只两门，更不可能降低
47 门下界。故 mode bank 至少需要 47 门，当前 47 个 OR 已达到该下界。

联合共享还有一个更直接的必测反例。对 `seed=0`：

```text
seed = 0
q = 0 forever
all 47 mode outputs = 0 forever
all fixed XOR data outputs = 0 forever
```

Architecture Input 关闭时是 Z，开启并读取零种子时是主动 0，但普通门只能读取数值面零，
不能读取 `_is_z`。多驱动网络要么仍得到已有数值，要么发生短路；短路不能作为合法逻辑。
因此在零种子测试中，借给控制器的任意 mode 输出都只是常量零。

若 mode bank 仍用最少的 47 门，而联合方案只允许一个额外私有门，则零种子时必然退化为
“两个零初态 Delay + 一个合法原生门”的控制器，已被 32940 项完整枚举判为 UNSAT。于是
控制器所需的两门不能计入 47 个 mode 门，联合下界为：

```text
47 + 10 + 2 = 59 gate
```

这也排除了净省一门；净省两门当然不可能。

## 范围边界

严格结论只覆盖：

- 当前 32 位编码状态和 61-XOR 固定数据面；
- 47 个 mode-pair 函数保持现有语义；
- 所有 Delay 初态为零；
- 67 周期 `00,10,01...` 协议；
- 当前合法原生元件、真实成本和高阻语义。

它不排除改变状态编码、改变 XOR DAG、65/66 周期持续 seed 递推，或设计全新的三态数据宏。
因此后续算力应离开固定 402 外壳，转向 65 周期常开 I/O 和 66 周期八延迟结构。
