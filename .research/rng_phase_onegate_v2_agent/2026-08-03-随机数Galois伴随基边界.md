# 随机数 Galois 伴随基边界

## 2026-08-03 / 研究：排除两族最稀疏反馈基的普通 XOR2 八延迟实现

### 结论

对 66 周期持续 seed 状态机：

```text
q' = B*q XOR D*seed
y  = C*q XOR seed
```

正向和反向 Galois 循环基都能把 `B` 压到每行至多两个状态输入：

```text
K+(v) = [v, A*v, ..., A^31*v]
K-(v) = [v, A^-1*v, ..., A^-31*v]
T     = K^-1
B     = T*A*K
C     = K
D     = T*(A+I)
```

两族的 `B` 都只有 `41` 个矩阵非零元，行权最大值为 `2`。然而，对每族全部可能的循环
向量 `v` 做精确枚举后，没有一个成员能让输出矩阵 `C` 满足普通 XOR2 的八延迟必要条件。

```text
每族必须检查的 v       5488
满足全部输出行的 v        0
最接近者的超限输出行     30 / 32
最接近者最大 C 行权       23
```

因此，“把反馈直接化成行权 1/2 的 Galois LFSR”不能生成普通 XOR2 的 66 周期八延迟候选。
这解释了为什么只优化 `B` 会把复杂度几乎完整地推入 `C/D`，而没有解决实际关键路径。

本结论不排除真实 Bit Switch/Z 共识 cover；它也不排除非伴随形的其它非对易基、冗余状态或
非线性可达态编码。

### 八延迟必要条件

状态 Delay 输出到达时间为 `4`，持续开启的 seed 到达时间为 `0`，普通 XOR2 是
`3 gate / 2 delay`。把任一共享 XOR DAG 展开成二叉公式后，输出行：

```text
y_i = parity(C_i*q) XOR seed_i
```

必须满足混合 Kraft 条件：

```text
wt(C_i)/4 + 1/16 <= 1
4*wt(C_i) + 1 <= 16
wt(C_i) <= 3
```

反馈行同理必须满足：

```text
4*wt(B_i) + wt(D_i) <= 16
```

这些条件允许共享；共享节点展开时只会复制叶，不能让一个目标所需的独立线性叶消失。

### 为什么只需枚举 5488 个成员

当前 xorshift32 的特征多项式是 32 次不可约本原多项式：

```text
x^32 + x^21 + x^20 + x^19 + x^18 + x^17
     + x^15 + x^14 + x^9 + x^6 + 1
```

所以任意非零 `v` 都是 `A` 和 `A^-1` 的循环向量。对正向或反向任一族，映射：

```text
v -> row_0(K(v))
```

都是一个可逆的 32 位线性映射。任何可能通过输出时序的成员都必须先满足
`wt(row_0(C)) <= 3`，因此只需枚举：

```text
C(32,1) + C(32,2) + C(32,3)
= 32 + 496 + 4960
= 5488
```

个非零首行，再通过逆映射唯一恢复 `v`。脚本随后构造完整 32 行 `C` 并逐行检查，所以这
不是随机抽样，也没有漏掉同一伴随族中的其它循环向量。

### 最接近见证

正、反两个方向在当前字典序目标下得到相同的重量统计：

```text
C total weight               497
C maximum row weight          23
C rows over weight 3          30
B total weight                41
D total weight               501
feedback Kraft violations     26
feedback maximum metric       28
```

即使忽略输出障碍，`D` 也重新变成近似稠密矩阵；伴随形只是在三个矩阵之间转移复杂度。

### Switch/Z 边界

这份证明只覆盖普通二输入 XOR DAG。Bit Switch 可以用非线性 enable 和多驱动共识总线在
较浅延迟内计算奇偶函数，因此 `wt(C_i)>3` 不能直接否决任意 Switch 电路。但最接近成员的
30 个稠密输出行说明，若继续这一族，必须为几乎整个输出面建立大规模三态 parity cover；
这与 `<=292 logic gate` 的 66 周期目标严重冲突。后续 Switch 搜索应优先使用已经保持
`C` 每行至多 3 的非伴随非对易基，而不是再从 Galois 伴随基开始。
