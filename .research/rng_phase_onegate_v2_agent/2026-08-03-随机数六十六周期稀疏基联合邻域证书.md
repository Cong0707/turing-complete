# 随机数六十六周期稀疏基联合邻域证书

## 2026-08-03 / 提交：研究：把持续种子八延迟前沿推进到三个超限行

### 范围

本轮只研究最新版 RNG 的 66 周期持续 seed 线性协议，没有启动游戏，也没有读取或修改
正式存档。所有结果都是八延迟的必要时序筛选，尚不是物理 XOR/Switch DAG，更不是可提交
成绩。

令 `A` 为游戏使用的 xorshift32 变换：

```text
x ^= x >> 13
x ^= x << 17
x ^= x >> 5
```

采用：

```text
q' = B*q XOR D*seed
y  = C*q XOR seed

T0 = C^-1
B  = T0*A*C
D  = T0*(A+I)
```

状态到达为 4、seed 到达为 0、普通 XOR2 延迟为 2 时，八延迟必要条件为：

```text
feedback: 4*wt(B_i) + wt(D_i) <= 16
output:   4*wt(C_i) + 1       <= 16
          wt(C_i)             <= 3
```

这里的 `over` 是违反 feedback 条件的行数，`excess` 是所有超限量之和。条件满足仍不代表
存在门数 `<=292`、无 BUS/Z 冲突的共享物理网表。

### 前沿推进

```text

wt(B)+wt(D)=193
wt(C)=68
max wt(C_i)=3
```

`audit_structured_shear_66.py` 重新验证了四条矩阵恒等式，并对 344 个 seed、每个 65 个
输出共 22360 拍逐拍重放通过。随后完整扫描每一行的 5488 个非零权重 1..3 向量，第二轮
单行坐标下降得到 `over=7/excess=45/max=30`。

两个独立搜索方向之后分别给出不同的 `over=3/excess=20/max=34` 中心。本轮将两者导入
自己的验证器重新推导，而不是信任来源日志：

```text

两者共同：

```

两个中心都完成 344 seed、22360 输出的独立逐拍重放。它们的三个坏行直接敏感输出坐标


### 结论与下一步

`over=3` 已经是多个大型局部邻域的共同严格极小值，继续做相同的单行或普通双行退火
收益很低。下一步保留三条互补路线：

1. 用 GF(2) Woodbury 公式完整枚举“单步奇异、双步联合可逆”的 rank-2 修复；
2. 在 16 个敏感坐标上做 rank-3 复合移动，并以坏行 16 的 `metric=34` 为预筛选；
3. 不再强迫所有行通过普通 XOR mixed-Kraft，用真实 Bit Switch 的高阻态直接综合三个
   残余行，显式检查无向 BUS、Z 传播、短路和最终 `logic<=292` 门预算。

## 2026-08-03 / 提交：研究：完整封闭十六敏感坐标的全部 rank-2 替换

继续用 GF(2) Woodbury 公式补齐前一节没有覆盖的两个象限。每个目标行有 5488 个非零
权重 1..3 向量，排除原行后有 5487 个替换；16 个敏感坐标共有 120 个坐标对。因此每个
中心的完整双行空间为：

```text
C(16,2) * 5487^2 = 3612860280
```

按两次 rank-1 替换的单独可逆性分成三个互斥象限：

```text
regular / regular：  101556491 raw，96328270 最终可逆
singular / singular：2490870641 raw，65017330 联合可逆
mixed：              1020433148 raw，31534050 联合可逆
----------------------------------------------------------------
合计：               3612860280 raw，192879650 联合可逆
```

三类 raw 计数精确等于理论全集；两个独立 `over=3` 中心的计数完全一致。对 singular 与
mixed 各抽取最先 4096 个联合可逆候选，将 Woodbury 增量行指标与完整求逆、完整矩阵乘法
逐行比较，全部一致。每个中心的 192879650 个最终可逆候选均没有改善 `3/20/34`。

这严格封闭了两个中心上、16 个直接敏感坐标内的全部双行稀疏替换；仍不外推到其余 16
坐标、三行替换、不同状态维数或真实 Switch/Z 非线性网络。
