# 样本 B 分裂负进位 reason 对 83 门联合尾的替换审计

日期：2026-08-05

## 一、结论

`Switch 103/5 B` 的两条负进位 reason 是真实且可复用的：

```text
K45 = NOT D45                         @3
R1  = NOT(C4 OR G4 OR G5)             @4  # 依赖样本 B 的 C4@3

NOT C6 = K45 OR R1
```

在当前 Patchouli `84/6` 主干上，同一条 `R1` 也可以不经过迟到的 `C4@4`，直接写成：

```text
R1 = NOR(B23,G345)                    1 gate @4
```

固定 `162` 个合法的 `{C4, bit4..bit7(K/P/G)}` 状态复核证明：

```text
K45 OR R1 == NOT C6                   mismatch 0
样本 B S5/S6/S7/C8                    mismatch 0
四个 BUS owner                        conflict 0
```

但这套分裂 reason **不能**替代此前公开 `E6@3 -> nC6@4` 的联合尾 producer，
也不能把当前 `84/6` 变成 `83/6`。决定性原因不是功能，而是消费者成本：只计算
`S5`、`S6` 和两条 reason，尚未重画 `S7/C8`，就已经比现图多九门；即使极端乐观地
假设旧四门 `C6` owner 可以无条件删除，仍然净增五门。

## 二、来源边界

样本 B 的完整反解证据位于：

```text
.research/byte_adder_frontier_samples_20260805/analysis_103d5b/
```

其真实节点为：

```text
V45 = NOR(Q4,Q5)                      @2
D45 = OR(V45,G5)                      @3
K45 = NOR(V45,G5)                     @3

E45 = OR(G4,G5)                       @2
R1  = NOR(E45,C4)                     @4  # C4@3

C6 = BUS(
  SW(E45,D45),
  SW(C4,D45)
)                                       @4
```

因此：

```text
C6  = D45*(C4 OR G4 OR G5)
nC6 = nD45 OR NOT(C4 OR G4 OR G5)
     = K45 OR R1
```

若直接把样本 B 的 `R1` 接到当前 Patchouli `C4@4`，arrival 会变成 `@5`。本审计已经
给它最有利的条件，使用当前已有的等价早式：

```text
R1 = NOR(B23@3,G345@3)                @4
```

所以后面的否决不是因为错误地把 `R1` 算晚了一层。

## 三、S5 的固定替换账本

Patchouli 当前五门 S5：

```text
U45 = OR(B23,K34)
H5  = NOR(Q4,P5)
T5  = AND(U45,H5)
J5  = NOR(Q5,C6)
S5  = OR(T5,J5)                        5 gate / D6
```

样本 B 使用三只 Switch：

```text
S5 = BUS(
  SW(Q4,P5),
  SW(H5,U45),
  SW(R1,P5)
)                                       6 gate / <=D5
```

这里用 Patchouli 的 `U45=C4 OR G4` 即可；在 `H5=1` 的 care domain 上，样本 B 的
`C4 OR nP4` 与它等价。三态冲突复核为零。

但完整账本是：

```text
旧：U45 + H5 + T5 + J5 + final OR       5
新：U45 + H5 + three-Switch owner        8
------------------------------------------------
delta                                   +3
```

`R1` 还没有计入这三门差额。

## 四、S6 的固定替换账本

Patchouli 当前只公开 `nP6=G6 OR Q6`，再用三门 XNOR 相位得到 S6：

```text
A6 = OR(C6,nP6)
B6 = NAND(C6,nP6)
S6 = NAND(A6,B6)                       3 gate
```

样本 B 直接消费分裂 reason：

```text
P6 = NOR(G6,Q6)                        +1 gate

S6 = BUS(
  SW(K45,P6),
  SW(R1,P6),
  SW(C6,nP6)
)                                       6 gate
```

三路分别实现：

```text
P6*K45
P6*R1
nP6*C6
```

`K45/R1` 重叠时 data 同为 `P6`，而 `C6` 与任一负 reason 互斥，所以 BUS 冲突为零。
代价却是：

```text
旧 S6 tail                             3
新 P6 + three-Switch owner              7
------------------------------------------------
delta                                   +4
```

## 五、S5/S6 已经封死预算

两条 reason 本身需要：

```text
K45                                      1
R1                                       1
```

所以在还没有触碰 `S7/C8` 前：

```text
K45/R1                                  +2
S5                                       +3
S6                                       +4
------------------------------------------------
subtotal                                 +9
```

此前公开因子联合尾之所以有机会，是因为：

```text
E6@3 -> nC6=NAND(D45,E6)@4
```

只支付一只普通门，就让 `S5/S6/Z7` 继续使用原来的两层后处理。分裂 reason 没有完整
`nC6@4`；为了绕开合流延迟，必须把每个消费者复制成额外 Switch driver，门数迅速增加。

即使做一个实际上不成立的极端乐观假设：

```text
删除旧 C6 two-Switch owner              -4
```

仍有：

```text
+9 - 4 = +5
```

而且删除 `C6` 后，S6 的第三只正相 driver、S7 的正相 cofactor 和 C8 的正相 enable 都
失去公共输入；必须分别从 `D45/E6` 重新复制正相 owner，实际只会更贵。因此这个 `+5`
已经是偏袒样本 B 的下界，不是可构造候选的真实总成本。

## 六、完整样本 B 高尾只会更贵

为了确认没有在 `S7/C8` 中藏着足以抵消九门的收益，本审计也固定复刻了样本 B 的联合
高尾：

```text
S7 = BUS(
  SW(K45,L7),
  SW(R1,L7),
  SW(C6,F7)
)

C8 = BUS(
  SW(M7,B8),
  SW(C6,B8)
)
```

其中：

```text
F7 = XNOR(Q6,P7)
L7 = XOR(G6,P7)
M7 = G6 OR nP7
B8 = G7 OR (P7*NOT Q6)
```

这部分功能与 BUS 冲突全部通过，但完整高尾为 `30` 门，而 Patchouli 当前为 `20` 门。
因此，把分裂 reason 的全部消费者照搬到 D6，相关切口为：

```text
Patchouli:
  current C6 core                       8
  S5                                    5
  high tail                            20
  total                                33

split-reason transplant:
  current C6 core                       8
  K45/R1                                2
  S5                                    8
  B high tail                          30
  total                                48

delta                                 +15
```

样本 B 的价值是以门换延迟得到 `103/5`，不是在 D6 边界下压门。

## 七、样本 B 自身 C4/C6 交易也不能补偿

样本 B 的 C6 core 在已经拥有 `C4@3` 时确实局部省一门：

```text
当前 C6 core                            8
样本 B C6 core                          7
delta                                  -1
```

但它的 `C4@3` producer 比当前 `C4@4` producer 多三门：

```text
当前 C4 producer                        6
样本 B C4 producer                      9
delta                                  +3
```

所以：

```text
current C4+C6                           14
B C4+C6                                 16
delta                                   +2
```

再公开 `K45/R1` 后，边界已经净增四门，尚未计算任何输出 owner。它同样不能替代
`E6@3/nC6@4` producer。

## 八、最终判断

```text
功能正确                                是
BUS conflict                            0
R1 最有利 arrival                       @4
最大输出 arrival                        <=D6
相对 84 净省至少一门                    否
可物化 83/6                             否
```

应保留的研究价值只有两点：

1. `nC6=K45 OR R1` 是正确的双 reason 分解，可用于追求 D5 的输出 owner。
2. 样本 B 的 `S7` 内部 cofactor 与 `C8` 有真实跨输出共享。

对当前 `84/6 -> 83/6` 目标，不应继续把 `K45/R1` 当成 `nC6@4` 的廉价替代；下一步仍
必须让上游直接公开完整 `E6@3`、完整 `nC6@4`，或找到能同时改写 `S5/S6/S7/C8`
且总增量不超过三门的新状态编码。
