## 成本分区完备性

exact cost 9 的非负整数方程是：

```text
o + 2s + 3x = 9
o,s,x >= 0
```

因为 `x=0..3`；固定 `x` 后，`s=0..floor((9-3x)/2)`，而
`o=9-2s-3x` 被唯一确定，所以全部解恰为：

```text
x=0: (o,s,x) = (9,0,0) (7,1,0) (5,2,0) (3,3,0) (1,4,0)
x=1:           (6,0,1) (4,1,1) (2,2,1) (0,3,1)
x=2:           (3,0,2) (1,1,2)
x=3:           (0,0,3)
```

总数为 `5+4+2+1=12`。证据分区是：

```text
(9,0,0)       root task 的 all-ordinary 未分片主结果
其余 11 项     strict value/driven worker 的双求解器结果
```

两组没有重叠，合并后也没有缺项。完整合并器从方程独立重新枚举 12 项，再与 n9 加 11 个
mixed case 做集合相等检查；不是手工宣称列表完整。

## 32 行与 36 行为何可合并

n9 root model 使用 `32` 个 Boolean truth-table assignments；它不是 36 行 strict
value/driven 投影。为了避免把两个模型无条件等同，完整合并器从当前权威 DAG 重新计算了
投影关系：

```text
full rows                              131072
strict (value,driven) signatures       36
n9 Boolean assignments                 32
unique Boolean boundary signatures     24
unique root boundary signatures        24
authoritative Boolean map == root map  true
```

24 个 Boolean boundary signatures 中，12 个只有一种 driven variant，另 12 个各有两种，
因此 strict signature 总数为 `12*1 + 12*2 = 36`。C1/C3 的 Z 行统计为：

```text
source  Z rows  value=1 while Z
C1      49152   0
C3      36864   0
```

对 `(9,0,0)` 纯 ordinary 网络，二者等价的理由必须同时满足：

1. active-bus normalization 使任一被选 ordinary 输入/输出 BUS 为 singleton；
2. ordinary component output 永远 driven；
3. 权威 C1/C3 在 undriven 行的 value bit 都是 0，所以 singleton ordinary 输入看到的 Z0
   与 D0 Boolean 值相同；
4. 权威 DAG 的 value-only boundary-to-target map 与 n9 的 32-assignment truth-table map
   精确相等，且两个 target 都由 Boolean boundary signature 唯一决定。

所以 n9 Boolean UNSAT 可封闭 all-ordinary 项。该等价论证**不外推到 Switch 分解**：Switch
会观察 driven/Z 状态，故所有含 Switch 的 case 都由 36 行 strict worker 直接求解。含 XOR
但无 Switch 的 case 也保守地留在 strict mixed 族中，没有借投影论证扩大 n9 范围。

## 严格边界

本结果只证明显式 retained-source pool `{a1,b1,G1,G2,V2,C1,C3}` 下，联合目标
`{S1@4,S2@7}` 的 exact weighted-cost9 不可实现。它：

- 不联合重综合 retained boundary；
- 不允许改变 paid-source shell；
- 不覆盖其它跨输出切口或更广的共享拓扑；
- 不是完整 80 门 DAG 的全局一门下界；
- 不能单独推出全局 `79/7` UNSAT。

继续寻优仍需选择其它全局 cut、改变 retained shell，或做更大范围的联合重综合。

candidate/metadata，也没有生成 graft。
