# 80/7 Byte Adder S0/S6 混合成本 3 根替换完整封闭

日期：2026-08-04

## 结论

在权威 `80/7/560` DAG 的两个私有四门根 `S0`（node 49）与 `S6`（node 73）上，固定
既有 reviewed retained-source pool、精确 source value/driven masks 与 D7 deadline，
exact weighted-cost 3 的全部可实现 primitive 分解均已封闭：

```text
o3       ordinary x3                         既有完整枚举 0 hit
o1+s1    ordinary x1 + Switch x1            双求解器 UNSAT
x1       XOR x1                              双求解器 UNSAT
```

库成本为 `ordinary=1, Switch=2, XOR=3`，所以非负整数成本分解只有上述三项。结合既有
`o3` 结果，两个固定局部接口下都不存在把当前四门私有根降为成本 3 的等价 DAG。

没有 SAT、UNKNOWN 或求解器分歧，没有产生候选、graft 或完整 79 门 DAG。该结论只属于
固定 retained pools，不是全局 `79/7` 下界。

## 搜索范围

本轮复用 reviewed physical BUS encoder 与 S2/S4 审计中独立审阅的完整 mask replay：

- ordinary kinds 为 `NOT/AND/OR/NAND/NOR`；
- synthesized Switch 输出允许 Z，最终 `S0/S6` 在全部 131072 行必须 driven；
- 相同完整 physical BUS driver set 可以复用；
- 任意两个 BUS 的 driver set 若相交则必须完全相同，禁止 partial overlap；
- 所有 synthesized components 必须 live；
- source arrival 与 primitive delay 递归约束最终 arrival 不超过 7；
- 每次 CNF build 从 pristine truth-table 模板开始，避免通用 core 原地追加常量 alias；
- SAT witness 只有通过完整 `131072`-bit value/driven 独立重放后才会被报告。

`o1+s1` 的两个 component kind 没有固定 slot 顺序，因此同时覆盖 ordinary 在 Switch 前与
Switch 在 ordinary 前的全部合法 DAG。`x1` 覆盖单个 XOR primitive 的全部 retained-source
输入选择。既有 reviewed `audit_80d7_three_gate_roots.py` 覆盖全部 live 三 ordinary
chain/fanout/parallel 拓扑。
