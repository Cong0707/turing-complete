# 80/7 Byte Adder S2/S4 混合成本 4 根替换完整封闭

日期：2026-08-04

## 结果

在已验收 `80/7/560` DAG 的两个私有五门根 `S2`（node 81）与 `S4`（node 86）上，
固定各自经过审阅的 retained-source pool、精确 source value/driven masks 与 D7 deadline，
对 exact weighted-cost 4 的全部可实现 primitive 分解完成封闭：

```text
o4       ordinary x4                         双求解器 UNSAT
o2+s1    ordinary x2 + Switch x1            双求解器 UNSAT
s2       Switch x2                          双求解器 UNSAT
o1+x1    ordinary x1 + XOR x1               双求解器 UNSAT
```

其中 `o4` 由 `.research/byte_adder_root/audit_80d7_four_gate_dag_sat.py` 的 CaDiCaL 195
与 Glucose42 两份既有结果封闭；本轮审计器覆盖余下三种混合分解。两个目标、三个混合
分解在 CaDiCaL 195 与 Glucose42 下均为严格 UNSAT，没有 SAT、UNKNOWN 或求解器分歧。
因此在这两个**固定局部接口**下，原五门根不存在成本 4 的等价替换。

没有产生新候选、graft 或完整 79 门 DAG。该结论不是全局 `79/7` 下界。

## 编码范围

本轮复用 reviewed physical BUS encoder，约束包括：

- ordinary kinds 为 `NOT/AND/OR/NAND/NOR`；
- `Switch` 中间输出允许 Z，最终 `S2/S4` 在全部行必须 driven；
- 相同完整 physical BUS driver set 可以复用；
- 两个 BUS 的 driver set 若相交，必须完全相同，禁止 partial overlap；
- 全部 synthesized components 必须 live；
- component arrival 递归受 source depth 与 primitive delay 约束，最终 arrival 不超过 7；
- SAT witness 必须独立用完整 `131072`-bit value/driven masks 重放后才可报告。

`o1+x1` 同时包含 XOR 后接 ordinary NOT 的 XNOR 结构。按库成本
`ordinary=1, Switch=2, XOR=3`，成本 4 的非负整数分解只有上述四项；因此与既有 `o4`
结果合并后，固定 pool 下的 exact weighted-cost 4 已完整覆盖。
