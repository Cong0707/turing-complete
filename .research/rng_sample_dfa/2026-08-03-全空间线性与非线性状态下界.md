# RNG 全空间线性与非线性状态下界

## 结论

本报告覆盖全部 `2^32` 个 seed，不是针对关卡的 256 个样本拟合。

1. xorshift32 的一步转移矩阵 `A` 在 `GF(2)` 上满秩 32。
2. `A` 的特征多项式为 `0x1003ec241`，且在 `GF(2)` 上不可约。
3. 对 `p=1..65`，机器计算均得到 `rank(A^p + I)=32`。
4. 任意分离表达式

   ```text
   y(phase, seed) = XOR_i g_i(phase) * M_i(seed)
   ```

   至少需要 32 个非零 word-linear 项。
5. 若 seed 只读取一次、随后彻底关闭输入，任意布尔状态机在首次输出前至少需要 33 个二值状态位。

这些是搜索边界，不是一份可落盘电路，也不是对任意三态顺序网络的全局不可行证明。

## 精确转移

关卡使用的 32 位变换为：

```text
x ^= x >> 13
x ^= (x << 17) & 0xffffffff
x ^= x >> 5
```

`full_space_linear_audit.py` 在 32 个单位 seed 上构造精确的 `32 x 32` 矩阵。因为目标本身是线性的，验证单位基等价于验证全部 `2^32` 输入。

矩阵证书：

```text
rank(A)                         = 32
charpoly(A)                     = 0x1003ec241
charpoly(A) irreducible over GF(2) = true
```

不可约性意味着由 `A` 生成的 32 维切片构成域 `GF(2)[A]`。在这个切片中，每个非零线性组合都是可逆的 32 位映射。

## 周期线性状态下界

若两个要求输出的时刻具有相同内部相位，间隔为 `p`，直接 seed 项在两次输出的差中抵消。差分必须经由数据状态传递，而目标差分包含因子：

```text
A^t (A^p + I)
```

证书对 `p=1..65` 全部算得秩 32。因此，只要协议中确实出现间隔 `p` 的重复相位，数据状态就不能少于 32 位。

重要边界：65 个必需输出只有 65 个相位点。对 65 周期机器，协议内没有第二次出现同一相位，所以 `p=65` 的代数结果不能直接变成该有限协议的状态下界。可直接使用的协议周期结论是 `p=1..64`。

## 相位与 seed 分离下界

把 65 个矩阵 `A^1..A^65` 沿“相位”和“输出位/seed 位”展平，其秩为 32。因此任何使用固定 word-linear 数据项、再由相位开关选择的分离方案，至少需要 32 项。

一个达到该代数下界的基是：

```text
A^1, A^2, ..., A^32
```

由于不可约性，这 32 项中的每个非零映射都是满秩变换。这个结论解释了为什么单纯寻找少量低秩、低成本线性支路不会突破现有前沿。

边界：该结论只约束“相位函数乘固定线性映射”的前馈分离族。共享多输出 DAG、带抵消的三态网络、非线性状态编码和跨拍重定时仍然开放。

## 一次读取 seed 的 33 位下界

假设：

- seed 只在装载拍可见；
- 之后输入开关关闭；
- 首次有效输出之前还有一个输出关闭的内部阶段；
- 所有控制均由机器内部状态产生。

首次必需输出为 `A(seed)`，而 `A` 是双射。因此两个不同 seed 在首次输出前不能落入同一内部状态，否则后续相同状态会产生相同输出。仅装载后的数据状态就至少需要 `2^32` 个不同值。

此外，输出尚未开始的预输出状态必须与全部已装载状态区分，否则某个 seed 会让控制轨迹混淆。状态数至少为：

```text
2^32 + 1
```

故二值状态位下界为：

```text
ceil(log2(2^32 + 1)) = 33
```

若 seed 在所有输出拍持续可读，这个计数证明不成立，不能拿 33 位下界排除 persistent-seed 方案。
