# 十二位仿射相位二次插值审计

## 目标

本实验检查一种非线性相位压缩路线：不用 65 位 one-hot 相位，而用 12 个 Delay Bit 产生至少 65 个不同相位，再以低次布尔函数解码 xorshift32 的 32 个相位系数。

所有恒等式覆盖全部 `2^32` seed。实验没有使用 RAM、没有启动游戏，也没有修改存档。

## 相位发生器

选用本原多项式：

```text
0x1053 = x^12 + x^6 + x^4 + x + 1
```

仿射递推：

```text
p' = (x * p mod 0x1053) xor 1
p0 = 0
```

机器验证结果：

```text
周期             = 4095
前 65 个状态唯一 = true
```

直接物理实现的门数账本：

```text
12 Delay Bit = 60 gate
3 U1 XOR     =  9 gate
1 NOT        =  1 gate
----------------------
相位外壳       = 70 gate
反馈最大到达   = 6 delay
```

其中 `U1 XOR` 严格按 `3 gate / 2 delay` 计价，不存在 1 门 XOR 假设。

## 二次特征满秩

12 位变量的常数、一次项和无平方二次项共有：

```text
1 + 12 + C(12, 2) = 79
```

在上述精确的 65 个相位点上，79 列特征矩阵满足：

```text
rank    = 65
nullity = 14
```

因此，任意定义在这 65 个点上的布尔函数都存在次数不超过 2 的插值。这是一条严格的表达能力结论。

对每个 xorshift 相位系数目标，脚本遍历其解空间中的全部 `2^14 = 16384` 个等价 ANF 表示，并按以下顺序选择：

1. 项数最少；
2. 二次项最少；
3. 平衡 XOR 树到达时间最短。

常量、线性相位位、二次项的输入到达时间分别按 `0 / 4 / 5` 计算；每层 U1 XOR 再增加 2 delay。

## 精确结果

32 个目标函数的最少项数直方图：

```text
18 项： 1 个
19 项： 1 个
20 项：10 个
22 项：19 个
26 项： 1 个
```

选中表示的朴素共享账本：

```text
共享二次 AND 特征        = 66 gate
各输出内部 U1 XOR       = 649 个
U1 XOR 门数             = 1947 gate
朴素相位解码合计         = 2013 gate
相位外壳 + 朴素解码      = 2083 gate
控制到 Switch 前最大到达 = 15 delay
```

这个数还没有包含：

- seed 线性预处理；
- 相位控制与 seed 数据的乘积/开关；
- 最终输出 XOR 网络；
- 输入输出控制；
- 物理布局。

因此该直接二次 ANF 方案在表达上完备，但在门数和延迟上明显不具竞争力，不能生成新的实机候选。

## 能排除什么

本实验只排除“12 位仿射相位 + 各目标独立最少项二次 ANF”的直接实现。它不能排除：

- 32 输出之间共享中间节点的多输出 DAG；
- 利用高阻态抵消的三态网络；
- 不同的非线性顺序状态编码；
- 相位逻辑与数据逻辑联合重编码；
- persistent-seed 架构。

后续若继续这条路线，必须直接优化共享多输出 DAG，而不是继续压单个 ANF 的项数。
