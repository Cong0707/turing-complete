# RNG 持续种子共享非最小 DAG 边界

日期：2026-08-03

## 结论

本轮没有得到可写入存档的候选。正确的持续 seed 模型为：

```text
q' = B*q XOR D*seed
y  = C*q XOR A*seed

C*T = A
T*C = B
D   = T*(A+I)
```

它与输入只开启一拍的 `T*A / A` 模型不同。本轮所有查询都直接约束
`[B|D; C|A]`，没有把两个协议混用。

为了让普通 XOR 网络在 8 delay 内完成，状态叶的到达时间为 4，seed 叶的到达时间
为 0，任意输出二叉树必须满足混合 Kraft 条件：

```text
4 * state_leaf_count + seed_leaf_count <= 16
```

当前需要击败的实测前沿为：

```text
402 * 9 * 67 = 242406
```

若持续 seed 方案按 `9 delay / 65 cycles` 计分，则必须做到：

```text
total gate <= 414
32 Delay Bit = 160 gate
logic gate <= 254
普通 XOR 最多 84 个
```

## 新中心与精确低秩边界

从已有全部 `mixed-kraft` JSONL 中去重后，找到一个此前未做定向扩展的更优中心：

```text
over rows  = 12
excess     = 92
maximum    = 34
standalone = 2763
weight     = 501
```

同分的另外三个记录只是 `T` 行集合的排列，即状态位重命名，不是新的电路结构。

先完整扫描 rank-1 与 rank-2；随后每一层从上一层求解时间最长的硬 UNSAT 边界继续加
一个自由 `C` 行。rank-3 至 rank-5 使用 32 个父状态，rank-6 至 rank-8 使用 16 个
父状态。所有查询均由 QF_BV Woodbury 低秩逆模型求解，内存上限 300 MB。

```text
rank 1：  32 /  32 UNSAT（完整）
rank 2： 496 / 496 UNSAT（完整）
rank 3： 840 / 840 UNSAT（定向）
rank 4： 829 / 829 UNSAT（定向）
rank 5： 842 / 842 UNSAT（定向）
rank 6： 409 / 409 UNSAT（定向）
rank 7： 391 / 391 UNSAT（定向）
rank 8： 375 / 375 UNSAT（定向）
----------------------------------
合计：  4214 / 4214 UNSAT
UNKNOWN：0
SAT：    0
```

这证明该中心的完整 rank-1/2 邻域以及记录的 rank-3..8 定向边界均无法满足逐行到达
必要条件。它不是全部 rank-3..8 组合的全局 UNSAT，更不是对任意 `T` 的全局反证。

## 共享 DAG 诊断

在忽略到达时间这一有利放松下，对相同中心运行 100 次随机化公共子表达式消元：

```text
best = 200 XOR
target = 84 XOR
```

这只是构造上界，不是 200-XOR 下界；但即使去掉最难的时序限制，当前中心仍离 84
XOR 很远。64 位 Boyar-Peralta C++ 运行工作集只有约 7 MB，但 90 秒内没有完成首轮，
已按墙钟限制停止，未把超时解释为不可满足。

另枚举 xorshift32 三个移位因子的长度不超过 6 的 1439 个不同乘积编码。最佳混合
Kraft 指标仍有 27 个超界行，明显差于退火中心的 12 个，因此没有继续投入精确 DAG。

## 后续方向

1. 不再沿这个固定中心继续无限增加低秩修复阶数。
2. 若全局搜索产生真正满足混合 Kraft 的 `[B|D; C|A]`，立即使用到达时间感知的共享
   DAG 综合器，并要求 `logic <= 254`。
3. 若共享 XOR2 DAG 超出预算，只能转向联合状态编码或给出具有真实 Z 语义和完整门表
   的三态网络，不能把逐行 Kraft 可行误报为物理电路可行。
