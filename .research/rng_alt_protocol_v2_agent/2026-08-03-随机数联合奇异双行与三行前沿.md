# 随机数持续种子联合奇异双行与三行前沿

1. 补齐了旧 rank-2 搜索遗漏的“单行替换会奇异，但两行合起来可逆”路径；
2. 在主 `over=3/excess=20/max=34` 中心周围，完整检查所有能由第三个坐标补成命中集的

## 协议与基线

持续 seed 的 66 周期模型为：

```text
r' = B*r XOR T*seed
y  = C*r XOR seed

P = C^-1
T = P*(A+I)
B = P*A*C
```

其中 `A` 是最新版 RNG 测试使用的 xorshift32 线性变换。普通二叉 XOR 在八延迟内的逐行
必要条件是：

```text
wt(C[row]) <= 3
4*wt(B[row]) + wt(T[row]) <= 16
```

输入中心来自：

```text
.research/rng_alt_protocol_v2_agent/sparse-c66-run-c6602.jsonl
SHA-256 405e64d5c1df1ab6a60371371695b45db62d818265892189ab798f160874229f
```

本报告实际依赖两个固定中心输入：上述主中心，以及
`.research/rng65_joint_basis_agent/phase8-legal-transvection-beam.jsonl`。两份 JSONL 均随提交
原样保存。生成它们时使用的**确切源码版本和完整调用参数已经无法逐字节重建**；当前保留的
`search_sparse_c66.cpp` 与 `search_legal_transvections.cpp` 只能用于校验矩阵、从固定中心继续
搜索或复现实验方法，不能声称会重新生成相同字节的中心文件。

## 为什么只需 343 个双行坐标

对原中心的某个坏行 `r`，只改 C 的若干行。若这些行的坐标均不在：

```text
supp(P[r]) union supp((P*A)[r])
```

则 Woodbury 更新既不改变该行的 `P`，也不通过 `P*A` 触及被替换的 C 行，所以该坏行的
`B/T` 与 metric 保持不变。因此，一个三行候选至少必须命中三个坏行各自的敏感集合。

32 个坐标中：

```text
能再加一个坐标完成命中的双行坐标 = 343
直接完成命中的三行坐标集合       = 672
```

每个 C 行允许所有权重 1、2、3 的非零 32 位向量，共：

```text
C(32,1) + C(32,2) + C(32,3) = 5488
```

排除原值后每行有 5487 个替换值，所以完整双行计数闭合为：

```text
343 * 5487^2 = 10326758967
```

## 联合奇异 rank-2

设两行增量为 `delta0, delta1`，并令：

```text
alpha0 = delta0 * P
alpha1 = delta1 * P
```

两行替换后的可逆性由对应的 `2x2` Woodbury 核决定。这样会自然覆盖：

- 两个单行替换都可逆；
- 一个单行替换可逆、另一个单独奇异；
- 两个单行替换都奇异，但联合替换可逆。

全部 `10326758967` 个值组合中有 `542967173` 个最终联合可逆。没有一个双行候选单独修复
原来的三条坏行。独立审计又随机抽取 4096 个联合可逆候选，三类分别覆盖：

```text
regular / regular      = 1968
singular / singular    = 1466
mixed                  = 662
```

每个样本均把 Woodbury 增量结果与完整 GF(2) 求逆交叉比较，4096 个继续追加合法第三行的
样本也全部与完整求逆、`B/T` 矩阵乘法一致。

## rank-3 beam

对每个联合可逆双行桥，先完整计算当前所有违规行。只有这些行的敏感集合仍存在共同第三坐标
时，单次第三行替换才可能全部修复。由此得到：

```text
pair states with a possible third = 859128
pair/destination options          = 875394
```

搜索按每个“原双行坐标、第三坐标”保留 256 个完整分数最好的桥；另按每个原坏行违规模式
保留 64 个桥，减少只按总分排序造成的单一路径偏置。最终保留 `61078` 个桥，逐一枚举第三行
的 5488 个稀疏值并检查 rank-1 可逆条件：

```text
rank3 checked             = 90568464
rank3 nonsingular         = 33644182
rank3 repaired all bad    = 0
best necessary score      = 3 / 20 / 34
```

第二个独立 `over=3` 中心也在较窄的 24 个“前两行已命中全部坏行”坐标上运行了
`beam=2048`，检查 `89772704` 个第三行候选、`34541332` 个可逆候选，同样没有修复项。

## 严格边界

本轮严格覆盖：

- 343 个可完成双行坐标上的所有 `5487^2` 个值组合；
- 其中所有联合可逆双行桥的精确计数；
- 既定 61078 个多目标桥上的全部第三行稀疏值；
- 普通 XOR 的逐行八延迟必要条件。

本轮没有覆盖：

- 859128 个可修复双行桥的全部第三行值，只覆盖每桶 beam；
- 三行一起可逆、但任意作为中间态的双行矩阵均奇异的 3-cycle 类；
- 超过三行的联合状态重编码；
- 能绕开普通 XOR 行权必要条件的真实无向 Switch/Z 网络；
- 共享 XOR/Switch DAG 的最终门数、物理布局与游戏逐拍证书。
- 两个固定中心 JSONL 的逐字节生成历史；原始源码修订与完整调用参数没有保留下来。

所以 JSONL 中的 `unsat-in-subspace` 只表示指定子空间没有命中，不是全局不可满足证明。
