# 随机数低次轨道闭环审计

## 2026-08-03 / 研究：排除 degree-4 乘积特征的零逻辑状态环

### 目标

检查固定 RNG 编码 DAG 中是否存在便宜的非线性状态特征 `f(q)`，使其后继
`f(Bq)` 能直接由另一个已存特征以导线或 NOT 提供。只有这些后继关系形成有向闭环时，
一组 Delay Bit 才能在稳态阶段不经过组合逻辑而持续更新；单独的有向路径仍会在末端需要
组合逻辑，不能直接换算成门数收益。

官方 256 个 seed 的前 64 次反馈状态共得到 16,384 个互异 care points。第一轮取当前
`B`、`C` 和 61-XOR 已检查 DAG 内部出现的 66 个不同线性信号，完整枚举这些信号的
1 至 4 次 square-free 乘积：

```text
线性信号                                      66
degree 1..4 特征                         768691
当前签名重复                                 9979
其中样本专有重复                                0
wire 后继匹配                                2206
其中非零全空间匹配                              30
其中样本专有匹配                                 0
NOT 后继匹配                                    0
非零功能图节点 / 边                         60 / 30
非零有向闭环                                    0
耗时                                      82.451 s
```

原始签名碰撞中包含 `a*b*(a XOR b)=0` 一类恒零关系。脚本没有依赖 care-point 签名来
判定这些关系，而是把每个乘积展开为 Boolean ring 上的精确 ANF，以 square-free monomial
集合进行全空间恒等比较。9979 个重复全部是全空间代数恒等式；排除恒零后只剩 30 条
全空间 wire 后继，而且它们形成 30 条不闭合的边。故在这个完整的 768691 特征族内：

1. 不存在利用 256 个官方 seed 才成立的 wire/NOT 后继。
2. 不存在可由 Delay Bit 之间直接连线维持的非零非线性状态环。
3. 这些碰撞不能物化为省门候选，也没有生成或部署电路。

### raw state 扩展

把全部 32 个原始编码状态位并入候选行后，共有 93 个不同线性信号。先完成 degree 1..3
的完整扩展审计：

```text
degree 1..3 特征                         134137
当前签名重复 / 样本专有重复                456 / 0
wire 后继匹配 / 样本专有匹配              8667 / 0
非零全空间 wire 匹配                         8606
非零功能图节点 / 边                    16852 / 8516
非零有向闭环                                    0
NOT 后继匹配                                    0
耗时                                       2.655 s
```

这一结果封闭了所列线性行的乘积族，不是对任意 affine form、任意非线性编码或带组合逻辑
后继网络的全局 UNSAT。degree-4 raw-state 扩展尚未包含在本证书中。

### 复算

```powershell
.\.venv\Scripts\python.exe -m py_compile `
  .research\rng_42state_direct\sample_nonlinear\search_degree4_orbit_collisions.py

.\.venv\Scripts\python.exe `
  .research\rng_42state_direct\sample_nonlinear\search_degree4_orbit_collisions.py `
  --rounds 64 --maximum-degree 4 `
  --output .research\rng_42state_direct\sample_nonlinear\degree4_orbit_collision_certificate.json

.\.venv\Scripts\python.exe `
  .research\rng_42state_direct\sample_nonlinear\search_degree4_orbit_collisions.py `
  --rounds 64 --maximum-degree 3 --include-all-state-bits `
  --output .research\rng_42state_direct\sample_nonlinear\degree3_allbits_orbit_collision_certificate.json
```

完整 degree-4 运行期间外部采样到约 294.3 MiB 工作集；这是运行中采样值，不宣称是精确
峰值。没有启动游戏，也没有读取或写入正式存档。
