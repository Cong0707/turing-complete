# 随机数低次轨道闭环审计

## 2026-08-03 / 研究：排除 degree-4 乘积特征的零逻辑状态环

### 目标

检查固定 RNG 编码 DAG 中是否存在便宜的非线性状态特征 `f(q)`，使其后继
`f(Bq)` 能直接由另一个已存特征以导线或 NOT 提供。只有这些后继关系形成有向闭环时，
一组 Delay Bit 才能在稳态阶段不经过组合逻辑而持续更新；单独的有向路径仍会在末端需要
组合逻辑，不能直接换算成门数收益。

官方 256 个 seed 的前 64 次反馈状态共得到 16,384 个互异 care points。第一轮取当前
`B`、`C` 和 61-XOR 已检查 DAG 内部出现的 66 个不同线性信号，完整枚举这些信号的
1 至 4 次 square-free 乘积：

```text
线性信号                                      66
degree 1..4 特征                         768691
当前签名重复                                 9979
其中样本专有重复                                0
wire 后继匹配                                2206
其中非零全空间匹配                              30
其中样本专有匹配                                 0
NOT 后继匹配                                    0
非零功能图节点 / 边                         60 / 30
非零有向闭环                                    0
耗时                                      82.451 s
```

原始签名碰撞中包含 `a*b*(a XOR b)=0` 一类恒零关系。脚本没有依赖 care-point 签名来
判定这些关系，而是把每个乘积展开为 Boolean ring 上的精确 ANF，以 square-free monomial
集合进行全空间恒等比较。9979 个重复全部是全空间代数恒等式；排除恒零后只剩 30 条
全空间 wire 后继，而且它们形成 30 条不闭合的边。故在这个完整的 768691 特征族内：

1. 不存在利用 256 个官方 seed 才成立的 wire/NOT 后继。
2. 不存在可由 Delay Bit 之间直接连线维持的非零非线性状态环。
3. 这些碰撞不能物化为省门候选，也没有生成或部署电路。

### raw state 完整扩展

把全部 32 个原始编码状态位并入候选行后，共有 93 个不同线性信号。先以 degree 1..3
复核实现，再完成 degree 1..4 全集：

```text
degree 1..4 特征                        3053872
当前签名重复 / 样本专有重复              40596 / 0
wire 后继匹配 / 样本专有匹配             84753 / 0
非零全空间 wire 匹配                        79202
非零功能图节点 / 边                 151555 / 75992
非零有向闭环                                    0
NOT 后继匹配                                    0
耗时                                      42.027 s
```

这一结果封闭了所列线性行的乘积族，不是对任意 affine form、任意非线性编码或带组合逻辑
后继网络的全局 UNSAT。degree 1..3 的独立中间证书也保留，用于回归检查。

为避免恒零签名桶导致近二次比较，最终实现对每个 care 签名只保留每一种全空间 ANF 的一个
代表；128-bit digest 命中仍会重算完整 16,384-bit 签名，ANF 相等仍按完整 monomial 集合
判断。压缩前后的 66-signal 全集除耗时和示例排列外，全部证书字段逐项一致；耗时从
82.451 秒降到 10.643 秒。

## 2026-08-03 / 研究：排除任意 degree-4 全局短周期特征

前一节只枚举“最多四个候选线性信号的乘积”。本节进一步覆盖 degree≤4 的完整 Boolean
ANF 空间，包括任意多个乘积项的 XOR，不再受具体乘积库限制。

xorshift32 自然转移 `A` 的 `e0,Ae0,...,A^31e0` Krylov 矩阵秩为 32；其特征多项式为：

```text
0x1003ec241
非零次数：0, 6, 9, 14, 15, 17, 18, 19, 20, 21, 32
```

矩阵幂复核得到 `A^(2^32-1)=I`，并且把指数分别除以
`3,5,17,257,65537` 后均不是单位阵，故 `A` 的精确阶为 `N=2^32-1`，是 32 维
primitive Singer cycle。

Boolean degree filtration 的第 d 个分次商是 `Λ^d(V*)`。对任意长度 `L` 的 wire-only
特征环，首特征必须满足 `f(A^L x)=f(x)`。因为 `<A^L>` 阶为奇数，Maschke 分裂保证固定
空间维数能在各分次商上相加。Singer cycle 在分裂域上的特征值为 `alpha^(2^i)`；因此
外幂基指数 `s` 被固定当且仅当：

```text
N divides L*s
```

`1<=L<=42` 只有五种 `gcd(L,N)`：`1,3,5,15,17`。完整枚举 degree≤4 的 41449 个
square-free 指数后，五类固定空间维数均为 1，即只剩常数。对应正固定指数的最小 Hamming
weight 分别为：

```text
gcd 1:  不存在正的真倍数
gcd 3:  16
gcd 5:  16
gcd 15: 8
gcd 17: 16
```

所以任意全局有效、ANF degree≤4、长度≤42 的 wire-only 非常数状态环都不存在。编码转移
`B=T*A*T^-1` 与 `A` 线性共轭，线性换基保持 ANF degree，因此结论同样适用于当前编码
状态。该证明仍不排除只在 256 个测试轨迹成立的多项式、degree≥5 特征或含组合门的更新环。

## 2026-08-03 / 研究：排除官方样本上的一项与两项四次短环

全局证明不自动排除只在官方有限轨迹成立的多项式。为此，对 256 个官方 seed 的
`A^0(s)..A^64(s)` 共 16640 个互异自然状态，逐个周期长度 `L=1..42` 检查：

```text
f(A^L x) = f(x)
```

长度 L 只使用能由 64 条连续反馈边组合出的 `t=0..64-L`，故每类约束点数从 L=1 的
16384 递减到 L=42 的 5888。特征全集是 41448 个非常数自然 ANF monomial
（degree 1..4），并进一步检查任意两个不同 monomial 的 XOR。实现对每个 monomial 保存
差分签名；两个差分签名相同，严格等价于它们的 XOR 是一个样本周期特征。128-bit digest
命中会重算完整 bit-vector，不能把摘要碰撞算作命中。

同时对每个 L 的起始状态集合独立计算 degree≤3 的完整 5489 列求值矩阵。42 个矩阵的秩
全部为 5489，因此这些样本集合上的 degree≤3 求值映射均为单射。若 degree≤3 特征 f 在
样本上满足周期关系，则 `f(A^L x)+f(x)` 先被迫成为全空间零多项式，再由上一节全局短周期
证明推出 f 只能是常数。这一步覆盖任意 ANF support，不只是一项或两项。

```text
周期长度                              42
每周期非常数 monomial              41448
单 monomial 周期命中                    0
双 monomial XOR 周期命中                0
digest 碰撞                             0
degree<=3 起始求值秩              42 * 5489
耗时                               93.298 s
```

因此非常数样本周期特征必须是 degree 恰为 4；其自然 ANF support 还必须至少为 3。即便
首特征存在，完整 wire 环仍需为所有中间相位找到同样廉价的表示。本轮没有生成电路。

## 2026-08-03 / 研究：排除两只廉价乘积组成的样本自环

自然 ANF support 不等于电路成本：一个最多四个任意线性信号的乘积虽然可能展开成很多
自然 monomial，却只需最多三只二输入非线性门。因此又对最有价值的 `L=1` 自环完整检查
更大的廉价原子库：93 个 `B/C/internal/raw-state` 线性信号的全部 degree 1..4 乘积，
以及任意两个不同乘积函数的 XOR。

对每个乘积 p 计算 16384 个反馈点上的差分签名 `p(Bq)+p(q)`。单乘积非零自环对应零
差分；两个乘积的 XOR 自环对应差分签名相同。摘要命中后重算完整签名，并用 Boolean-ring
精确 ANF 区分“两个写法表示同一个全局函数”和真正的样本专有关系。

```text
线性信号                                 93
degree 1/2/3/4       93 / 4278 / 129766 / 2919735
乘积总数                            3053872
差分签名重复                           40596
其中全空间等价                         40596
其中样本专有                               0
不同非零单乘积自环                         0
digest 碰撞                               0
耗时                                 17.323 s
```

因此当前廉价因子库中不存在单产品自环，也不存在由两个产品 XOR 构成的样本专有自环。
40,596 个重复全部只是前面已经识别的全空间产品恒等。本结论只覆盖 `L=1`、最多两个产品
原子；不覆盖三个产品、带常数的 affine 因子或含组合门的反馈更新。
