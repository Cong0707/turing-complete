# 字节加法器物理分区宏冻结

## 2026-08-03 / 本轮边界

本轮只修改离线精确综合器、重放旧证书并搜索 1--3 位局部宏。没有启动游戏，没有读取或
修改正式存档，没有操作 Git，也没有创建子代理。冻结通知到达后，正在进行的三位搜索已
自然结束，此后没有启动新求解。

目标仍为无 `com_add` 的合法 Byte Adder，优先寻找完整 `<=85/6` 且能耗严格低于 `515`
的候选。本轮只得到可供全局 DP 使用的局部宏，没有得到完整八位候选。

## 物理 BUS 修正

`exact_carry_block_sat.py` 现在默认启用与 `exact_adder_block_sat.py` 相同的物理网络分区
约束。全部组件 `left_bus`、非空或空的 `right_bus` 以及所有 `output_buses` 都作为 BUS
occurrence 参与约束：

```text
两个 BUS 若共享任意 source，则完整 source set 必须相同；
否则同一输出引脚会把两条 resolved network 物理短接。
```

相同 source set 可以出现多次，表示同一物理网络的正常扇出。独立 verifier 同时枚举
全部 BUS 对，并输出：

```text
physical_net_partition_violation_count
physical_net_partition_violations
```

任何真值错误、BUS 冲突、未驱动输出或物理分区违规都会拒绝 SAT 见证。可用
`--abstract-buses` 复现旧编码，但这种结果不得升级为游戏候选。

## 一位晚到 carry 回归

### `Cin@4 -> Sum@6 / Cout@5`

物理约束下，`gate<=10` 的 `components=6..10` 全部 UNSAT；当前首个合法命中为
`11 gate / 7 components`：

```text
Q    = NOR(A,B)
G    = AND(A,B)
P    = NOR(Q,G)
Sum  = XOR(Cin,P)
PC   = SWITCH(P,Cin)
NP   = NOT(P)
NB   = SWITCH(NP,B)
Cout = BUS(PC,NB)
```

`Cout` 的两只 Switch 只共同出现在 source set `{PC,NB}`，没有跨 BUS 复用。八组输入的
Sum/Cout 全部正确，冲突、未驱动和物理分区违规均为 0，递归重放最大深度为 6。

这里的 UNSAT 窗口没有覆盖 `components<5`，因此冻结记录只称它为当前首个命中，不把
`11 gate` 外推成任意元件数的全局下界。

### `Cin/~Cin@5 -> Sum/Cout@6`

原 `12 gate / 6 components` 双轨宏在新编码下重新 SAT，八组输入的全部检查仍为 0。

### `Cin/~Cin@5 -> Sum/Cout/~Cout@6`

旧十四门证书已确认物理非法。新物理编码对固定 `9 components` 的 `gate<=14`、`<=15`
和 `<=16` 均返回 UNSAT；其他元件数尚未穷尽，不能将 16 门写成全局下界。

## 固定 GP 外壳下的 transfer 宏

`--free-gp` 表示八位方案已经为每位支付 `G=AND(A,B)`、`Q=NOR(A,B)`、
`P=NOR(Q,G)`，综合器只计算新增 carry/transfer 逻辑。它不表示这些信号在完整电路中
免费，也不能把局部门数直接当作完整 Byte Adder 成绩。

### 一位 transfer：当前命中 `1/2`

```text
u = g
v = NOT(q)
```

文件参数上限为 depth 3，但独立重放的真实最大深度为 2。

### 两位 transfer：当前命中 `4/3`

```text
x0 = NOR(q0,q1)
v  = OR(g1,x0)
x1 = NOR(g0,g1)
u  = NOR(q1,x1)
```

四个输出 BUS/输入 BUS 均为单 source，不存在三态复用。真值检查 `64/64`，全部错误计数
为 0。

### 两位 dual-transfer：当前命中 `6/3`

在上方两组互补锥上同时输出 `u,v,~u,~v`，共 6 个普通一门元件。真值检查
`128/128`，全部错误计数为 0。

### 三位 transfer：当前命中 `8/4`

当前证书也是纯普通门结构：

```text
t0 = OR(g1,g2)
t1 = NOR(q0,q1)
t2 = NOR(t0,t1)
v  = NOR(q2,t2)

h1 = OR(a1,b1)
t3 = AND(g0,h1)
t4 = NOR(t0,t3)
u  = NOR(q2,t4)
```

真值检查 `256/256`，冲突、未驱动和物理分区违规均为 0，递归重放最大深度为 4。

冻结前的三位 depth-3 对角枚举 `gate_bound=components=5..11` 全部 UNSAT；depth-4 的
对角枚举 `5..7` UNSAT、`8` SAT。该枚举没有覆盖同一 gate bound 下“更少 components
+ 若干 Switch”的全部组合，所以 `8/4` 只是当前最佳合法命中，不是完整最小性证明。
