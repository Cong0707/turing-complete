# bit3:4 C5 输出分区独立覆盖审计

日期：2026-08-04

## 结论

对固定 `d7_80 g13/n11/s2/x0` 的 C5 输出 normal-form 分片做了独立静态概念审计。
结论是 pair + single-driver 的 coverage argument **sound**，未发现覆盖漏洞；本审计没有
重新运行 SAT 求解。

## 输出 driver-count 二分

权威 exact encoder 对 C5 的 `output_uses` 加入非空 clause，因此 driver count 至少为 1。
`_restrict_active_bus_to_switches` 又保证：

- paid source 或 free constant 一旦被选中，就不能与任何其它 driver 同选；
- synthesized component 若属于任意非-Switch kind（包括 ordinary 与 XOR），其输出一旦
  被选中，也不能与其它 driver 同选；
- 因而 driver count 大于 1 的 C5 BUS 只能由 synthesized Switch 输出组成。

base case 精确限制 `switches=2`，所以多 driver 分支只能是恰好两只 Switch。由此全部
合法 C5 输出严格二分为：

```text
exactly one driver
exactly two Switch drivers
```

single-driver ledger 覆盖前者，pair-cone ledger 覆盖后者，不存在第三类。

## Pair 分支 normal form

设最终 C5 BUS 的完整 driver set 为 `{A,B}`。若 Switch A 的输出馈入 Switch B 的任一
输入 BUS，则该输入 BUS 与最终 C5 BUS 至少在 A 上重叠。权威
`_enforce_physical_net_partition` 要求任意两个有公共 component-output driver 的 BUS
具有完全相同的 driver set，因此 B 的输入 BUS 也必须包含 B；但 DAG 编码中 B 自身输出
不在 B 的输入候选中，产生矛盾。反向依赖同理，所以两个 C5 Switch 互不依赖。

任意 covered DAG 因而可以保持边与种类不变地拓扑重标号为：所有 Switch-input ordinary
祖先在前，两只互不依赖的 C5 Switch 紧随，其余 ordinary 在后。九只 ordinary 中的祖先数
唯一属于 `k=0..9`。每个 prefix gate 都被要求至少有一个位于 prefix 或两只 Switch 中的
后继用户；有限 DAG 中沿这些用户边最终必达某只 Switch，因此不会误收非祖先门。

## Single-driver 分支 normal form

若 C5 不选择任何 component output，输出非空约束与 paid-source 互斥共同保证它恰好选择
一个 paid source 或 free constant，这正是 `source` shard。

若 C5 选择一个 component output，分片把其余全部 output selector 置假，并把该 driver
的全部 component ancestors 拓扑重标号到前、driver 紧随、全部非祖先 component 放在后。
十一只 component 中，driver 的祖先数唯一属于 `k=0..10`。prefix user clauses 同样保证
每只 prefix component 传递到达 driver。因此 `source + k0..k10` 完整覆盖 singleton
分支。

## Slot-order 约束检查

权威 core 没有额外的 component kind 排序或 prefix kind symmetry breaker。唯一相关的
slot-order 规范化是 commutative gate 两个输入 BUS 的字典序约束。拓扑重标号后可以交换
commutative gate 的左右输入恢复该顺序而不改变功能；Switch 不属于 `COMMUTATIVE`。
所以该约束不破坏上述拓扑 normal form 的 WLOG 完备性。
