# 87 门电路 Switch 恒零线索独立审计

日期：2026-08-04

## 结论

人工审核提出：当前 `87/6/522` 电路可能存在一只 `enable` 始终为 `0` 的 Bit
Switch；若成立，该元件等价于永久断路。

本轮不再信任生成器中的 Factory 节点名，而是直接解码正式存档的物理组件、最新版
引脚和 167 条实际导线，并枚举全部：

```text
256 * 256 * 2 = 131072
```

个 `A/B/Cin` 输入组合。结论为：

```text
全域恒零 enable                         0
可单独断开且保持输出正确的 Switch       0
最少 enable=1 行数                   32768
单独断开后最少错误测例行数              8192
原电路九输出 mismatch                      0
原电路异值多驱动冲突                       0
```

因此，**当前正式文件中不存在 enable 恒零的 Switch**。画面中某只开关在当前测试向量
下关闭，不等于它在完整输入域中恒零。

## 最新版物理引脚合同

正式文件中的 Bit Switch 为组件 kind `12`。本轮按当前版本实际引脚几何读取：

```text
enable  = component position + (0, +1)   # 下方控制端口
in      = component position + (-1, 0)
out     = component position + (+2, 0)   # 高阻输出
```

这与最新版“enable 在下方而不是上方”的游戏变更一致。本审计没有按旧版端口顺序
解释导线。

### 特别容易误判的 index 70

index `70` 的 `enable` 与 data 都接到同一个 `G7` 网络。这种接法等价于：

```text
SW(enable=G7, data=G7)
```

视觉上它可能像一只“多余”的开关，但它的用途是：

```text
G7=0 -> 输出 Z
G7=1 -> 主动输出 1
```

它在 `32768` 行开启；单独断开后，Cout 在 `32768` 行错误。因此它既不是恒零，也不
能用普通直连替换而保持原来的 Z 合同。

## 逐只断开结论

13 次反事实测试每次只改变一个变量：把目标 Switch 的输出强制为永久 Z，其余物理
组件和导线不动。得到：

```text
最少错误行数       8192   # index 40 / 44 / 67
最多错误行数      34816   # index 43
断开后新增冲突        0
```

没有一只开关满足：

```text
enable 永远为 0
或
断开后仍保持全部 131072 行九输出正确
```

## 最终判断

人工线索本身值得复核，但针对当前正式物理文件，严格结论是：

```text
不存在恒零 enable
不存在等价永久断路的 Switch
不存在由直接删一只 Switch 得到的 85/6
```

如果人工审核指的是某一只具体外观元件，下一步应提供它的截图或相邻门位置，再按上表
的坐标/PID 定点对应；但在没有新位置证据前，不能删除当前 13 只中的任何一只。
