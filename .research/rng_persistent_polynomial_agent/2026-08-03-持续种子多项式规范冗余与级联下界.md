# RNG 持续 seed 多项式规范冗余与级联下界

日期：2026-08-03
首次归档提交：`9dbefe1`

## 结论

本轮没有得到可写入存档的候选，但封闭了两个此前仍开放的方向：

1. 题设的任意可逆多项式 `P(A)` 不会扩大 66 周期持续 seed 的可实现电路族；它只是
   状态编码参数的规范冗余。`P=I`、`P=A+I` 以及全部可逆 `P(A)` 已经包含在原来的任意
   可逆编码矩阵搜索中。
2. 利用 `q'=q+U*y` 的直接四级级联
   `z=Cq; y=z+seed; w=Uy; q'=w+q` 至少需要 `98` 个普通 XOR2，即 `294 logic gate`。
   它已经严格超过八延迟的 `292` 门逻辑预算，也超过九延迟的 `242` 门逻辑预算。因此
   下一条正常候选必须跨 `B/D/C` 的级联边界联合综合，不能只优化 `U` 与 `C` 两个独立
   线性层。

本轮没有启动游戏，没有读取或写入正式存档，没有使用 RAM、抽象一延迟 XOR 或伪造成绩。

## 正确预算

当前正常前沿为：

```text
401 / 9 / 67 = 241803
```

66 周期持续 seed 固定外壳为 `32 state Delay + 1 ready Delay = 165 gate`。严格超过当前
前沿时：

```text
9 delay: total <= floor(241802 / (9*66)) = 407, logic <= 242
8 delay: total <= floor(241802 / (8*66)) = 457, logic <= 292
```

普通 XOR2 使用实测成本 `3 gate / 2 delay`。Bit Switch 的 `2/1` 与 Z 语义没有被抽象成
便宜 XOR；本报告的下界只讨论普通线性 XOR2 直线程序。

## 多项式规范冗余定理

设 `A` 是 xorshift32 的可逆转移矩阵，`P=P(A)` 可逆，因此 `PA=AP`；`T` 是任意可逆
状态编码。题设广义族为：

```text
B = T A T^-1
D = T P
C = (A+I) P^-1 T^-1
E = I
```

令：

```text
U = T P
```

则：

```text
B = T A T^-1
  = T P A P^-1 T^-1
  = U A U^-1

D = U

C = (A+I) P^-1 T^-1
  = (A+I) U^-1
```

这正是取 `P=I, T=U` 时的方程。反过来，任意可逆 `U` 都可以由 `P=I, T=U` 得到，
所以两边的 `(B,D,C)` 集合完全相等，而不是一边只包含另一边。证明实际上不要求 `P`
是多项式，只要求它可逆且与 `A` 对易。

两个已知端点只是同一空间中的不同参数名：

```text
P=I:     U=T
P=A+I:   U=T(A+I)
```

脚本同时确认当前 `A+I` 可逆。因此继续联合枚举 `(T,P)` 只会重复枚举相同的 `U`，不会
产生新前沿。

## 全空间协议证明

规范化后：

```text
q' = Bq XOR U*seed
y  = Cq XOR seed
B  = U A U^-1
C  = (A+I) U^-1
q0 = 0
```

第 `t` 拍状态为：

```text
q_t = U (I + A + ... + A^(t-1)) seed
```

所以：

```text
y_t = (A+I)(I + A + ... + A^(t-1)) seed XOR seed
    = (A^t + I) seed XOR seed
    = A^t seed
```

`tick1..65` 因而精确输出 `A^1(seed)..A^65(seed)`。验证器不是只抽查几个数，而是在每一
拍比较完整的 32x32 `seed -> output` 矩阵，故覆盖全部 `2^32` seed。另用 66 个多项式
案例逐值重放 32 个单位 seed 和 256 个固定随机 seed，共 `1,235,520` 次，全部通过。

## 联合变换与显式级联

由规范化方程还有：

```text
U C = U(A+I)U^-1 = B+I
```

因此：

```text
y  = Cq XOR seed
q' = q XOR U*y
```

联合 64x64 变换可分解为两个块剪切：

```text
[q']   [I U] [I 0] [q]
[ y] = [0 I] [C I] [s]
```

这给出最自然的显式四级实现：

```text
z = Cq
y = z XOR seed       # 32 个 XOR
w = Uy
q'= w XOR q          # 32 个 XOR
```

若 `L(M)` 表示矩阵 `M` 的最小二输入 XOR 直线程序长度，则该拓扑需要：

```text
32 + L(C) + L(U) + 32
```

把 `C` 电路接到 `U` 电路前即可计算 `UC=A+I`，所以：

```text
L(C) + L(U) >= L(A+I)
```

关键剩余问题是严格证明 `L(A+I)>=34`，不能把 61 门 Boyar-Peralta 构造上界误当下界。

## `L(A+I)>=34` 的规范化引理

当前 `A+I` 的 32 个目标行满足：

```text
rank             = 32
distinct rows    = 32
all row weights >= 2
weight distribution = {2:5, 3:12, 4:3, 5:10, 6:2}
```

因此每个目标都必须由某只 XOR 门产生，32 门程序没有非目标辅助节点，33 门程序恰有一只
非目标辅助节点 `h`。

### 32 门

目标门可以作为后续目标的中间节点，本证明没有禁止这种复用。设当前目标行为 `r_i`：

- `input XOR input`：`r_i` 是权重 2 的根；
- `earlier_target XOR input`：`r_i` 与一个更早目标行相差一个单位向量；
- `earlier_target XOR earlier_target`：不可能，因为
  `r_i=r_j XOR r_k` 会使 32 个目标行线性相关。

所以在“两个目标相差一个单位向量就连边”的图中，沿实际拓扑反向追踪，每个连通分量都
必须包含一个权重 2 根。实际图存在无根分量，32 门不可能。

### 33 门及免费 `h` 放宽

把唯一非目标辅助形式 `h` 放宽为**任意 32 位线性形式，并从时间零免费可用**。这删除了
`h` 本身必须由一只门按拓扑生成的约束，只会扩大可行域。因此放宽模型若 UNSAT，真实
33 门模型必然 UNSAT。

在此放宽下，每个目标门的全部可能类型为：

```text
input XOR input                  -> 权重2根
h XOR input                      -> 与h相差单位向量的根
earlier_target XOR input         -> 差一个单位向量的目标边
earlier_target XOR h             -> 差h的目标边
earlier_target XOR earlier_target -> 因目标独立而不可能
```

因此在“目标差一个单位向量或差 `h` 就连边”的图中，每个分量仍必须含一个根。若 `h`
真的被任何目标门使用，它必为以下两类之一：

```text
h = target XOR input
h = target_i XOR target_j
```

若 `h` 未使用，则退化为 32 门图。故只需完整枚举这两类与 `h=0` 的并集，而不是遍历
`2^32` 个无关形式。去重后共 `1505` 个 `h`。结果：

```text
checked h = 1505
feasible  = 0
best relaxed h = 0x00108084
best still has 20 rootless rows in 20 rootless components
```

注意，无向分量含根只是拓扑可实现的**必要条件**，并非充分条件；这里使用更宽松的必要
条件仍全部失败，所以结论方向是安全的。

于是：

```text
L(A+I) >= 34
explicit cascade >= 64 + 34 = 98 XOR2
logic gate       >= 98 * 3 = 294
```

这严格排除显式四级级联的八延迟和九延迟预算。结论不排除跨层共享中间节点、直接实现
`[B|U; C|I]` 的联合 DAG，也不排除经过完整 `(value,is_z)` 物理复算的非线性 Switch 网；
这些正是下一步应继续搜索的范围。

## 可达 tick 1 仍不能廉价替换末级 XOR

前面的 `98 XOR2` 下界使用了完整线性形式。一个自然疑问是：协议只访问
`q_t=U(I+A+...+A^(t-1))*seed`，能否利用可达状态的 don't-care，把 64 个末级 XOR 中
至少一个换成 OR、单只 Switch 或不超过两门的普通布尔宏，从 `294` 门降进 `292` 门预算。

对显式级联：

```text
z = C*q
y = z XOR seed
w = U*y
q'= w XOR q
```

只看完全可达的 tick 1 即可否决这种局部替换。此时：

```text
q = U*seed
z = (A+I)*seed
y = A*seed
w = U*A*seed
```

所以第 `i` 个输出末级对是 `((A+I)_i, e_i)`，第 `i` 个反馈末级对是
`((U*A)_i, U_i)`。脚本对全部 64 对逐项验证两个 32 位线性形式均非零且不相等，即每对
秩均为 2。秩 2 映射对全部 `2^32` seed 满射到：

```text
00  01  10  11
```

证书还为每一对、每个二元组合保存了一个具体 32 位 seed witness。例如：

```text
output bit 0: left=00042020 right=00000001
00->00000002  01->00000001  10->00000020  11->00000021

feedback bit 0: left=01088c40 right=00800400
00->00000001  01->00000440  10->00000040  11->00000400
```

关卡实际 seed 域是 `1..0xffffffff`。64 对的四类 witness 均已强制为非零，证书中没有借用
被关卡排除的 seed 0。因此 OR 与 XOR 必然在 `11` 上不同；无其它可达状态假设可以删除
这个反例。独立真值表
闭包从常量、`a`、`b` 出发，允许 `NOT/AND/OR/NAND/NOR`，得到不用原生 XOR 时的最小
成本仍为 3 门，一个见证是：

```text
NOR(AND(a,b), NOR(a,b))
```

单只 Switch 在输出端以 Z 读零时只是 `data AND enable`，成本 2 门，也不能实现四组合
XOR。两只 Switch 的互斥双轨宏成本至少 4 门，只能换延迟，不能省门。

该结论**只封闭显式级联 64 个末级的局部廉价替换**。它没有证明任意跨层共享网络需要
`294` 门，也没有排除多输出共用非线性节点、多个三态驱动器组成的真实 BUS、或针对官方
有限测试集的跨层重构。

## `over=3` 联合中心的 61 条安全行精确下界

显式级联被封闭后，又直接检查当前最好的 `over=3` 联合状态中心。其完整 64 行目标严格为：

```text
[B | U]
[C | I]
```

且矩阵秩为 64。三条超出 delay-8 cancellation-free XOR Kraft 条件的行是：

```text
row 13: 3 q + 5 seed, Kraft 17
row 16: 7 q + 6 seed, Kraft 34
row 27: 3 q + 5 seed, Kraft 17
```

本轮在生成候选之前排除这三行，只对其余 61 条安全行做精确共享 DAG 综合。这样不会把
重行的全部子集送入 MaxSAT，也避免了前一版完整模型的内存爆炸。允许的物理宏为：

```text
XOR2                  3 gate / 2 delay / always driven
Switch-XOR3 partial  12 gate / 2 delay / may be Z
Switch-XOR3 full     18 gate / 2 delay / always driven
self-OR normalize     1 gate / 1 delay / always driven
```

输入到达时间沿用真实两相外壳：32 个状态位到达 4，32 个 seed 位到达 0，所有目标必须在
到达 8 前始终驱动。候选生成只允许不相交 support partition，因此这是严格的
**cancellation-free** 族；同一中间线性形式可跨任意目标共享。RC2 对 27497 个物理候选、
45757 个硬子句和 27497 个加权软子句求得精确最优：

```text
61 targets only
154 XOR2
0 Switch-XOR3
0 normalize
logic gate      = 462
maximum arrival = 8
solve seconds   = 0.8660646
peak working set= 117338112 bytes
```

61 行自己已经需要 462 门，严格超过整个 64 行候选的 `logic<=292` 数据面预算。因此当前
`over=3` 中心不可能在该 cancellation-free XOR2/Switch-XOR3 宏族内形成
`<=401/9/67` 候选；剩余三行无需继续加入模型。

这个结论不能外推为一般线性电路下界。它不覆盖带 cancellation 的中间形式、非线性节点
跨层相消、多输出共享的真实三态 BUS，以及针对官方有限轨迹的特化。下一步只研究这些
尚未覆盖的结构，不再重跑相同的重行全子集模型。

## 允许跨层 cancellation 后的普通 XOR2 下界

前一节的 `462` 门最优只适用于 support 不相交的 cancellation-free 宏族。为了覆盖一般
普通 XOR2 电路，本节不再枚举完整 64 位中间形式，而只投影到状态输入 `q`，并利用真实
到达时间得到一个更宽松但更一般的必要条件。

61 条安全目标全部不同、全部含至少一个 `q` 位和至少一个 seed 位，因此每个目标至少需要
一只产生其最终线性形式的门，共 61 门。只看其中 26 条 `q-weight=3` 目标。状态输入到达 4，
普通 XOR2 延迟 2，目标截止 8，所以目标末级的两个输入必须在 6 前可用。在到达 6 前，
任何含 `q` 的新普通 XOR2 信号的 `q` 投影只能是：

```text
q-pair: XOR(raw q_i, raw q_j), seed label 必为 0
q-unit: XOR(raw q_i, arbitrary seed-only form)
```

两个投影要异或成权重 3，唯一可能是一个不相交 `q-pair` 加一个 `q-unit`。因为 pair 的
seed label 必为 0，unit 必须携带该目标的**完整** seed label。每条 q3 目标有三个选择，
即选择哪个 q 位留在 unit 中；不同目标可任意共享相同 pair 或带标签 unit。

模型还作了两项只会扩大可行域的优惠：

1. 任意 seed-only 线性形式均从到达 4 起免费可用，不计它实际需要的任何 XOR 门；
2. 11 条 q1 安全目标对应的 `(q_bit, seed_label)` unit 已经包含在 61 个目标末级门中，
   把它们作为额外成本为 0 的可复用中间节点。

因此，这个模型中的额外节点最优一定不大于真实电路所需的额外 q 节点。它不禁止中间
形式带 cancellation，也不限制 seed 标签之间怎样相消。145 个收费 pair/unit 候选和
26 个三选一目标约束的精确结果为：

```text
extra q node <= 40: UNSAT (Glucose 4.1, Minisat 2.2)
extra q node <= 41: SAT   (Glucose 4.1, Minisat 2.2)

target final gate baseline = 61
extra q-node optimum       = 41
ordinary XOR2 lower bound  = 102
logic gate lower bound     = 102 * 3 = 306
delay-8 logic budget       = 292
```

这严格封闭当前 `over=3` 中心的**全部普通 XOR2 delay-8 电路**，包括有 cancellation 的
共享直线程序；甚至不必使用 24 条 q2 目标和三条超重目标的额外结构约束。这个结论仍不
覆盖 AND/OR/NOT 等非线性中间节点相消，也不覆盖多只 Switch 驱动同一真实三态 BUS。
所以后续只需专攻 nonlinear Switch/Z，而不应继续调普通 XOR CSE。
