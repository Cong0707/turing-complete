# 七延迟三十四门早到因子进位接口

日期：2026-08-06

## 结论

七延迟状态共享路线得到两个新的固定构造边界：

```text
S0..S3 + late negative C4 factors             32 gate / D7
S0..S3 + early factored C4 interface           34 gate / D7
```

`32` 门结构使用 `N2` 同时服务 `S2` 与 `C3`，比先前的 `33` 门结构再省一门：

```text
C3 = NAND(N2,nG2)                              @5
N3 = NAND(C3,P3)                               @6
C4 = NAND(nG3,N3)
```

这个接口的晚因子仍到 D6，不能直接在 D7 终端扇出到四个双向翻转的 Sum。真正更有价值
的是只增加两门群描述符：

```text
R23 = NAND(nG2,nG3) = G2 OR G3                 @2
P23 = AND(P2,P3)                               @3

C4 = (R23 * V3) OR (P23 * C2)
```

这里故意不物化两个乘积，也不建立 resolved `C4` BUS。四个因子最晚都在 D3 到达，
完整 `71/7` 的剩余合同因此变为：

```text
low                                             34 gate
compatible joint high                          <=37 gate / D7
--------------------------------------------------------
complete                                        <=71 gate / D7
```

当前仍没有完整 `<=37` 门高段，因此不能宣称已经得到新榜一。但与原先的 D5/D6 晚状态
不同，这个接口把“共享增加延迟”限制在消费者内部：高段可以直接吸收乘积，而不必先付费
恢复 C4，再重复支付 C6/C7 的 owner。

## 一、十九门快速前缀

bits0:1 与 `C2` 保留已审计的快速结构：

```text
V0  = OR(A0,B0)
nG0 = NAND(A0,B0)
P0  = AND(V0,nG0)

D0 = OR(Cin,P0)
N0 = NAND(Cin,P0)
S0 = AND(D0,N0)
C1 = NAND(N0,nG0)

V1  = OR(A1,B1)
nG1 = NAND(A1,B1)
P1  = AND(V1,nG1)

D1 = OR(C1,P1)
N1 = NAND(C1,P1)
S1 = AND(D1,N1)

T0  = AND(Cin,V0)
E01 = NAND(nG0,nG1)

C2 = BUS(
  SW(enable=T0, data=V1),
  SW(enable=E01,data=V1)
)
```

门数为 `19`，`C2@3`。两路 driver 使用相同 data，固定重放无 BUS 冲突。

## 二、七门 bit2 共享状态

bit2 使用 `V/nG/P` 三态：

```text
V2  = OR(A2,B2)                                @1
nG2 = NAND(A2,B2)                              @1
P2  = AND(V2,nG2)                              @2

D2 = OR(C2,P2)                                 @4
N2 = NAND(C2,P2)                               @4
S2 = AND(D2,N2)                                @5
C3 = NAND(N2,nG2)                              @5
```

关键共享恒等式：

```text
N2 = NOT(C2*P2)
C3 = NOT(N2*nG2)
   = G2 OR P2*C2
```

`N2` 原本就是 S2 三门壳的一部分；追加一只 NAND 即生成 C3。bit2 因此只需：

```text
state                                           3
S2 shell                                        3
shared C3 final                                 1
-------------------------------------------------
                                                 7 gate
```

## 三、六门 bit3 与 32 门晚接口

```text
V3  = OR(A3,B3)                                @1
nG3 = NAND(A3,B3)                              @1
P3  = AND(V3,nG3)                              @2

D3 = OR(C3,P3)                                 @6
N3 = NAND(C3,P3)                               @6
S3 = AND(D3,N3)                                @7
```

这里免费暴露：

```text
C4 = NAND(nG3,N3)
```

所以低段为：

```text
fast bits0:1 + C2                              19
bit2 shared S2/C3                               7
bit3 state + S3                                 6
-------------------------------------------------
late split low                                 32
```

但 `N3@6` 到 D7 只剩一层。既有 81 状态审计已经证明，`S4..S7` 对 C4 都发生双向
翻转，因此不能把这个晚接口直接当成完整答案。

## 四、34 门早到因子接口

在 32 门低段上只增加：

```text
R23 = NAND(nG2,nG3)                            @2
P23 = AND(P2,P3)                               @3
```

由于：

```text
R23*V3
  = (G2 OR G3)*(P3 OR G3)
  = G3 OR P3*G2

P23*C2
  = P3*P2*C2
```

因此：

```text
C4 = G3 OR P3*G2 OR P3*P2*C2
   = (R23*V3) OR (P23*C2)
```

两个乘积严格互斥：`P23=1` 时 `G2=G3=0`，所以 `R23=0`。固定 512 行复算结果：

```text
low32 mismatch                                 0
low34 mismatch                                 0
C2 BUS conflict                                0
factored product overlap                       0
```

接口到达时间：

```text
R23 / V3 / P23 / C2                        2 / 1 / 3 / 3
```

如果后续单独物化两个正原因，需要两门：

```text
H23 = R23*V3                                   @3
L23 = P23*C2                                   @4
```

此时低段为 `36` 门；再用一只 OR 恢复标量 `C4@5`，低段为 `37` 门。当前研究不采用
这两种过早合流，因为它们分别把高段预算压到 `35` 和 `34` 门。

## 五、对七延迟新榜一的意义

当前实机前沿：

```text
84 / 6 / 504
```

七延迟严格超越必须达到：

```text
71 / 7 / 497
```

四种边界的真实合同是：

```text
low32, nG3/N3 latest D6             high<=39，终端双向翻转阻塞
low34, factored inputs latest D3     high<=37，当前主研究入口
low36, products latest D4            high<=35，预算过紧
low37, scalar C4 D5                  high<=34，预算更紧
```

`low34` 路线并不等于“已经省了十门”。原人工 `79/7` 在低段支付两只 C4 Switch，
高段又支付 C6/C7 owner。新接口删除 resolved C4 后，高段必须同时完成两件事：

```text
1. 直接消费 R23/V3/P23/C2，不能先重建 C4；
2. 至少再吸收一组高位 carry owner，令完整 high<=37。
```

所以对用户问题的严格回答是：

```text
状态共享在七延迟下仍有达到新榜一的结构窗口；
新的 34 门因子接口比晚状态扇出路线明显更可信；
但完整 <=71/7 高段尚未闭合，当前不能声称已经可写入存档。
```
