# `S5/S6/S7/C8 g18/o4/s7` 尾部控制 multiset 固定拓扑完整排列

```text
NOT, NOR, OR, OR
```

本次把这个 multiset 投影到四输出 `S5/S6/S7/C8` 的 `g18/o4/s7` residual，
并穷尽它的全部 `4!/2! = 12` 个唯一槽位排列：

## 完整性与运行

12 个 fixed-kind 约束是 `{NOT,NOR,OR,OR}` 的所有唯一排列；重复的两个 `OR` 通过
multiset 去重，因此不存在重复片。每个排列后面固定七个 `SWITCH`，并由
`physical_exact.py` 强制 exact `components=11/switches=7/xors=0`。

全集约束 SHA：

```text

```

所有结果都在 per-process `800 s` 外层硬超时前结束：

```text
minimum solve time = 90.827 s
maximum solve time = 273.349 s
sum solve time     = 1595.037 s
```

正式 runner 使用四个 worker，`stop_on_first_sat=true`；最终 summary 为
`finished=true/results=12/12 UNSAT`，进程树完全退出。没有把 timeout 或无 JSON 情况
误记为 UNSAT。

## 限定范围

本结论只封闭：

```text
[perm(NOT,NOR,OR,OR), SWITCH, SWITCH, SWITCH, SWITCH, SWITCH, SWITCH, SWITCH]
```

它不能外推到：

1. 其它四 ordinary kind multiset；
2. ordinary 与 Switch 交错、ordinary 读取 resolved Switch BUS 的拓扑；
3. `g18/o6/s6`、含 XOR 的分解或全部 `g18/o4/s7`；
4. paid-source shell 或 residual 接口重写后的完整 Byte Adder。

因此正确表述是“已知 tail ordinary-control multiset 的 terminal-Switch 拓扑类
UNSAT”，不是“四输出 `g18/o4/s7` 全局 UNSAT”。
