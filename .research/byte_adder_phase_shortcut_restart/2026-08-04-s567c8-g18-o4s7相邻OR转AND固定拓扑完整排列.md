## 内存保护与可重放恢复

初始 spec 使用四个 worker、每片 `800 s` 外层硬超时和
`stop_on_first_sat=true`。四片并发时本机 Free RAM 降至约 `2583 MiB`，接近本任务
要求的 `2.5 GiB` 下限，因此没有继续冒险运行：

1. 停止 runner supervisor；
2. 保留优先级最高的三个在途 solver；
3. 干净终止第四片 `AND/NOR/OR/NOT`；
4. 三个保留片写出 UNSAT 后，用相同 24 个约束和相同结果目录的三 worker
   resume spec 恢复；
5. resume 自动复用 3 个已完成结果并求解其余 21 片。

## 限定范围

本结论只封闭：

```text
[perm(NOT,NOR,OR,AND), SWITCH, SWITCH, SWITCH, SWITCH, SWITCH, SWITCH, SWITCH]
```

它不能外推到：

1. 其它四 ordinary kind multiset；
2. ordinary 与 Switch 交错、ordinary 读取 resolved Switch BUS 的拓扑；
3. 完整 `g18/o4/s7`、`g18/o6/s6` 或含 XOR 的分解；
4. paid-source shell 或 residual 接口重写后的完整 Byte Adder。

因此正确表述是“已知 tail multiset 的单步 `OR -> AND` 邻域 terminal-Switch
拓扑类 UNSAT”，不是“四输出 `g18/o4/s7` 全局 UNSAT”。
