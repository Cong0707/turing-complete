## 完备性边界

本结论对上述子域是完整的，但不是全局 `g16` UNSAT。

完备性理由：

1. 加权公式为 `g = components + switches + 2*xors <= 16`。
2. `components=14` 且 C5 已由两个 Switch driver 组成，因此至少 `switches=2`。
3. 于是全部加权余量已耗尽，强制 `switches=2`、`xors=0`。
4. C5 已消费全部两个 Switch。不同输出表示不同函数，物理 driver set 不能共享；T5、S5 因而不可能再是多 Switch driver BUS。
5. 96 行静态等价检查已证明 T5、S5 均不等于 paid source 或常量，因此二者只能各由一个 component output 驱动。
6. 对 `n=14,d=2`，C5 normal form 的合法严格祖先数恰为 `k=0..12`。十三片两两不重叠并覆盖完整子域。

仍未覆盖的全局方向包括 C5 的 `source`、`single_k*` 类，以及较小 component count 下允许额外 Switch/XOR 的类。
