## 完备性边界

加权公式为：

```text
g = components + switches + 2*xors <= 16
```

在 `components=13` 时，`switches + 2*xors <= 3`。C5 的两个 Switch driver 已消费两个
单位，因此强制 `xors=0`，并且全网最多只允许一个额外 Switch。T5 或 S5 若是
multi-driver，至少需要两个与 C5 driver set 不共享的额外 Switch，总数至少为四，超过上限。
96 行静态等价又已证明 T5、S5 均不等于 paid source 或常量，故二者只能各由一个
component output 驱动。

对 `n=13,d=2`，C5 normal form 的合法严格祖先数恰为 `k=0..11`。十二片两两不重叠，
并允许第三个可选 Switch 出现在 C5 driver set 之外。因此本结论封闭整个
`n13/C5=multi_d2` 类，而不是仅封闭一个不完整的 phase 抽样。

本结论不是全局 `g16` UNSAT；它不覆盖 C5 singleton、C5 三 Switch driver，或其它较小
component count。
