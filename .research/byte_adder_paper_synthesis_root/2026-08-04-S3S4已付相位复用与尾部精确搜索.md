### 可安全复用的七个普通门

见证前七个节点都是普通门，始终主动驱动，因此可以作为后续网络的已付费 source。真实
递归到达时间如下：

| 名称 | 公式 | 到达 |
| --- | --- | ---: |
| `u0` | `NOR(Q3, P4)` | 3 |
| `u1` | `NAND(nC3, P3)` | 4 |
| `u2` | `AND(nC3, N3)` | 4 |
| `u3` | `AND(P4, A34n)` | 3 |
| `u4` | `OR(nC3, P3)` | 4 |
| `u5` | `OR(u0, u3)` | 4 |
| `u6` | `NAND(u1, u4) = S3` | 5 |

S4 的最后两个节点是 Switch driver，单独看可能为 Z，不能伪装成免费 Boolean source。
包装器只暴露 `u0..u6`，明确排除这两个 Switch 输出。

```text

```

零组件直连 SAT 正回归。包装器 SHA-256 为：

```text

```

这里的 `u0..u6` 在尾部编码中是接口 source，所以尾部内部 physical-net partition 会被
检查，但这些 source 恢复成真实组件后的全局分区必须在合并阶段重新检查。单独的 tail SAT
不是可部署见证。

## 2026-08-04 / 阶段：封闭 o2/s8 输出双 Switch 正规形

为避免继续把算力浪费在最低价值的 `o2/s8` 排列，新增一个比 generic SAT 更小的精确
枚举。它审查以下正规形：

1. 两个普通门都在八个 Switch 之前；
2. 每个 `S5,S6,S7,C8` 是恰好两个 Switch driver 的 resolved BUS；
3. Switch 的 enable/data 只能读取 D4 以内的 paid source 或这两个普通门；
4. 输出在 D5；
5. 为使结论更强，枚举放宽跨输出分区与组件 liveness。

两类普通门网络都被完整枚举：

```text
独立普通门：
  D4 唯一单门函数         = 1118
  无序函数对              = 625521
  可表示 S5/S6/S7/C8      = 0/0/0/0
  stream SHA256           = f0e5cd79fab9089f6411d9eac005ccfa91a6ee3ebad3d77cd0326cd678dce128

两门依赖链：
  D3 唯一第一门函数       = 752
  拓扑函数对              = 67847
  可表示 S5/S6/S7/C8      = 0/0/0/0
  stream SHA256           = d7e8fd93492aa076dc4aaef53355ef3849e1852bb203d946ad7028564809f8d6
```

`PairSwitchOracle` 的判定条件是：对 driver `(enable,data)`，`enable` 的 support 上必须有
`data==target`；两个合法 enable 的 OR 必须覆盖 486 行全域。独立代理复跑得到完全相同的
计数和哈希，并继续用小宽度直接存在性枚举对拍。

规范证据：


范围边界必须保留：普通门读取 earlier resolved BUS 的交错 `o2/s8` 仍未封闭，所以这不是
完整 `o2/s8` 下界，更不是完整 cost-18 下界。
