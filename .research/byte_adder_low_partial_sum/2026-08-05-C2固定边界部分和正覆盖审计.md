# C2 固定边界的部分和正覆盖审计

日期：2026-08-05

## 结论

本轮只研究已经实机验收的 `85 gate / 6 delay / 510 energy` 架构，不启动游戏，
不修改候选电路，也不触碰正式存档。目标是验证 Maker8 的 `Z -> 0` 合同能否把
低位 Sum 的私有尾部压掉一门，特别是：

```text
C2@2 保持不变
S1 私有尾部 5 门 -> 4 门
```

结果为否：在固定 `C2@2` 的已付费边界上，所有成本不超过 4 的合法形态都没有
闭合。因而不能据此物化 `84/6`。

## 权威输入与边界

```text
.research/byte_adder_architecture_restart/
byte-adder-human85-s3-positive-phase-full.json
```

该 DAG 的低位边界源为：

```text
a0, a1, b0, b1, cin
B0partial (#18, arrival 1, may-Z)
G1        (#19, arrival 1)
V1        (#20, arrival 1)
G0        (#21, arrival 1)
C2        (#26, arrival 2, may-Z)
Q0/P0/S0  (#22/#23/#45, 已存在但不属于 S1 私有尾)
```

当前 `S1` 私有节点是：

```text
#36 C1phase       OR(G0,B0partial)       @2
#37 S1_nand_left  NAND(G1,C1phase)       @3
#38 S1_nand_right NAND(#37,C2)            @4
#39 S1_or         OR(C1phase,V1)          @3
#46 S1            AND(#39,#38)             @5
```

总成本为 `5`。普通门读取 `Z` 时按 active `0`，Switch 的 enable 读取 `Z` 时等同
关闭；因此内部 Switch 不能凭空保留第三逻辑值，只有最终 Maker8 lane 可以把未驱动
的零行归一化为 active `0`。

## 形态完备的成本分类

在一个最终 Sum lane 上，成本不超过 4 的新网络只可能属于以下类别：

1. 四只普通一门元件（`AND/NAND/OR/NOR`，NOT 可由同输入 NAND/NOR 得到）；
2. 一个最终 Switch（2 门）加至多两只普通门；
3. 两只最终 Switch（4 门）组成一个完整 resolved BUS owner；
4. 一只 `XOR`（3 门）或 `XOR` 加一只普通门；
5. 内部 Switch 后再接普通门不会增加能力：普通逻辑输入会把其 Z 读成 0，
   同功能的内部 AND 只需 1 门，所以不可能成为成本不超过 4 的最优形态。

这覆盖了允许 Maker8 对零行做 `Z -> 0` 的所有单输出拓扑；没有把普通 XOR 错算成
`1/3`，这里按游戏实际 `3 gate / 2 delay` 计费。

## 精确结果

### 四门普通 DAG

用当前 `Factory DAG` 的完整逻辑状态，压缩到低位 32 个等价输入行，对任意有内部
fanout 的四门拓扑作 CNF 闭包，源集合包含上面的全部已付费低位相位及原始输入。

```text
target                         S1 (#46)
compressed rows                32
ordinary gate bound            4
arrival limit                  7（放宽；D6 要求更严）
status                         UNSAT
```

将同一个检查收紧到 arrival `6` 仍为 `UNSAT`。五门回归为 `SAT`，解正好投影到现有
`#36/#37/#38/#39/#46` 五门尾部；因此不是编码器误报。

### 最终 Switch 正覆盖

对每一只最终 Switch，驱动函数是 `enable & data`；两只 Switch 的正集并集必须
覆盖 S1 的全部 `1` 行，且重叠开启时 data 必须同值，否则会产生真实 BUS conflict。

```text
两只 source-to-source Switch（4 门）       0 个覆盖
一只 Switch + 一门普通门（3 门）           0 个覆盖
一只 Switch + 两门普通门（4 门）           0 个覆盖
两只一门普通门后接一只 Switch（4 门）      0 个覆盖
```

`Q0/P0/S0` 也加入 source pool 后结果不变。对全 DAG 中 arrival 不超过 5 且不属于
目标私有锥的现有节点做同样的两 Switch 正覆盖扫描，S1 共得到 14 个合法
`enable/data` 正项，但没有一组能覆盖完整 `S1=1` 集；S0、S3 分别得到 4 和 20 个
正项，对应也都是 `0` 组闭合。按真值 mask 去重时三者分别为 1、7、10 个；两种计数
口径结论一致。

### XOR 形态

```text
XOR(source, source)                           0 命中
一门普通逻辑 -> XOR                         0 命中
XOR -> 一门普通逻辑                         0 命中
```

所有候选均按 XOR 的实际 `3/2` 成本和 arrival 规则计算。

## 为什么 `D0/N0` 共享仍不能省门

S0 的 reduced-state 公式会产生：

```text
N0 = NAND(G0, cin)
D0 = NAND(C1, N0)
```

在合法输入域上确实有：

```text
C1 = NAND(D0, N0)
```

但把 `C1` 删除后，S1 仍必须区分 bit1 的 `P/G` 两相位。对源集合
`{D0,N0,G1,V1,C2}`（再加入所有原始低位输入也不改变结论）作精确闭包：

```text
S1 ordinary 3 gates       UNSAT
S1 ordinary 4 gates       UNSAT
```

所以 `D0/N0` 不能同时替代 C1 并让 S1 尾部少于原五门。

## 物理合同

- 任何被动 `Z` 行只允许在最终 Maker8 处按 0 读取；不能作为跨 owner 的第三值。
- 两个 Switch 共用 data 时重叠可以安全；不同 data 的重叠必须逐行证明同值或互斥。
- endpoint、pin、tap 和 foreign wire 规则与逻辑结果无关，本轮没有生成布局候选。
- `C2` 必须继续在 arrival 2 直接供 bits2/3 的后继 owner；将其显式 OR 到 arrival 3
  会把 `R23` 和后续高位 Switch 推迟，不能计作同延迟方案。
