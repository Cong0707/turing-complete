# Byte Adder C1/S1 五门因式分解与四门阻塞

日期：2026-08-05

## 结论

本轮只研究 Patchouli `84/6/504` 中固定 `C2@2` 三 driver owner 合同下的：

```text
{C1,S1} 5 gate -> 4 gate
```

没有使用 SAT、PySAT、函数池、门序列枚举、随机搜索、布局或游戏进程。

令：

```text
T0 = Cin*(A0 OR B0)          # two-Switch BUS 的 effective value
G0 = A0*B0
C1 = T0 OR G0

V1 = A1 OR B1
G1 = A1*B1
P1 = V1 AND NOT G1

C2 = G1 OR P1*C1
   = V1*(G1 OR T0 OR G0)
```

合法 K/P/G 状态满足严格蕴含链：

```text
G1 <= C2 <= V1
```

于是 `S1` 可以看成 `{C1,V1,G1}` 三个 bit 的奇偶位，而 `C2` 正好是这三个 bit
“至少两个为 1”的阈值位：

```text
S1 = C1 XOR V1 XOR G1
```

当前 `C1` 一门加 `S1` 四门尾不是偶然拼接，而是一只 XOR-free 的三输入人口计数
单元。手工检查了不显式物化 `C1`、改用 `T0/G0/C2`、正负 carry、carry-select 与
partial-Z 输出等因式分解，均没有得到诚实的四门完整结构。

这不是所有可能游戏电路的全局四门不可实现证明；它关闭的是固定 `C2@2` owner 和
当前 paid basis 下的直接因式分解路线。

## 一、六个合法状态

只需考虑 `C1` 与 bit1 的 K/P/G 状态：

```text
bit1  V1  G1  P1   C1   C2   S1
K      0   0   0    0    0    0
K      0   0   0    1    0    1
P      1   0   1    0    0    1
P      1   0   1    1    1    0
G      1   1   0    0    1    0
G      1   1   0    1    1    1
```

因此：

```text
K/G: S1=C1
P:   S1=NOT C1
```

也就是：

```text
S1 = C1 XOR P1
   = C1 XOR V1 XOR G1
```

由于 `G1=>V1`，最后一个等式在合法 K/P/G 域严格成立。

## 二、当前四门尾的人口计数解释

对 `{C1,V1,G1}` 考虑取值个数。合法状态中：

```text
C2 = 1  <=>  至少两个输入为 1
```

定义：

```text
Z0 = NOR(C1,V1)              # 三输入全零
N3 = NAND(C1,G1)             # 不是三输入全一
E2 = AND(C2,N3)              # 恰好两个为一
S1 = NOR(Z0,E2)              # 排除 0 个和 2 个一
```

逐门为：

```text
C1 = OR(T0,G0)               1 gate @2
Z0 = NOR(C1,V1)              1 gate @3
N3 = NAND(C1,G1)             1 gate @3
E2 = AND(C2,N3)              1 gate @4
S1 = NOR(Z0,E2)              1 gate @5
```

总计：

```text
5 gate / D5
```

当前 DAG 使用的是完全等价的 De Morgan 相位：

```text
U1 = OR(C1,V1)               = NOT Z0
F1 = NAND(N3,C2)             = NOT E2
S1 = AND(U1,F1)
```

所以当前结构已经共享了 `C1` 的两个相反 care-domain：

```text
C1 与 V1 识别全零；
C1 与 G1 识别全一；
C2 再把“至少两个”收紧为“恰好两个”。
```

## 三、为什么直接删除 C1 只会复制共因子

把 `C1=T0 OR G0` 展开：

```text
Z0 = NOT(T0 OR G0 OR V1)
N3 = NOT(G1*(T0 OR G0))
```

两条相位都需要同一个：

```text
T0 OR G0
```

但使用方向相反：

```text
Z0 需要它进入 OR 零检测；
N3 需要它进入 AND 全一检测。
```

当前一只 `OR(T0,G0)` 正是这两个消费者的最小公共子表达式。若不物化 `C1`：

```text
三输入 NOR(T0,G0,V1)              2 gate
G1*(T0 OR G0) 的 NAND 相位         至少 2 gate
E2/S1                              2 gate
-----------------------------------------
总计                               至少 6 gate
```

游戏中的三输入 OR/NOR 虽然只有一层延迟，但真实门成本是 `2`，不能按一门计算。

## 四、为什么换一个公共中间仍未省门

### 4.1 先生成 U1

```text
U1 = C1 OR V1
```

`U1` 在 `V1=1` 时丢失 `C1`。而 `N3` 恰好需要在 `G1=1,V1=1` 的域继续区分
`C1=0/1`，所以不能由 `U1/G1/C2` 一门恢复。

### 4.2 先生成 N3

```text
N3 = NAND(C1,G1)
```

`N3` 在 `G1=0` 时恒为一。全零检测却必须在 bit1=K 时区分 `C1=0/1`，所以不能由
`N3/V1/C2` 一门恢复 `Z0`。

### 4.3 改用 nC1

```text
nC1 = NOR(T0,G0)
```

只是把同一个公共相位翻相。`S1` 仍需同时形成：

```text
P1*nC1
nP1*C1
```

其中 `P1=V1*NOT G1` 在当前 `V1/G1` basis 上不是一门函数。负相 carry 没有减少
人口计数所需的两种极端状态检测。

## 五、C2 的蕴含链为什么不能直接给出 P1 相位

合法状态中：

```text
G1 <= C2 <= V1
```

因此对这三条 rail 中任意两条使用一只普通二输入门，只会退化为原 rail 或其反相：

```text
AND(G1,C2)  = G1
OR(G1,C2)   = C2
NAND(G1,C2) = NOT G1
NOR(G1,C2)  = NOT C2

AND(C2,V1)  = C2
OR(C2,V1)   = V1
NAND(C2,V1) = NOT C2
NOR(C2,V1)  = NOT V1
```

但传播相位是蕴含链中的差集：

```text
P1 = V1 AND NOT G1
```

差集至少还需要反相和相交两个动作。不能把 `C2/V1/G1` 中任意两条接到一门
AND/NAND/OR/NOR 后，直接得到 `P1*C1` 或 `P1*nC1`。

## 六、C2 的物理 Z 也不能充当额外状态位

`#26 C2` 的三 driver owner 满足：

```text
driven(C2) = T0 OR G0 OR G1
value(C2)  = V1*(T0 OR G0 OR G1)
```

关键反例：

```text
bit1=K, C1=1:
C2 = active zero
S1 = 1
```

若把 `C2` 物理输出直接并入 `S1` owner，再增加一个 one driver，原 active-zero 会与
one driver 产生真实冲突，而不是自动变成 Z。

另一个反例：

```text
bit1=P, C1=0:
C2 = Z
S1 = 1
```

普通门、Switch enable 和 enabled Switch data 都只读取 `C2.effective=0`，无法读取
“它原来是 Z”这一元信息。因此不能借 `C2` 的 active-zero/Z 分布免费实现反相。

## 七、carry-select、carry-skip 与双轨账本

### carry-select

预计算：

```text
C1=0 -> S1=P1
C1=1 -> S1=nP1
```

需要 `P1/nP1` 双相和两个选择 driver。U1 Switch 每只真实成本 `2 gate / 1 delay`，
两 driver 已经四门，尚未计算 `P1/nP1`，严格差于当前五门完整结构。

### carry-skip

`C2@2` 已经是：

```text
G1 OR P1*C1
```

的 common-data Switch 实现。它是 carry-skip/prefix reason，不暴露 `P1` 差集，也
不暴露 driven mask predicate；不能再免费拆出选择信号。

### 正负 carry 双轨

增加：

```text
nC2 = NOT C2
```

至少一门。虽然可以把 `S1` 写成：

```text
J1 = G1*C1
U1 = C1 OR V1
K1 = nC2*U1
S1 = J1 OR K1
```

但这是 `nC2` 之外的四门，局部账本变为六门。只有当 `nC2` 同时在
`S2/S3/B23` 中净替代另一门时才值得；现有 encoded-C2 联合架构已经证明这一交换
只能打平 `42` 门。

## 八、结论边界

固定：

```text
T0@1
G0/V1/G1@1
C2@2 三 driver owner
ordinary AND/NAND/OR/NOR 真实成本 1
三输入 gate 真实成本 2
```

当前最紧凑、手工可解释的 `{C1,S1}` 仍为：

```text
C1                         1
zero-count phase           1
not-all-three phase        1
exactly-two phase          1
final parity               1
----------------------------
total                      5
```

本轮没有得到 `5 -> 4`，因此没有生成候选、没有覆盖正式存档。

下一步不能继续单独改 `S1`，必须把：

```text
{C2,B23,S1,S2,S3}
```

作为一个多输出 prefix/sum cell 重画，让某条正负 carry 相位同时替代至少两个现有
节点，才可能得到全局 `83/6`。
