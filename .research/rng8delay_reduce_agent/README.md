本目录只做离线研究，不启动游戏、不读取或写入正式存档。

目标是审计已实机通过的 `468/8/67` 双轨开关数据面，并在真实元件成本下寻找改进：

```text
普通 XOR / U1 XOR  3 gate / 2 delay
Bit Switch          2 gate / 1 delay
NOT/AND/OR/NAND/NOR 1 gate / 1 delay
Delay Bit           5 gate / 4 delay
```

关键补充模型：不是所有末级 XOR 都必须用两只 Switch。若一个末级 XOR 的所有一级
pair 在装载拍标签均为零，则这些 pair 的稳态到达时间为 `4+2=6`，可以使用一个正常
`3 gate / 2 delay` XOR 在总延迟 8 内完成。原精确模型无条件把所有末级都记作
`4 gate` Switch 宏，并额外要求 pair 反相轨和 direct NOT；这里联合选择 native/Switch
末级，寻找此前可能漏掉的一门改进。
