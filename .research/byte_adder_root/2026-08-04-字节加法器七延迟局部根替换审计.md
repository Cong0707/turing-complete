# 字节加法器七延迟局部根替换审计

## 结论

本轮没有生成新的可部署候选。权威 `80 gate / 7 delay / 560 energy` DAG 中，四个最有
希望的输出私有锥在下述明确范围内均不能各省一门：

```text
S0 node 49：私有 4 门 -> 不存在 3 ordinary 替换
S6 node 73：私有 4 门 -> 不存在 3 ordinary 替换
S2 node 81：私有 5 门 -> 不存在 4 ordinary DAG 替换
S4 node 86：私有 5 门 -> 不存在 4 ordinary DAG 替换
```

这里的 ordinary 为 `NOT/AND/NAND/OR/NOR`，每个均按 `1 gate / 1 delay` 计费。
`NOT` 在 SAT 模型中由同输入 NAND/NOR 完整覆盖。所有目标截止时间均为 D7。

## 三门根替换

`audit_80d7_three_gate_roots.py` 对 S0、S6 枚举了全部 live 三门拓扑：

- 三门链，包括第一门同时扇出到第二、第三门；
- 两个独立首门加一个合并末门；
- 每个源向量均从完整 `2^17=131072` 行投影，并先验证相同源向量不会对应不同目标值。

结果：

```text
S0：压缩 8 行，35 个首门函数，568 个依赖二门函数，18852 次末门检查，0 hit
S6：压缩 32 行，434 个首门函数，25113 个依赖二门函数，1361405 次末门检查，0 hit
```

## 四门任意 DAG

同一脚本先对 S2、S4 枚举 cost=4 的完整普通门公式树闭包：

```text
S2 exact-cost function counts = 17, 346, 5918, 59794, 514060；目标未出现
S4 exact-cost function counts = 17, 382, 6596, 66790, 568028；目标未出现
```

公式树不能覆盖内部节点向两个后继扇出的所有 DAG，因此又由
`audit_80d7_four_gate_dag_sat.py` 建立独立 SAT 模型。模型包含：

- 四个拓扑有序的普通门，每门两个输入可任意选 retained source 或更早的合成门；
- 每个前三门必须被至少一个后继使用，等价保证全部位于末门后向切片；
- 每个 source、合成门和目标在压缩域上的精确真值；
- source 的权威到达时间与每一级至少增加一延迟的约束；
- 最终输出到达不超过 7。

双求解器独立结果：

```text
S2 four-gate：576 variables / 8659 clauses / CaDiCaL UNSAT / Glucose42 UNSAT
S4 four-gate：576 variables / 8715 clauses / CaDiCaL UNSAT / Glucose42 UNSAT
```

## 正回归

为排除选择器、到达约束或真值编码过强造成的假 UNSAT，同一编码只把门数从 4 改为 5。
CaDiCaL 与 Glucose42 均为两个目标找到 SAT witness；解码后再次用原始位并行真值检查：

```text
S2：725 variables / 11371 clauses / SAT / 131072 行通过 / arrival 7
S4：725 variables / 11441 clauses / SAT / 131072 行通过 / arrival 7
```

正回归重建的结构与现有五门私有锥等价，但两个求解器可以给出不同的等价门排列，证明
负结果不是依赖某个硬编码见证。

## 严格边界

本结论不是全局 `79/7` 下界，也不覆盖：

- `2 ordinary + 1 Switch`、`2 Switch`、`1 ordinary + 1 XOR/XNOR` 等精确成本 4 混合；
- 改写 retained source 本身或跨多个输出联合共享；
- 显式 source pool 以外的全 DAG 信号；
- 任何 D6/D5 全局前缀结构。

下一步已经转向上述 weighted-cost4 混合，并继续并行推进 bit3:4、suffix567、D6 carry
retime 与 D5 Hub33 function-map。只有完整候选严格低于 560 且通过全链审计时才覆盖存档。
