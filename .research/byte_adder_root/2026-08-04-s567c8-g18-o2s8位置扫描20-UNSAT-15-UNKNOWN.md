
## Runner 恢复语义

纳入证据的 runner：

```text
.research/byte_adder_root/run_o2s8_position_sweep.sh
```

静态检查及远端 `bash -n` 均通过。它具备以下保护：

```text
external timeout + TERM/KILL-after
per-run atomic .tmp -> .run.json
SAT_FOUND atomic marker and stop check
existing .run.json skip for interrupted-run resume
missing payload => status=missing, never UNSAT
```

恢复边界必须明确：已经存在 `.run.json` 的 timeout pair 会被跳过，因此直接重跑
该脚本不会自动精化这 15 个 UNKNOWN。它只会补齐尚无 run marker 的中断任务。
另外，当前源码默认 `AS_KIB=6291456`；在 1.25 GiB 约束下使用时必须显式设置
`AS_KIB=1310720`。15 个 UNKNOWN 的 concrete-kind 精化应使用独立 runner。
