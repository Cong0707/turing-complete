# 字节加法器混合门局部公式封闭

## 结论

本轮没有生成新的可部署候选，正式存档未被覆盖。对已实机验收的
`80 gate / 7 delay / 560 energy` 权威 DAG，下列四个输出私有锥在明确的
局部 source pool 上均没有找到省一门的混合公式树：

| 输出 | 原私有成本 | 替换成本 | 压缩真值行 | D7 终态数 | 其中全驱动 | 结果 |
|---|---:|---:|---:|---:|---:|---|
| S0 / node 49 | 4 | 3 | 8 | 428 | 226 | UNSAT |
| S6 / node 73 | 4 | 3 | 48 | 70,416 | 62,710 | UNSAT |
| S2 / node 81 | 5 | 4 | 48 | 666,373 | 509,384 | UNSAT |
| S4 / node 86 | 5 | 4 | 48 | 679,765 | 513,866 | UNSAT |

这里的 `UNSAT` 严格限定为：

> 在各自显式审查过的 source pool 上，不存在总成本恰为 3 或 4、
> 输出到达不超过 7、最终全驱动且无冲突的混合公式树。

它不是任意内部扇出 DAG 的下界，也不是全局 `79/7` 下界。

## 组件语义与计费

本轮严格使用当前版本已确认的成本：

```text
NOT / AND / NAND / OR / NOR = 1 gate / 1 delay
Bit Switch                  = 2 gate / 1 delay
XOR / XNOR                  = 3 gate / 2 delay
```

高阻并非被压成普通布尔函数。搜索状态同时保留：

```text
bits
driven
conflict
arrival
```

一个 Switch 以完整单驱动 BUS 建模，成本 2、延迟 1；两个 Switch
可组成一个双驱动解析 BUS，总成本 4。S2 和 S4 的 cost-4 层均显式
枚举了：

```text
17 个零成本源
17² = 289 个有序 (enable,data) 驱动对
289×290/2 = 41,905 个无序双驱动 BUS 组合
```

因此本轮不是只把 Switch 当作 MUX，而是直接审查高阻、驱动覆盖和
0/1 冲突。

## 枚举完备性

对任意给定的精确成本 `c`，闭包递推包含：

1. `NOT(child)`，子式成本 `c-1`；
2. 普通二输入门，穷尽 `left_cost + right_cost + 1 = c`；
3. 单驱动 BUS，穷尽 `enable_cost + data_cost + 2 = c`；
4. XOR/XNOR，穷尽 `left_cost + right_cost + 3 = c`；
5. `c=4` 时，额外穷尽两个原始 Switch 驱动共享一个 BUS。

对相同精确成本和相同 `(bits,driven)` 状态，只保留最早到达的见证。
所有支持的运算都会单调传播已有 conflict，因此冲突状态不可能在后续
变回合法公开输出，可以安全剪枝。到达已经大于 7 的状态也不可能被
后续元件缩短，同样安全剪枝。

## 验证

### 完整输入域

独立审计器不导入枚举 worker，而是从权威 Factory DAG 重新对
`A:U8 × B:U8 × Cin:U1` 的 `131072` 行分区，四个 target 均得到：

```text
source signature 映射冲突 = 0
public target driven            = ALL
public target conflict          = 0
```

### 拓扑尝试数独立复算

审计器仅使用每层记录的状态数，独立重新推导：

- 普通门的无序子式成本分割；
- Switch 的有序 enable/data 成本分割；
- XOR/XNOR 的无序子式成本分割；
- cost-4 双驱动 BUS 的 `n(n+1)/2` 组合数。

四个 target 的所有层均与 worker 记录逐项相等，独立审计结果：

```text
status = pass
errors = []
```

### 正回归与确定性

六个单元测试覆盖：

```text
单 Switch 的高阻 driven 状态
双 Switch 0/1 冲突检测
Switch -> NOT 的合法混合正回归
XOR 的 cost=3 / delay=2 正回归
cost=4 双驱动 BUS 枚举正回归
非法冲突公开目标拒绝
```

结果为 `6/6 OK`。完整四 target 运行另独重跑一次，去除墙钟时间和
绝对路径后，两次规范化负载哈希完全一致：

```text
4eab8130f48372e3f79005d9a33751c9051c9ac47d71895ce3d4ebeea6b1aeba
```

## 边界

本轮没有覆盖：

- 一个内部节点同时扇出到两个或更多后继的任意 DAG；
- 重写 retained source 本身；
- 跨多个输出的联合共享；
- 全局 D6/D5 前缀结构；
- source pool 之外的任意中间信号。

下一步继续由 connected-cut、条件和、suffix physical SAT、D6 carry retime
和混合高阻全局编码并行推进。
