# 字节加法器混合门任意扇出局部封闭

## 结论

本轮没有生成新的可部署候选，正式存档继续保持已实机验收的
`80 gate / 7 delay / 560 energy`。在权威 Factory DAG 的 S2、S4 两个
明确 source pool 上，精确 SAT 编码封闭了此前公式树没有覆盖的最后一种
cost-4 局部组合：

```text
components       = 3
ordinary gates   = 2
Switch           = 1
XOR/XNOR         = 0
weighted gate    = 1 + 1 + 2 = 4
output deadline  = 7
internal fanout  = arbitrary
```

S2 和 S4 在不加入常量以及加入免费 `0/1` 常量的两种 source pool 中，
均由 CaDiCaL195 与 Glucose42 独立返回 `UNSAT`：

| 输出 | 常量 | variables | clauses | CNF SHA256 | 结果 |
|---|---|---:|---:|---|---|
| S2 | 否 | 2,845 | 28,434 | `3d74901c...a7d123` | 双求解器 UNSAT |
| S4 | 否 | 2,845 | 28,791 | `fc2a2c8...dff278` | 双求解器 UNSAT |
| S2 | 免费 0/1 | 2,931 | 31,162 | `19c7b5dd...abbb6` | 双求解器 UNSAT |
| S4 | 免费 0/1 | 2,931 | 31,519 | `d13e13d3...954f6` | 双求解器 UNSAT |

这里的结论严格限定为上述 source pool、元件配额和 D7 deadline。它不是
全局 `79/7` 下界，也不排除跨输出共享、重写 retained source、D6/D5 前缀
或 source pool 外的新中间信号。

## 为什么需要本轮

上一轮混合公式树已经覆盖：

- 普通门公式树；
- 单 Switch 高阻 BUS；
- 双 Switch resolved BUS；
- ordinary 与 XOR/XNOR 的公式组合。

但公式树不能表示一个中间节点同时供多个后继读取。对 S2/S4 的精确
cost-4 分类而言，唯一尚未被其它完整搜索覆盖的组合，就是两个普通门与
一个 Switch 形成的三组件 DAG。本轮不再固定公式形状，而是让每个后继
从所有原始源和所有更早组件中自由选择输入 BUS，因此包含内部任意扇出。

## 编码语义

本轮采用游戏当前版本已经实机确认的成本和延迟：

```text
NOT / AND / NAND / OR / NOR = 1 gate / 1 delay
XOR                         = 3 gate / 2 delay
Switch                      = 2 gate / 1 delay
```

每个 compact truth row 都同时编码：

```text
value
driven
resolved BUS conflict
```

Switch 关闭时输出 Z，不会被折叠为普通布尔值。任意 BUS 的 0 驱动和 1
驱动不能同时出现；多个 driver 只能来自 Switch 输出。物理网还满足分区
约束：两个 BUS 如果共享任何输出引脚，就必须拥有完全相同的 driver 集合，
从而禁止一个 Switch 输出被错误复用成两个互相隔离的 resolved net。

编码另含：

- 精确一个 Switch、零个 XOR；
- 总成本不超过 4；
- 所有三个组件必须存活；
- 后继只能读取原始源或拓扑序中更早的组件；
- 递归到达时间不超过 7；
- 最终输出必须全驱动且无冲突；
- S2/S4 各自 131072 行到 compact 48 行的严格确定映射。

## 双求解器与正回归

每个负例切片都用同一顺序生成 CNF，再分别交给 CaDiCaL195 和
Glucose42。独立审计确认每一对记录的 variables、clauses、CNF SHA256
完全一致，两个求解器均返回 `UNSAT`。

为了排除“编码过强导致一律 UNSAT”，同一编码器改成五个普通门、成本 5，
对 S2/S4 各运行两种求解器。四次均返回 `SAT`：

| 输出 | variables | clauses | CNF SHA256 | 实际门数 | 实际到达 |
|---|---:|---:|---|---:|---:|
| S2 | 6,086 | 58,210 | `7624681e...4666d2` | 5 | 7 |
| S4 | 6,086 | 58,799 | `84a95f76...f300` | 5 | 7 |

四个见证均由独立审计器重新执行完整 131072 行，结果一致：

```text
mismatch_count                         = 0
conflict_assignment_count              = 0
undriven_output_count                  = 0
physical_net_partition_violation_count = 0
dead_component_count                   = 0
actual_gate                            = 5
actual_output_arrival                  = 7
```

## 独立审计边界

`audit_80d7_weighted_cost4_fanout.py` 不导入 SAT 求解 worker。它独立完成：

1. 从权威 DAG 重建 S2/S4 的 131072 行状态；
2. 重新计算 compact source partition，均为 48 行且 target 映射冲突为 0；
3. 核对 12 个结果文件的配额、依赖、source pool、CNF 指纹与状态；
4. 核对六组 CaDiCaL195/Glucose42 CNF 完全相同；
5. 对四个 SAT 正见证重算 value、driven、Z、BUS conflict、时序、成本、
   liveness 和 physical-net partition；
6. 把每个正见证完整重放到 131072 行。

审计结果：

```text
status  = pass
records = 12
errors  = []
```

负例没有生成 DRAT/LRAT proof trace，因此本报告准确表述为“双求解器、同
CNF 的局部实验封闭”，不把结果冒充可独立检查的形式证明。

## 与既有局部封闭的合并解释

在各自明确 source pool 内，当前可安全合并的局部结论是：

- S0/S6：三普通门任意拓扑与 exact-cost-3 混合公式树均已覆盖；
- S2/S4：四普通门任意 DAG 已由双求解器封闭；
- S2/S4：双 Switch、ordinary+XOR/XNOR 已由混合公式树覆盖；
- S2/S4：两个 ordinary 加一个 Switch 的任意扇出 DAG 由本轮封闭。

这说明继续逐个替换 S2/S4 私有根的收益已经很低。后续算力应转向：

- connected multi-output cut；
- bit3:5 的 n12 联合重编码；
- D6/D5 carry retiming；
- 跨输出共享的高阻多驱动结构；
- 同 D7 下全局减门和减能耗，而不是继续枚举同一局部输出。
