# 字节加法器区间动态规划阶段冻结

## 2026-08-03 / 任务边界

本分支只研究 Byte Adder 的数学结构和离线精确枚举方案，没有启动游戏，没有读取或修改
正式存档，没有生成候选电路，也没有执行 Git 提交或推送。本轮收到主任务的统一暂存通知后
立即停止继续实现和枚举。

固定成本模型如下：

| 元件 | gate | delay |
| --- | ---: | ---: |
| NOT / AND / OR / NAND / NOR | 1 | 1 |
| XOR / XNOR | 3 | 2 |
| Bit Switch driver | 2 | 1 |
| wire / split / make / index / concat | 0 | 0 |

多驱动 BUS 只允许以下情况：关闭的 Switch 退出驱动集合；所有同时开启的驱动数据完全
一致。若同时出现主动 0 和主动 1，就是短路，不能按 wired-OR 处理。Switch 的 data 为 Z、
enable 为 1 时会重新主动驱动数据面 0，因此 Z 不能沿 Switch data 链自动传播。

## 完整测试边界

既有协议证书已经证明 Byte Adder 的测试覆盖完整的
`U8 A * U8 B * U1 Cin = 131072` 个输入，并且每个输入恰好出现一次。因此区间 DP 只能
用于枚举真实等价电路，不能使用样本特化。

任何后续机器证书必须同时给出：

1. `131072/131072` 的 `Sum[7:0]` 与 `Cout` 真值一致；
2. 每条多驱动 BUS 在全部输入下的冲突掩码为零；
3. 最终九个输出在全部输入下均为主动驱动，而不是仅依赖全 Z 数据面为零；
4. 从原始输入到每个输出的精确最大到达时间；
5. 对结构族的枚举计数、Pareto 支配规则和可复现摘要哈希。

## 进位区间的三种精确编码

对任意连续区间，把它看作单调进位传递函数 `F(c)`。它只有三种状态：

```text
K: F(0)=0, F(1)=0
P: F(0)=0, F(1)=1
G: F(0)=1, F(1)=1
```

### `G/P` 编码

`G` 表示无条件生成，`P` 表示传递。高区间 `H` 接在低区间 `L` 后面时：

```text
Gout = GH OR (PH AND GL)
Pout = PH AND PL
```

普通 black cell 是 `3 gate / 2 delay`。若 `GH` 与 `PH` 保持互斥，生成项还可写成：

```text
Gout = BUS(
  Switch(enable=GH, data=1),
  Switch(enable=PH, data=GL)
)
```

它与 `Pout = PH AND PL` 合计 `5 gate / 1 delay`。只求实际进位的 gray cell 为：

```text
Cout = GH OR (PH AND Cin)                 # 2 gate / 2 delay
Cout = BUS(Switch(GH, 1), Switch(PH,Cin)) # 4 gate / 1 delay
```

两个 Switch 的活动域互斥，因此无冲突。

### `G/K` 一热编码

`G` 和 `K` 可分别由 `A AND B` 与 `NOR(A,B)` 在一层得到；`P=NOR(G,K)` 再增加一门。
它适合保留三态语义和做相位审计，但独立组合两个输出时通常不如 `G/P` 紧凑。

### 条件双轨 `U/V`

定义：

```text
U = F(0) = G
V = F(1) = NOT K
```

始终有 `U <= V`。单个位的两个轨可直接由：

```text
U = A AND B
V = A OR B
```

以 `2 gate / 1 delay` 同时产生。区间组合为：

```text
Uout = HU OR (HV AND LU)
Vout = HU OR (HV AND LV)
```

普通双轨 cell 合计 `4 gate / 2 delay`。实际进位为：

```text
Cout = U OR (V AND Cin)
```

普通实现是 `2/2`。单个输出也可利用蕴含关系 `U => V` 写成一致多驱动 BUS：

```text
Cout = BUS(Switch(U,1), Switch(Cin,V))
```

当两个 driver 同时活动时，`U=1` 必然推出 `V=1`，所以它们都驱动 1；其余输入也不会
出现 0/1 冲突。成本为 `4/1`。同理：

```text
Uout = BUS(Switch(HU,1), Switch(LU,HV))
Vout = BUS(Switch(HU,1), Switch(LV,HV))
```

每轨 `4/1`，双轨共 `8/1`。这给出了“加门换层数”的精确局部 Pareto 点。

## 相位编码与 Ripple 共享

另一个有用编码是：

```text
N = NOT G = NAND(A,B)
V = NOT K = OR(A,B)
P = N AND V
```

`N/V` 两轨只需 `2/1`，`P` 再需一门。对实际进位有二 NAND 恒等式：

```text
Cout = NAND(N, NAND(V,Cin))
```

若同时生成 sum，可用七门共享全加器：

```text
N = NAND(A,B)
V = OR(A,B)
P = AND(N,V)
T = NAND(Cin,P)
Cout = NAND(N,T)
O = OR(Cin,P)
Sum = AND(T,O)
```

总成本 `7 gate`。输入同时到达时首位 `Sum/Cout` 都在第 4 层；后续进位每位增加两层，
八位 Ripple 因此是既有 `56/18` 结构。该公式解释了为什么单独为 carry 和 sum 计费会
丢失跨输出共享，后续 DP 必须以“可达节点集合的并集成本”而不是逐输出成本相加。

## 延迟预算的硬约束

若采用常规 `P XOR Carry` 作为 sum 尾层，最后 XOR 固定增加 `2 delay`。因此：

| 总延迟目标 | `C1..C7` 最迟到达 | gate 上限（严格优于 515） |
| ---: | ---: | ---: |
| 5 | 3 | 102 |
| 6 | 4 | 85 |
| 7 | 5 | 73 |

逐位同时产生 `P/G` 再做八个 sum 的固定账本已经是：

```text
8 * shared(P,G) = 24 gate
8 * XOR(P,C)    = 24 gate
合计             = 48 gate
```

所以 `102/5` 只给完整 carry 网络留下 54 门；`85/6` 留 37 门；`73/7` 只留 25 门。
最后一个预算甚至低于许多常规前缀网络本身，说明要达到 `<=73/7`，必须同时共享 sum 与
carry 的相位节点，不能只替换前缀拓扑。

条件双轨 `U/V` 的叶子只需 16 门，但从 `U/V` 恢复 `P` 再输出 sum 仍需每位 4 门，固定
账本仍是 48 门。它的优势是 transfer combine 的局部 Pareto，而不是直接减少 sum 成本。

## 已校准的局部单元

公开 `2e64a/ADD_u0` 的文件头是 `4/1`，内部正好两只 Bit Switch；这与一输出 Switch
gray cell 的推导一致。`ADD_u1` 是 `5/2`，内部为两只 Bit Switch 加一只 OR，说明公开
实物也在使用“Switch 合并生成轨、普通门维护传播轨”的混合单元。

公开二位 `Add_2` 是 `25/5`，其同 data 多驱动结构等价于：

```text
D AND (e0 OR e1 OR ...)
```

因为所有活动 driver 的 data 都是同一个 `D`，enable 可以重叠且仍不冲突。这一模式应
作为后续区间 DP 的 BUS 产生规则，而不是把多驱动错误建模为 wired-OR。

## 计划中的精确多目标 DP

后续实现应只在本目录创建脚本，建议状态为：

```text
State(interval, encoding, output_phase,
      gate_node_set, arrival_vector, driven_mask, conflict_mask)
```

核心规则：

1. 对长度 1 的区间枚举 `G/P`、`G/K/P`、`U/V`、`N/V` 叶编码；
2. 对每个连续区间和每个切分点，枚举普通 black/gray cell 与 Switch BUS cell；
3. 对每个长度枚举全部有序 block partition，并加入 ripple 与 conditional-sum 组合；
4. 普通选择器和双 Switch 选择器都纳入，但按实际共享反相信号计费；
5. canonical node interning 后，以输出 backward slice 的节点并集精确计 gate，覆盖跨 carry、
   sum 和相邻 block 的公共子表达式；
6. Pareto 支配至少比较 gate、逐轨到达时间、Z 掩码、冲突掩码和节点集合包含关系；
7. packed truth table 使用 131072 位整数或等价 bitset，一次验证完整输入域；
8. 只对明确枚举的 interval/block 家族报告下界，不能外推成任意布尔电路全局下界。

为了控制内存，n=8 时无需通用大规模 SAT。连续区间只有 36 个；结构记录只保存 canonical
节点编号和摘要，packed truth table 对每个唯一节点只存一份，RSS 可以稳定限制在 1.2 GB
以内。

- 已确认 `U/V` 的叶编码为 `2/1`，普通 combine 为 `4/2`，Switch combine 为 `8/1`。
