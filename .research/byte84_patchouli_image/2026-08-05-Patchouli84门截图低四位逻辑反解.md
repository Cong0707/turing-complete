# Patchouli 84 门截图低四位逻辑反解

日期：2026-08-05

## 结论

公开截图中的低四位没有使用 `joint10`，也没有产生 `nC4@3`。图中可见的低位 carry
spine 与当前 85/6 权威结构的正相前端同构：

```text
T0@1 -> C1@2
          |
          +---- strict C2@2 ---- B23@3 ---- C4@4
```

低四位总账仍是 `42 gate`。因此公开成绩从 `85/6` 到 `84/6` 的一门节省不在低四位，
应当继续在 bits4:7 或最终 owner 中寻找。

## 一、bit0 与第一组 Switch

截图最上方 bit0 cluster 明确是：

```text
Q0 = NOR(A0,B0)                            1 gate @1
G0 = AND(A0,B0)                            1 gate @1
P0 = NOR(Q0,G0)                            1 gate @2
```

其下两只 Switch 使用同一条 `Cin` data rail，enable 分别来自 `A0/B0`：

```text
T0 = BUS(
  SW(enable=A0,data=Cin),
  SW(enable=B0,data=Cin)
)                                           4 gate @1, may-Z

C1 = OR(G0,T0)                              1 gate @2
```

两只 Switch 重叠时 data 都是 `Cin`，没有异值 driver。这个 topology 与 85/6 权威
DAG 的 node18/node21/node36 完全一致；它不是 joint10 的 `C1` 两 Switch owner。

`S0` 使用图中右侧标准三门 XOR phase：

```text
N0 = NOR(P0,Cin)                            1 gate @3
H0 = AND(P0,Cin)                            1 gate @3
S0 = NOR(N0,H0)                             1 gate @4
```

## 二、bit1 与 strict C2@2

bit1 左侧只有两只早期状态门：

```text
V1 = OR(A1,B1)                              1 gate @1
G1 = AND(A1,B1)                             1 gate @1
```

其右侧截图清楚显示三只纵向 Switch。三只 Switch 共用 `V1` data，enable 分别为
`T0/G0/G1`：

```text
C2 = BUS(
  SW(enable=T0,data=V1),
  SW(enable=G0,data=V1),
  SW(enable=G1,data=V1)
)                                           6 gate @2, may-Z
```

归一化布尔值为：

```text
C2 = G1 OR V1*C1
```

所有重叠 driver 的 data 都是同一个 active `V1`，所以它是合法 strict owner。最关键
的视觉结论是 `C2` 在第二层已经完成，不是 joint10 的双 Switch `slow C2@3`。

截图的 `S1` 四门尾可按接线直接读为：

```text
A1s = NOR(C1,V1)                            1 gate @3
B1s = NOR(A1s,C2)                           1 gate @4
D1s = AND(G1,C1)                            1 gate @3
S1  = OR(B1s,D1s)                           1 gate @5
```

逐 bit1 状态检查：

```text
K: B1s=C1, D1s=0
P: B1s=NOT C1, D1s=0
G: B1s=0, D1s=C1
```

所以严格等于 `P1 XOR C1`。

## 三、bits2:3 carry reason

bit2 与 bit3 都使用相同三门状态 cluster：

```text
Qi = NOR(Ai,Bi)                             1 gate @1
Gi = AND(Ai,Bi)                             1 gate @1
Pi = NOR(Qi,Gi)                             1 gate @2
```

截图中 bit2/bit3 之间有一只独立 NOR，输出同时进入两只 Switch 的共同 data 端：

```text
R23 = NOR(Q2,Q3)                            1 gate @2

B23 = BUS(
  SW(enable=C2,data=R23),
  SW(enable=G2,data=R23)
)                                           4 gate @3, may-Z
```

`C2/G2` 重叠时两支仍驱动相同的 `R23`，冲突为零。这个 owner 的归一化值为：

```text
B23 = R23 * (C2 OR G2)
```

随后截图中的 OR 把 `B23` 与 bit3 的 `G3` 合并：

```text
C4 = OR(G3,B23)                             1 gate @4
```

因此从低四位跨入中段的 rail 是完整正相 `C4@4`，不是 partial `nC4@3`。

## 四、S2/S3 paid phase

`S2` 是图中第三组 `NOR/AND/NOR`：

```text
N2 = NOR(C2,P2)                             1 gate @3
T2 = AND(C2,P2)                             1 gate @3
S2 = NOR(N2,T2)                             1 gate @4
```

`T2` 没有死亡。截图下一只 OR 将它与 `G2` 合并为真实 `C3`：

```text
C3 = OR(G2,T2)                              1 gate @4
```

紧接的 `NOR/AND/NOR` 生成：

```text
N3s = NOR(P3,C3)                            1 gate @5
T3s = AND(P3,C3)                            1 gate @5
S3  = NOR(N3s,T3s)                          1 gate @6
```

所以公开图的 S3 四门尾是 `C3 OR + 三门 XOR`。它与我方
`D3/E3/O3/S3` positive-phase 四门改写等成本、等 arrival，但视觉接线更直接。

低四位逐段成本因此可从图中完整闭合：


## 五、与 joint10 假设的排他对照

```text
特征                     joint10 假设             Patchouli 截图
bit0 carry reason         不保留 T0@1              明确保留双 Switch T0@1
C1 owner                  双 Switch joint owner     G0 OR T0
C2 owner                  双 Switch @3              三 Switch common-V1 @2
bits2:3 carry input       C1/raw 联合补偿            strict C2@2
跨入中段 rail             目标 nC4@3                 实际 C4@4
低四位门数                目标 41                    实际 42
```

因此 `20 + 21 + negative 43` 不是这张公开 84/6 图的架构。它仍可作为独立理论方向，
但不能再用该截图为它背书。
