# Patchouli 84/6 底部高尾逐线反解

日期：2026-08-05

## 结论

公开截图中的 bits6:7/C8/S7 高尾不是此前推导的 `19 gate / D6` 结构，而是与当前
实机验收 `85/6` 完全相同的：

```text
20 gate / D6
```

因此 Patchouli 从 `85 -> 84` 的唯一净减门不在高尾，必须位于截图更上方的
bits0:5、低位 carry reason 或 C6 producer 中。`Z7@4/J19@5` 仍是独立理论切口，
但不是这张公开 84 门图采用的解法。

## 一、逐元件识别

截图底部左侧两组 raw 输入首先生成：

```text
G6  = AND(a6,b6)                         1 gate @1
Q6  = NOR(a6,b6)                         1 gate @1
nP6 = OR(G6,Q6)                          1 gate @2

G7  = AND(a7,b7)                         1 gate @1
Q7  = NOR(a7,b7)                         1 gate @1
P7  = NOR(G7,Q7)                         1 gate @2
```

图中 `Q6/P7` 同时进入上下排列的 `NOR/AND`，其输出再各自进入两个 OR：

```text
T67 = AND(Q6,P7)                         1 gate @3
R67 = NOR(Q6,P7)                         1 gate @3
E7  = OR(T67,R67)                        1 gate @4
H7  = OR(T67,Q7)                         1 gate @4
```

两只 generate 另接一只 OR：

```text
K67 = OR(G6,G7)                          1 gate @2
```

从中段下来的竖直 rail 是完整 `C6@4`。它与 `nP6` 同时进入一只 OR 和一只 NAND，
两者再进入最终 NAND；这与当前 85 门高尾逐 pin 相同：

```text
A6 = OR(C6,nP6)                          1 gate @5
B6 = NAND(C6,nP6)                        1 gate @5
S6 = NAND(A6,B6)                         1 gate @6
```

`C6` 与 `K67` 进入底部 NOR：

```text
Z7 = NOR(C6,K67)                         1 gate @5
```

最终两只 Switch 的端口连接为：

```text
S7 = BUS(
  SW(enable=E7, data=A6),
  SW(enable=Z7, data=P7)
)                                        4 gate @6

C8 = NOR(Z7,H7)                          1 gate @6
```

截图右侧可直接看到：

```text
S6 -> 8 位 Maker 的倒数第二条高位线
两只 Switch 合流 -> S7
最底 NOR -> 独立 carry 输出
```

## 二、完整门数账本

```text
G6/Q6/nP6/G7/Q7/P7                        6
T67/R67/E7/H7/K67                         5
A6/B6/S6                                  3
Z7/C8                                     2
S7 two-Switch owner                       4
-------------------------------------------
total                                    20
```

这 20 门与权威 human85 DAG 的高尾逐项一致，没有出现：

```text
J19 = T67 OR Z7
S7  = BUS(SW(J19,P7),SW(R67,A6))
C8  = NOR(Q7,J19)
```

所以公开 84 门图没有通过 early `Z7@4` 省掉一门。

## 三、arrival 与 fanout

```text
G6/Q6/G7/Q7                               @1
nP6/P7/K67                                @2
T67/R67                                   @3
E7/H7/C6                                  @4
A6/B6/Z7                                  @5
S6/S7/C8                                  @6
```

决定性 fanout：

```text
C6   -> D5（截图上方）、A6、B6、Z7
Q6   -> nP6、T67、R67
P7   -> T67、R67、S7 第二 driver data
T67  -> E7、H7
A6   -> S6、S7 第一 driver data
Z7   -> S7 第二 driver enable、C8
```

`C6` 仍是四条输出相位共同摊销的快速标量；Patchouli 并未取消它。

## 四、三态 owner 审计

只枚举 18 个合法抽象状态：

```text
C6 in {0,1}
bit6 in {K,P,G}
bit7 in {K,P,G}
```

得到：

```text
S6/S7/C8 mismatch                    0
S7 BUS conflict                     0

driver E: active1 / active0 / Z      8 / 2 / 8
driver Z: active1 / active0 / Z      2 / 2 / 14

driver overlap                       2
overlap both-one                     1
overlap both-zero                    1
overlap disagreement                 0

resolved S7 active1 / active0 / Z    9 / 3 / 6
```

两只 Switch 的 data 都是普通门输出，不含 partial-Z data。重叠的两行分别同为主动 1、
同为主动 0，因此没有异值冲突，也没有依赖 `SW(enable=1,data=Z)` 的错误透明假设。

## 五、研究方向修正

公开图已经把解空间明确切开：

```text
Patchouli high tail                    20 / D6
human85 verified high tail             20 / D6
```

因此接下来反解截图时应把底部高尾冻结，直接寻找上方少掉的唯一付费实例，优先比较：

```text
bits0:1 的 C1/C2/S1 联合 owner
bits2:3 的 R23/C4/S2/S3
bits4:5 的 C6/S4/S5 producer
```

不应继续把公开 84 门成绩解释为 `Z7@4` 或 `J19@5` 命中。
