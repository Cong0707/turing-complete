# S5/S6/S7/C8：g17/o0/s7/x1 八个 XOR 槽完整 UNSAT

## 结论

在 `fixed 73 + high residual 29` 的 D5 paid-source 接口上，完整封闭了下面这个明确、有限的组成类：

```text
domain       = s34567c8_leaf
outputs      = S5,S6,S7,C8
rows         = 486
gate/delay   = 17/5
components   = 8
ordinary     = 0
Switch/XOR   = 7/1
XOR slot     = 0..7（全部八种位置）
solver       = cadical195
```

八个位置求解均正常退出并返回 strict `UNSAT`；没有 watchdog、没有 `UNKNOWN`、没有缺片。因此：

> 在权威物理 CNF 的 paid-source 接口上，不存在由恰好七只 `SWITCH` 与一只 `XOR`、共八个 topological components 构成，且成本 17、最大延迟 5，同时实现 `S5,S6,S7,C8` 的网络。

该结论只覆盖 `g17/o0/s7/x1` 固定 decomposition，不能外推成完整 g17、完整 cost-17 或完整 high-residual 下界。

## 为什么位置覆盖完整

成本按权威 worker 的 primitive 规则计算：

```text
components + switches + 2*xors
= 8 + 7 + 2*1
= 17
```

由于 ordinary 数为 0，八个 component slots 中必须恰有：

```text
1 × XOR
7 × SWITCH
```

唯一自由度就是 `XOR` 位于哪个 slot。枚举 `slot 0..7` 恰好得到八种、且 fixed-kind 向量互不相同：

```text
x0 = XOR,SWITCH,SWITCH,SWITCH,SWITCH,SWITCH,SWITCH,SWITCH
x1 = SWITCH,XOR,SWITCH,SWITCH,SWITCH,SWITCH,SWITCH,SWITCH
...
x7 = SWITCH,SWITCH,SWITCH,SWITCH,SWITCH,SWITCH,SWITCH,XOR
```

结构审计结果：

```text
position_patterns          = 8
unique_fixed_patterns      = 8
concrete_kind_assignments  = 8
invalid                    = 0
```

这里没有 ordinary wildcard，也没有 ordinary kind 子枚举需要补充。

## split-slot / shard 完整性

所有求解统一使用：

```text
split_slots = 1
shard_count = 1
shard_index = 0
```

对于 `components=8, switches=7, xors=1, ordinary=0`，worker 的合法单槽 suffix universe 恰为：

```json
[["XOR"],["SWITCH"]]
```

其 SHA256 为：

```text
920b0950e3ece8f8e5870ea85704dc5490e6ccf8ecdb95b44f584554ffe8bd66
```

`shard_count=1/shard_index=0` 分配整个 universe。每个模式的 slot 7 无论固定为 `XOR` 还是 `SWITCH` 都在该 universe 中，所以 shard 没有删除任何 XOR 位置模式。
