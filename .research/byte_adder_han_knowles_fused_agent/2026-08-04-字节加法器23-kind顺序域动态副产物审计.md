# 字节加法器 23-kind 顺序域动态副产物审计

日期：2026-08-04
状态：`COMPLETE`（仅对本文明确列出的有限 grammar 完备）

## 1. 结论

本轮把 Byte Adder 关卡中全部 23 种合法原语放到真实的 131072 拍顺序域中审计，并把 current-cycle、history、autonomous phase、Switch/BUS、Z normalizer、word lane、Maker/Splitter 和 FullAdder tuple 放进同一套可重放判定中。

结论分为三层：

1. **存在一个真实、可复用但尚不能删锥的正资产。** 基线中的四条 partial carry BUS `n45/n56/n62/n69` 的数据面分别严格等于 `C1/C3/C5/C7`。按语义角色使用 `Maker4(kind 112) -> Splitter4(kind 110)`，可以在 `0 gate / 0 delay` 下得到四条 active、无冲突、具有新 owner barrier 的 clone。
2. **本轮有限动态 grammar 内没有 score 改进替换。** history/phase 直接命中、一元/二元 graft、AND3/OR3 late-input、FullAdder joint tuple、两驱动 BUS、BUS 后 normalizer、word lane、connected-cut 和 ripple suffix 均没有产生优于 `80/7/560` 的非递归候选。
3. **这不是全局 UNSAT。** 四条 carry clone 仍依赖原 BUS；跨 carry 层联合重定时、非均匀共享 cut、更大动态 grammar、以及未实证的多 Delay feedback SCC 均未被证明不可能。timeout、工具崩溃、缺少 timing 证据一律记为 `UNKNOWN`。

### 2.2 live-Int 顺序

必须逐句按宽 `Int` 执行，三次移位/XOR 之间不能截成 17 位：

```python
x = cycle
x ^= x << 6
x ^= x >> 11
x ^= x << 9
return x & 0x1ffff
```

协议范围为 cycle `0..131071`，共 `131072` 拍。该序列是完整 `2^17` 排列，`x=0` 只发生在 cycle 0。主动态审计的 packed U24LE 序列 SHA-256 为：

```text

```

```text

```

两者编码宽度不同，不是证据冲突。错误地在每一步做 17 位 mask 会从 cycle 2048 开始偏离 live 序列，共偏离 129024 拍，不能用于本审计。

## 4. Delay Line、history 与 autonomous phase

### 4.1 kind 13 的已封口语义

```text
Q(0)      = init_data
Result(t) = Q(t)
Q(t+1)    = data_plane(Input(t))
```

默认 reset/init 为 0，`Result` 为 active driven；输入 Z 按数据面 0 存储。每只 Delay Line 成本 `5 gate`、组件延迟 `4`，**不是 timing cut**：

```text
arrival(Result) = arrival(Input logic) + 4
```

因此 D5 候选中，单只 Delay 前后的普通逻辑总共最多只能再贡献一个 delay unit。

### 4.2 current-node history

82 个 live current truth class 各延迟一拍，序列去重后仍为 82 条 history rail。基础审计对 D1 future target 得到：

```text
D1 future live targets                              82
current direct/NOT closure functions               162
current one-gate closure functions               17791
current BUS2 closure functions                    2331
direct / NOT / one-gate / BUS2 target matches        0
future final-output matches                          0
post-Delay one-gate live-node matches                0
minimum D1 future live-node ANF degree              11
D1..D20 affine input/output matches                  0
D1..D20 nine-output replay mismatches                0
```

D1 future 只在最后一个 source cycle 缺失一个 current assignment；该合法 don't-care 已在直接、NOT、一门和 BUS2 比较中一致处理。它不等同于 warm-up residual 的 cycle-0 don't-care。

### 4.3 autonomous phase

精确枚举 grammar：1 至 3 只全零初始化 Delay Line；每条 update rail 可为常量、状态 wire、NOT，或两个不同状态 rail 的一只 `AND/OR/NAND/NOR/XOR/XNOR`；update gate 总成本不超过 3；同时枚举状态 rail 与一门 decode；每台机器完整展开 131072 拍。

```text
unique full-sequence phases                         305
unique state-rail phases                             75
unique decoded phases                               230
direct live/output matches                            0
complement matches                                    0
undominated phase + current one-gate matches          0
NOT-feedback parity arbitrary-residual matches        0
phase BUS2 nonrecursive output matches                 0
```

一只 Delay 的 `q[t+1]=NOT(q[t])` 相位严格为 `q[t]=t mod 2`，成本/延迟为 `6/5`。两只或三只 Delay 的 feedback SCC 没有做 native timing 实证；凡依赖这类 timing 的点一律是 `UNKNOWN`，没有把组合展开深度冒充游戏计分。

## 5. warm-up residual 与 Pareto 证书

可用的最强 warm-up 相位是：

```text

q(0)=0
q(t)=1, t=1..131071
target = AND(q, residual)
```

所以 residual care cycles 恰为 `1..131071`，唯一 don't-care 是 cycle 0。该 don't-care 来自 outer AND 在 `q=0` 时对 residual 不敏感；测试终止没有引入 terminal don't-care。

## 6. Z、Switch/BUS 与 Maker/Splitter

### 6.1 数据面和 normalizer 规则

本审计区分 value data plane、driven/owner 与 conflict：

- 普通组件读取 Z 的数据面为 0，并产生 active 输出。
- Delay Line 把 Z 存成 0，下一拍输出 active 0。
- Maker/Splitter 可在 `0/0` 下把 Z lane/word 的数据面变成 active 0，并形成 owner barrier。
- conflict 不能被 normalizer 消除；它是非法/停止条件，必须传播或事先证明不存在。

## 10. 正结论、负结论和严格边界

### 10.1 已证明的正结论

- live xorshift 是完整 `2^17` 排列，cycle 0 是唯一零输入。
- 基线在全部 131072 拍上九输出 mismatch=0、public Z=0、conflict=0。
- kind 13 的状态、Z 存储和 `+4` arrival 规则已单独封口。
- warm-up residual 的唯一 DC 是 cycle 0 的 outer-gate cofactor DC，不是 terminal-test DC。
- `C1/C3/C5/C7` 四条 partial BUS 的数据面可经 Maker4/Splitter4 在 `0/0` 下联合生成 active owner clone，且 conflict=0。
- `all9 77/18/1386` 是 truth-correct 顺序候选，但不改善 score。

### 10.2 本轮有限 grammar 内的负结论

```text
history direct named-carry/output match              0

AND3/OR3 dynamic late-input matches                    0

dynamic FullAdder sideproduct target matches           0
nonrecursive phase-BUS physical/normalized matches     0/0
score-improving dynamic connected cuts                 0

```

### 10.3 不得外推的边界

- `COMPLETE` 只表示本文 grammar 的枚举和重放完成，不表示所有顺序网络、所有 BUS tuple 或所有重定时拓扑 UNSAT。
- 338 条一门命中和 566 条 Switch/BUS 命中是递归/被支配 clone，不能写成可替换候选。
- implication、care cofactor 和 partial data-plane equality 只是合成资产；只有非递归 exact truth、owner/conflict 合法、connected-cut 成立且全链 arrival 重算通过，才可进入 score 比较。
- 多 Delay feedback SCC timing 目前为 `UNKNOWN`。没有 native timing 证据时，不得把它标为 D5/D6，也不得写成 UNSAT。
- Espresso 默认运行的 assertion failure 是 `UNKNOWN`；`-Dso` 成功只证明对应 cover 和有限 ABC recipes 的结果。
- 本轮没有启动游戏，没有读取或修改正式存档、正式 candidate、metadata 或 history，也没有修改基线依赖。
