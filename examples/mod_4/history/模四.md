# 模四

## 2026-08-01 / 提交：功能：建立零门模四ASIC

### 灵感

最新版关卡每次给出 `0..255` 的整数，要求输出 `input % 4`。这里不需要执行旧 Overture
程序，也不需要任何处理器、拆分器或逻辑门。架构输入端直接设置为 2 位时，游戏只把输入的
最低两位送入电路：

```text
U2(input) = input & 0b11 = input % 4
```

把该 2 位数据线直接连接到 2 位架构输出即可同拍提交答案。

### 修改点

- 使用一个最新版 switched input、一个 switched output 和一个 ON；
- ON 同时开启输入和输出，2 位数据脚直接相连；
- 按当前 v15 的三格数据脚和偏移控制脚布线，不复用旧架构坐标；
- 独立候选目标为 `schematics/architecture/CODEX-MOD-4/circuit.data`，不覆盖正式存档。

### 验证

- 穷举 256 个输入，全部满足 `input & 3 == input % 4`；
- 3 个元件、3 条导线、5/5 引脚连接；
- 无多驱动、位宽冲突、悬空引脚或组合环；
- v15 编码后完整反解析一致；
- 目标为 `0 门 / 0 延迟 / 1 周期 / 0 能耗`，等于公开榜首和非负指标理论下界；
- 未启动游戏，最终关卡通过状态仍由用户在最新版中验收。
