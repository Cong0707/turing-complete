# 三位解码器

## 2026-07-31 / 提交：功能：扩展多输入验证并生成第二批候选

## 灵感

使用一个 `com_decoder_3` 同时处理三位选择和禁用信号。启用时输出一位有效码，禁用时
八位全部为 0，正好覆盖官方 16 个测试向量。

## 布局

- 三根选择线与八根输出线分别保持水平平行。
- Disable 从上方绕入独立控制脚，不与选择线建立公共端点。
- 新增并核对 `com_level_output_8` 的八个固定输入脚，位置为本体左侧 `y=-4..3`。

## 离线验证

- 穷举 3 位 Input 和 1 位 Disable，共 16 个向量。
- 24 个引脚全部连接，无多驱动、位宽冲突和组合环。
- 声明目标 `14 gate / 3 delay / 42 energy`。

## 2026-08-01 / 提交：修复：按实时精灵几何避让禁用线

### 问题

旧候选的 Disable 线从 `(-11, 1)` 斜接到解码器控制脚 `(0, -6)`。它经过
`select0` 引脚 `(-1, -5)`，在游戏内会把本应独立的 Disable 网络视为穿过选择端口。

### 修改点

- 保持 `com_decoder_3` 和所有选择/输出端点不变，成绩仍为 `14/3`。
- Disable 改走 `(-11, 1) -> (-2, -8) -> (0, -6)`，只在控制脚处接触解码器。

### 离线验证

- 穷举 16 组 `Input(3 bit) x Disable`，结果不变。
- v15 编解码往返、引脚连通性和组合环检查全部通过。
- 使用当前安装版组件精灵 alpha 掩码审计：零门体碰撞、零非端点引脚接触、零组件重叠。
