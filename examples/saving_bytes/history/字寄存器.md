# 字寄存器

## 2026-08-01 / 候选构建

### 思路

`Saving Bytes` 需要持续可读的 U8 状态，并仅在 Save 为 1 时写入新 Input。原生
`com_register_word`（kind `39`）提供 `load`、`save`、`in` 与三态 `out`；一个 On 元件
持续驱动 `load`，使输出始终非 Z。

### 修改点

- 在 `(0, 0)` 放置 U8 字寄存器，在 `(-8,-6)` 放置 On 输出使能。
- On 接 `load`，Save 接 `save`，Input 接 `in`，`out` 接 Output。
- 当前 immutable scaffold 的 Save 输出端为 `(-15,-3)`；不采用旧 baseline 中不同位置的
  嵌入式接口坐标。

### 离线验证

- 穷举所有 `memory(256) * Save(2) * Input(256) = 131072` 个状态转换。
- 每组都验证本拍输出等于旧 memory，且下一拍状态为 `Save ? Input : memory`。
- v15 编解码往返、引脚连通性、组件实体碰撞和引脚穿越审计均通过。

候选成绩头为 `73 gate / 5 delay / 365 energy`，仍待游戏内实际验收。
