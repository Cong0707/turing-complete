## 2026-08-01：共享异或网络的双模信号

### 结果

```text

```

该分数低于当前公开参考 `431/9/66 = 256014`。本轮只完成代数网络和成本证书，没有制作物理布局、没有启动游戏，也没有写入正式存档。

### 核心结构

每条进入共享 XOR 网络的叶子不再固定代表一个状态位，而是一个双模信号：

```text
tick0:  seed[i]
steady: q[j]
```

它由一只 OR 构成：

```text
seed[i] ---\
             OR ---- mode_pair(i,j)
q[j] -------/
```

成立条件来自当前游戏已经实测通过的 `381/11/66` 结构：

- tick0 时所有状态 Delay Bit 的初值为零，所以 `seed[i] OR 0 = seed[i]`；
- 后续 Level Input 被 `ready` 禁用，运行时数据值为零/高阻，所以 `0 OR q[j] = q[j]`。

同一个 XOR 门因此能在 tick0 与稳态传播不同的线性形式。完整结构为：

```text
47 个 mode-pair OR ─┐
状态直通信号 q-only ├─> 61-XOR、深度 2 的共享 DAG ─> B 节点 ─> 32 Delay Bit
                    │                              └> C 节点 ─> Level Output
                    └────────────────────────────────────────────────────────
```

tick0 的 `B` 输出节点被重新标记为 `T(seed)`；从 tick1 开始，相同节点变为 `B(q)`，可见输出节点为 `C(q)`。

### 线性关系

自然 RNG 变换为：

```text
A(x) = ((x ^ (x >> 13)) ^ ((x ^ (x >> 13)) << 17))
A(x) = A(x) ^ (A(x) >> 5)
```

选取编码：

```text
T = (I + R17)(I + R13)
q = T*x
C = A*T^-1
B = T*A*T^-1 = T*C
```

验证器逐行检查：

```text
C*T = A
T*C = B
T*T^-1 = I
```

于是时序为：

```text
tick0: q0 = T(seed), output disabled
tick1: output = C*q0 = A(seed), q1 = B*q0 = T*A(seed)
...
tick65: 输出第 65 个 RNG 值
```

### 为什么不再支付 34 个初始化 XOR

稳态 `B/C` 网络包含：

```text
27 个第一层 XOR
34 个第二层 XOR
总计 61 XOR
```

它的 27 个第一层节点可以在 tick0 获得另一组 seed 线性标签。反馈输出节点上的标签恰好组成 `T` 的 32 行。因此初始化编码不是另一张常驻网络，而是同一批物理 XOR 门的另一种输入模式。

脚本会逐门传播 `(tick0_form, steady_form)`，并检查全部 32 个反馈节点满足：

```text
tick0_form == T[row]
steady_form == B[row]
```

### 精确成本

| 元件 | 数量 | 单价 | gate |
|---|---:|---:|---:|
| Delay Bit | 32 | 5 | 160 |
| XOR | 61 | 3 | 183 |
| mode-pair OR | 47 | 1 | 47 |
| ready Delay Bit + NOT | 1 组 | 6 | 6 |
| **总计** | | | **396** |

Splitter、Maker、Level Input 和 Level Output 按当前计分模型为零门。

对于这张固定的 61-XOR DAG 和固定编码 `T`，可选 Z3 证明会同时选择：

- 每个第一层 XOR 的两个 seed 标签；
- 五个三项反馈输出的直通 seed 标签；
- 可扇出的 `(seed[i], q[j])` OR 配对。

精确最小值为 47 个不同配对。该最小值只针对当前固定 DAG，不是对所有可能 RNG 网络的全局最优证明。

### 精确延迟

最坏稳态路径为：

```text
Delay Bit output  4
mode-pair OR      1
XOR layer 1       2
XOR layer 2       2
-------------------
total             9
```

ready 控制路径为 `Delay Bit 4 + NOT 1 = 5`，不会超过数据路径。初始化路径没有前置状态延迟，也不会提高静态上界。

### 周期

```text
1 tick  编码并装载 seed
65 tick 输出 RNG 值
总计    66 cycles
```

验证器对固定边界值和 64 个确定性随机种子逐一检查 65 次输出及编码状态不变量。

### 实装前必须验证

- 当前 OR 对禁用 Level Input 的语义必须保持与已验收 `381/11/66` 相同。
- 47 个 OR 的输出需要按配对扇出，线路不能穿过元件、引脚或形成意外汇合。
- `B` 节点同时承担状态反馈，不能把仅供 `C` 输出的节点接入 Delay Bit。
- Level Output 在 tick0 必须由 ready 控制关闭。
- 游戏需要重新计算实际 `gate/delay/cycle`，不能只相信文件头声明。

只有以上各项通过后，才应生成候选电路并请求人工游戏验收。
