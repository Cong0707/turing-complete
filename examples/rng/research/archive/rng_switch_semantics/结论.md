# RNG Bit Switch 精确语义研究

## 结论

Turing Complete 2.1.281 的 Bit Switch（`kind 12 / com_switch_bit`）不是普通
`AND` 门，而是一个真正会退出驱动集合的三态缓冲器：

```text
enable = 0: output._is_z = true
enable = 1: output._is_z = false, output.value = input.value
```

当前版本未旋转时的引脚顺序和坐标是：

```text
enable: (0, +1)  U1 input
data:   (-1, 0)  U1 input
out:    (+2, 0)  U1 output_tristate
```

它的成本是 `2 gate / 1 delay`。这一点同时由游戏成本表和官方 `Bit Switch`
关卡基线交叉确认：基线含 `2 NOT + 2 Switch`，头部成绩恰为 `6 gate / 2 delay`。

## 多驱动解析

对同一网络上的所有驱动器，运行时先忽略 Z，再解析有效驱动：

| 有效驱动 | 电气结果 | 普通逻辑读取的数据面 |
| --- | --- | --- |
| 无，全部 Z | `_is_z=true` | `0` |
| 全部为 0 | `0, _is_z=false` | `0` |
| 全部为 1 | `1, _is_z=false` | `1` |
| 同时有 0 和 1 | 短路并停止本轮模拟 | 不存在合法结果 |

字总线遵循同一规则；Z 是整条输出的状态，不是逐位掩码。两个有效字驱动必须逐位
完全相同，否则任一差异位都会形成短路。二进制中的多驱动解析模板同时累计有效值的
OR 和 AND；二者不相等时写入两个冲突元件、引脚、顶层 ID、导线 ID 和数值，并调用
`halt()`。因此不能把冲突的 `0/1` 驱动当作 wired-OR。

“全部 Z 的数据面为 0”不等于 Z 消失。Architecture Output 会单独记录
`level_output._is_z`，输出历史也保存该字段；关卡协议可以据此拒绝未开启的输出。
普通门只消费数据面，产生的输出默认是主动驱动。特别需要注意：

- Splitter/Maker 不传播 Z，会把关闭的上游所呈现的数据 `0` 变成主动 `0`；
- Switch 的 Z 只由自己的 `enable` 决定，数据输入为 Z 时不会自动级联传播 Z；
- 同一三态源的扇出仍属于同一电气网，不会得到互相隔离的多个副本。

## 已验证构型

### 二输入 XOR / 选择器

官方 `examples/bit_switch/baseline/circuit.data` 的两个 Switch 输出接在同一网：

```text
y = BUS(
  Switch(enable=b,     data=NOT(a)),
  Switch(enable=NOT(b), data=a)
)
```

两个 enable 严格互斥，所以没有冲突，结果是 `a XOR b`。它也是一个带反相数据的
二选一选择器，成本 `6/2`。一般 mux 为：

```text
y = BUS(Switch(NOT(s), a), Switch(s, b))
```

成本 `5 gate / 2 delay`。在 RNG 中它的价值不是替代普通 mux，而是在共享反馈线上让
未选中的来源真正退出驱动集合。

### 三输入 XOR

SchematicHub entry 53 的 `XOR3` 使用四个 Switch 和四个一延迟控制门：

```text
y = BUS(
  Switch(NOR(a,b), c),
  Switch(NOR(a,c), b),
  Switch(NOR(b,c), a),
  Switch(AND(b,c), a)
)
```

它严格实现 `a XOR b XOR c`，成绩是 `12 gate / 2 delay`。部分偶校验输入会让所有
Switch 都关闭，利用数据面默认 0 得到正确结果。脚本在“原始输入/常量或一个一延迟门
作为 enable/data”的限定构型内穷举，得到 XOR3 的最小成本也是 `12/2`。这只是限定模型
的完整证明，不是任意 TC 电路的全局下界。

## 对 RNG 的直接意义

Switch 有两个切实可用的方向：

1. **相位注入。** `seed` 在装载拍直接驱动某网，`q` 通过 `Switch(ready,q)` 在稳态驱动
   同一网，可把控制路径从 `ready Delay 4 + NOT 1 + OR 1 + 2 XOR 2 = 10`
   缩成 `ready Delay 4 + Switch 1 + 2 XOR 2 = 9`。
2. **浅层奇偶。** `XOR3 12/2` 用额外门数把两个串联 XOR2 的 `4 delay` 压成
   `2 delay`，适合只替换真正位于所有关键环上的三输入奇偶节点。

但相位注入有硬约束：若 `seed_i` 直接接入两个不同的 `(seed_i,q_j)` 汇合网，这两个网
实际会被 seed 导线并成同一个网，稳态下不同 `q_j` 将短接。Splitter 不能隔离 Z。要复制
成独立相位网，必须给每个副本增加自己的三态输出，或者寻找源/目标一一匹配的状态编码。

现有固定 61-XOR 编码 DAG 在物理一一匹配约束下，即使相位预算放宽到 `150 gate` 仍为
UNSAT；所以不能把先前放宽模型的 `427/9/66` 直接落盘。另一方面，canonical 61-XOR
DAG 的“5 个 XOR3 + 少量 retiming”也已被严格模型否定，无法解释 `431/9/66`。

因此榜一所说的“Switch 很重要”更可能指向：

- 重新选择联合状态编码，使早期相位配对接近匹配；
- 把相位选择嵌入新的 XOR3/条件反馈节点，而不是固定 DAG 前统一加选择层；
- 允许若干独立 Switch 复制关键 seed/q 源，以门数换取 `delay 9`，但必须逐网证明互斥。

下一轮搜索不应再把 Switch 当布尔 AND，也不应允许免费 Z 复制。每个候选网络必须显式
记录全部三态驱动，并检查所有输入组合和所有拍次都满足“零个有效驱动或有效值完全一致”。
