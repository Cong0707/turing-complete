# 标准 61-XOR RNG 的同步重定时反证

## 结论

在以下明确模型内，`5` 个 XOR3 不可能把反馈组合周期压到 `6` 或 `5`：

- 组合核是标准三阶段 `61` 个 XOR2 DAG；
- XOR2 和 XOR3 延迟均为 `2`，稳态反馈 OR 延迟为 `1`；
- 一个 XOR3 只替换 DAG 中一条相邻 `XOR2 -> XOR2` 链；
- Delay Bit 只按同步 retiming 公式移动，允许扇出导致总寄存器数增加；
- 原始每个输出位经一个寄存器反馈到同编号状态位。

同步 retiming 对边 `u -> v` 的寄存器数为：

```text
w_r(u,v) = w(u,v) + r(v) - r(u)
```

因此任意有向环 `C` 上：

```text
sum_C w_r = sum_C w
```

全局增加 `2` 或 `4` 个 Delay Bit 可以来自扇出后的寄存器复制，但不能增加证书环上的
寄存器数，也就不能放宽这些环的周期下界。

## 环证书

证书使用两个单寄存器环和五个五寄存器环：

| 状态位环 | 寄存器 | 组合延迟 | 周期 6 至少 XOR3 | 周期 5 至少 XOR3 |
|---|---:|---:|---:|---:|
| `17` | 1 | 7 | 1 | 1 |
| `18` | 1 | 7 | 1 | 1 |
| `0 -> 12 -> 7 -> 19 -> 18` | 5 | 31 | 1 | 3 |
| `1 -> 13 -> 25 -> 24 -> 6` | 5 | 31 | 1 | 3 |
| `2 -> 14 -> 26 -> 8 -> 20` | 5 | 31 | 1 | 3 |
| `3 -> 15 -> 10 -> 22 -> 21` | 5 | 31 | 1 | 3 |
| `5 -> 17 -> 16 -> 11 -> 23` | 5 | 31 | 1 | 3 |

一个 XOR3 对指定物理路径最多减少 `2` 延迟。七个环上能够缩短路径的相邻链集合两两
不交，因此周期 `6` 至少需要 `7` 个 XOR3，周期 `5` 至少需要 `17` 个 XOR3。两者都
严格排除 `5` 个 XOR3。

环平均约束的完整 Z3 优化会把周期 `6` 的必要下界继续收紧到 `9`，但它仍不是充分的
retiming 条件。加入每一条条件边、整数 retiming 标号和零寄存器路径到达时间后，精确的
放宽 I/O 相位模型得到：

| 反馈组合周期 | 环平均模型 | 完整 retiming | 对应总 delay |
|---|---:|---:|---:|
| `P <= 6` | 至少 9 XOR3 | 至少 11 XOR3 | `4 + 6 = 10` |
| `P <= 5` | 至少 17 XOR3 | 至少 17 XOR3 | `4 + 5 = 9` |

这里 `4` 是本机实际 Delay Bit 延迟。完整模型故意不固定主输出的 retiming 相位，因而比
“每拍输出必须原样对齐”的要求更宽松；在宽松模型中已不可行的门数，在真实任务中同样
不可行。

这还是对目标有利的放宽：即使上游 XOR 被其它输出共享，证书仍允许一次替换获得完整
`2` 延迟收益。若还要求每次按 `2*XOR2 -> 1*XOR3` 删除上游门、只增加 `6 gate`，标准
DAG 中只有 `a17 -> b17`、`a18 -> b18` 两条单消费者链，连五次这种门数替换本身也不可行。

对任意仍存活的局部替换，child 从 XOR2 变为 XOR3 增加 `9 gate`；一次替换最多再删掉
它的直接 parent，节省 `3 gate`，所以每次净增至少 `6 gate`。任意保持全部 32 位种子状态
的逐拍实现至少需要 32 个状态寄存器。把这些对目标最有利的下界代入当前 `381` 成本口径：

```text
P <= 6: 183 + 11*6 + 32*5 + (32 OR + ready Delay + NOT) = 447 gate
P <= 5: 183 + 17*6 + 32*5 + (32 OR + ready Delay + NOT) = 483 gate
```

若强制题设的额外 `2` / `4` 个 Delay Bit，下界进一步成为 `457` / `503`。所以标准 DAG
的同步重定时既不能得到 `421/10`，也不能得到 `431/9`。

完整模型给出的具体可实现节点集合均保持每个 child 最多展开一个 parent，并逐位验证 GF(2)
输出仍等于标准 `xorshift32`。`P=6` 见证为 11 个 XOR3、59 个存活 XOR 节点、32 个重定时
状态寄存器，宽松 I/O 相位模型中已需 `474 gate`；`P=5` 对应 `17 / 59 / 32 / 528`。
前者成本分类为 8 次 parent 保留的 `+9`、1 次单扇出删除的 `+6`，以及两次共同删除共享
parent 的组成本 `+15`；后者是 13 次 `+9`，另有两组各两个 XOR3 共同删 parent，每组
`+15`。

## 边界

反证针对标准 DAG 的局部 XOR3 链替换和等价同步 retiming。若独立向反馈环串入新寄存器，
就违反环寄存器不变量，不再是原电路的 retiming；它会改变迭代相位，不能据此宣称仍逐拍
输出 `F(state)`。任意全新状态编码或不同 XOR 网表需要另建顺序等价模型，不在本证书范围内。
