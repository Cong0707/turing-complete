# 前导零计数器

## 2026-08-01 / 候选构建

### 思路

关卡输入和结果均为 U8，当前版本原生 `com_clz`（kind `49`）直接接受一个字并输出
前导零数量，不需要把字拆成八条位线再编码。

### 修改点

- 在 `(0, -4)` 放置一个 U8 CLZ 元件。
- Input 直连 CLZ 输入，CLZ 输出直连 Result。
- 离线模拟器补充了 `0 -> 8` 的 CLZ 边界语义，避免把全零字误判为零个前导零。

### 离线验证

- 穷举所有 `256` 个 U8 输入，逐项比较 `clz(input)`。
- 验证零值结果为 `8`，最高位为 `1` 的值结果为 `0`。
- v15 编解码往返、引脚连通性、组件实体碰撞和引脚穿越审计均通过。

候选成绩头为 `22 gate / 4 delay / 88 energy`，仍待游戏内实际验收。
