# 乘法器

## 2026-08-01 / 提交：待提交

### 目标

为 `multiply` 关卡构造当前 v15 格式的 U8 低字节乘法候选，并保持所有线路可在当前游戏中安全加载。

### 方案

使用当前游戏原生 `com_mul`（存档 kind `31`），只连接其 U8 输出到关卡的 `Result`。安装版 `Turing Complete.exe` 偏移 `0xA4CAC8` 的 Verilog 模块为 `TC_Mul (in0, in1, out)`，其主体是 `assign out = in0 * in1;`；结果按元件字宽截断，因此在 U8 下恰好实现 `(A * B) & 0xff`。

布局采用当前 v15 实存电路已使用的端口位置：`in0=(-1,-1)`、`in1=(-1,+1)`、`out=(+2,0)`。三条线均在读取安装版 `com_mul.png`、`com_level_input_word.png`、`com_level_output_word.png` 的 alpha 网格后审计，无元件重叠、无穿过元件、无穿过非端点引脚；导线交叉规则未被依赖。

### 指标

- 声明门数：`230`
- 声明延迟：`11`
- 能耗：`2530`
- 元件：3 个关卡不可变 I/O + 1 个 U8 `MUL`
- 导线：3

该指标与本轮公开榜单前沿 `230 / 11 / 2530` 对齐，但排行榜服务端与游戏加载时会重新计算成绩，最终是否并列或超越仍应由游戏实际验收。

### 离线验证

- `65536` 个 `(A, B)` U8 组合全部穷举。
- v15 `encode -> decode` 无损往返。
- 端点连通性：无悬空输入、多驱动、无驱动网络、位宽不匹配或无接收端网络。
- 当前精灵 alpha 几何：无元件重叠、导线穿元件、导线穿非端点引脚或非引脚端点。

### 下一步

本候选是已验证的低风险前沿基线。若要超过它，需要用门级截断 Wallace/Dadda 压缩树或经游戏验证的自定义复合单元，在不引入布局碰撞的前提下压低原生 `MUL` 的 `230 / 11`。
