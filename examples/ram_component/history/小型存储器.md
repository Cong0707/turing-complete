# 小型存储器

## 2026-08-01 / 提交：修复：重构小型存储器为基础元件实现

### 问题

旧候选直接放置 `com_ram`（kind `118`）。当前游戏的
`campaign/ram_component/meta.txt` 明确表示该组件由 **Little Box 自身**
解锁，因此它在本关的设计界面中不可用，载入后不能作为合法解法运行。

### 修改

- 删除原生 RAM 和 U2 地址合成器。
- 使用一个 `Decoder 2`、八个 `AND` 和四个 U8 `Register Word`：每个地址槽
  各有一条读使能 `Load & select` 和一条写使能 `Save & select`。
- 四个寄存器的数据输入共用 Value 总线；输出通过三态总线接到 Output。
- Address 的 `value0` 接 Decoder 的 `select0`，`value1` 接 `select1`，保留
  关卡脚本使用的 U2 小端位序。

### 版图

- 所有组件和导线保持在 `size = 16` 的 `[-16, 16]` 坐标范围内。
- 路由器从每个引脚的唯一水平方向进出走廊开始搜索，禁止穿过其它元件 alpha
  本体或非端点引脚。
- 导线之间可以相交，但组件、端口和汇接点均由独立几何审计检查。

### 离线验证

- `test.si` 前八拍的逐地址写入和读回均通过。
- 穷举 `4 * 256 * 256 * 2 * 2 = 1,048,576` 个局部状态转移；每组确认先读旧值、
  后按 Save 写入，且 `Load = 0` 时输出为 Z。
- v15 编解码往返、所有引脚网络精确分组、位宽、多驱动、组合环和当前 PNG
  精灵版图审计均通过。

### 计分

候选不伪造门数或延迟缓存，头部保留 `0 / 0`，由游戏实际载入、运行和通关后重算。
在游戏内通过前，不能将其登记为排行榜候选或覆盖正式存档。
