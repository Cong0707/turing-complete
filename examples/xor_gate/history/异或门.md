# 异或门

## 2026-08-01 / 提交：功能：重制三门异或门

### 灵感

本关完成前不能使用它自己解锁的 XOR 元件。将两个输入同时送入 AND 和 NOR，再对这两个
互斥结果取 NOR，可以得到：

```text
p = A AND B
q = A NOR B
Y = p NOR q = A XOR B
```

第一层 AND、NOR 并行，第二层只有最终 NOR，因此结构为三个基础门、两层延迟。

### 修改点

- 从当前 v15 基线提取两个 immutable 接口元件，保留它们的永久 ID 和实际位置。
- 不复制基线中的三个可变门，改用稳定永久 ID 重建 `AND + NOR + NOR`。
- 两个输入分别扇出到第一层 AND、NOR；两个第一层结果接入最终 NOR。
- 将 `xor_gate` 注册到 `build-known-candidates` 的确定性配方集合。

这里不能直接采用旧版 campaign 脚手架坐标：其 `Input` 位于 `(-13, 0)`，当前存档中同一个
immutable 元件实际位于 `(-8, -2)`。候选以当前 v15 基线为准，避免导线落到错误端点。

### 验证

- 穷举输入 `00,01,10,11`，输出为 `0,1,1,0`。
- 12 个引脚全部连接，无多驱动、悬空、位宽冲突或组合环。
- 单位逻辑深度为 2，v15 编解码往返一致，重复生成字节完全相同。
- 声明成绩为 `3 gate / 2 delay / 6 energy`，与当前基线和公开排行榜样本一致。
