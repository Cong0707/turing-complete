# 非门

## 2026-08-01 / 提交：功能：重制一门非门

### 灵感

本关只允许使用上一关解锁的 NAND。将同一个输入同时送到 NAND 的两个输入端即可得到：

```text
Y = NAND(A, A) = NOT(A)
```

该结构只含一个基础门，门数和逻辑层数都已经达到非恒定一输入反相函数的理论下界。

### 修改点

- 保留关卡脚手架中的固定 `Input`、`Output` 元件及永久 ID。
- 新建一个具有稳定永久 ID 的 NAND，不复制当前存档中可变元件的身份。
- 将 `Input` 扇出到 NAND 两个输入，并把 NAND 输出直连 `Output`。
- 将 `not_gate` 注册到 `build-known-candidates` 的确定性配方集合。

### 验证

- 穷举 `Input=0,1`，输出分别为 `1,0`。
- 5 个引脚全部连接，无多驱动、悬空、位宽冲突或组合环。
- v15 编解码往返一致，重复生成字节完全相同。
- 声明成绩为 `1 gate / 1 delay / 1 energy`，与当前基线、官方提示门数及公开排行榜样本一致。
