# 字节加法器

## 2026-08-01 / 候选构建

### 思路

当前版本的原生 U8 加法器同时提供 `carry_in`、8 位和输出与 `carry_out`，可以直接
覆盖旧的八级全加器链。候选保留关卡的三个输入和两个输出，只替换可编辑区域。

### 修改点

- 在 `(0, 0)` 放置一个 `com_add`（kind `30`，U8）。
- 分别接入 Carry in、A、B，并从原生元件输出接到 Output、Carry out。
- 所有线路只在端点触及元件引脚；导线之间的交叉不作为连接点。

### 离线验证

- 穷举 `A(256) * B(256) * Carry in(2) = 131072` 组输入。
- 每组均比较低 8 位和与第 9 位进位。
- v15 编解码往返、引脚连通性、组件实体碰撞和引脚穿越审计均通过。

候选成绩头为 `103 gate / 5 delay / 515 energy`，仍待游戏内实际验收。

- 对 Hub 79 每条 BUS 独立替换得到的“`131/4`”只是冻结输入到达时间的局部账本。

  击败 `515`。

  共审计 2177 个结构，最好为 `75/10/750`，没有低于 `515` 的候选。

## 2026-08-03 / 候选：折叠第六位进位得到八十二门

### 修改灵感

`84/7` 在 bits5:6 先单独生成 `C6`，再分别计算 `S6` 与二位组进位 `C7`。精确搜索
表明可以直接让 `S6` 消费 `C7` 及已有的 `G/Q/P` 相位，从而删掉独立的四门 `C6`
开关网络。新增的五门普通门重构只取回其中两门，局部块由 23 门降到 21 门：

```text
T  = AND(P5, P6)
D  = NOR(Q6, T)

C7 = BUS(Switch(T, C5), Switch(A, D))
S6 = NAND(OR(Q6, C7), NAND(OR(C5, G5), NOR(Q5, P6)))
```

## 2026-08-03 / 候选：共享第五位求和相位得到八十一门

### 修改灵感

`82/7` 的 `S5` 使用三门 XOR，而 `S6` 的五门重构没有利用 XOR 内部已经存在的
`P5 AND C5`。把 `S5` 改写为等价的三门相位形式后，可以免费暴露这个乘积项：

```text
T5 = AND(P5, C5)
S5 = NOR(NOR(P5, C5), T5)
```

随后对 `P5,C5,G5,P6,C7` 的局部完整真值表进行穷举，得到四门 `S6` 公式：

```text
S6 = AND(NAND(C7, P6), OR(T5, OR(G5, P6)))
```

它替换 `82/7` 中原有的五门 `S6` 重构，进位网络和所有其他位保持不变，因此整体
净省一门，并保持七延迟。

## 2026-08-03 / 候选：共享第五位和相位得到八十一门

### 修改灵感

继续检查 `bits5:6` 联合块时，发现 `S5` 的三门相位实现会自然产生中间项
`T5 = P5 AND C5`。旧版 `S6` 重构没有消费这个已经付费的相位，而是重新构造另一组
等价条件。把 `T5` 直接送入相邻高位，可把 `S6` 的五门重构压成四门：

```text
T5 = AND(P5, C5)
S5 = NOR(NOR(P5, C5), T5)

T  = AND(P5, P6)
D  = NOR(Q6, T)
A  = OR(G5, G6)
C7 = BUS(Switch(T, C5), Switch(A, D))

S6 = AND(NAND(C7, P6), OR(T5, OR(G5, P6)))
```

这不是修改计分数据，也没有使用 `com_add`；它是相邻 Sum/carry 相位融合的真实门级
重写。局部 `bits5:6` 从 21 门继续降到 20 门，完整加法器由 `82/7` 降为 `81/7`。
