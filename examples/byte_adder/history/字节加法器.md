# 字节加法器

## 2026-08-01 / 候选构建

### 思路

当前版本的原生 U8 加法器同时提供 `carry_in`、8 位和输出与 `carry_out`，可以直接
覆盖旧的八级全加器链。候选保留关卡的三个输入和两个输出，只替换可编辑区域。

### 修改点

- 在 `(0, 0)` 放置一个 `com_add`（kind `30`，U8）。
- 分别接入 Carry in、A、B，并从原生元件输出接到 Output、Carry out。
- 所有线路只在端点触及元件引脚；导线之间的交叉不作为连接点。

### 离线验证

- 穷举 `A(256) * B(256) * Carry in(2) = 131072` 组输入。
- 每组均比较低 8 位和与第 9 位进位。
- v15 编解码往返、引脚连通性、组件实体碰撞和引脚穿越审计均通过。

候选成绩头为 `103 gate / 5 delay / 515 energy`，仍待游戏内实际验收。

## 2026-08-04 / 提交：五延迟负相低位与尾部严格边界

### 七门 `S1/S2` 前端

快速负相前缀现在有一份真实普通门结构：

```text
v  = NOR(Q1, P2)
a  = AND(P2, nC3)
w  = NAND(nC1, P1)
x  = AND(v, w)
u  = OR(nC1, P1)
S1 = NAND(w, u)
S2 = OR(a, x)
```

七个节点全部按 `1 gate / 1 delay` 计费；没有把 XOR 当成一门，也没有使用 RAM 或原生
`com_add`。完整 bit0→A/V12→`nC3`→`S1/S2` 重放通过全部 `131072` 行：

```text
S0/S1/S2 arrival = [4,4,5]
mismatch          = 0
BUS conflict      = 0
final Z           = 0
```

由此得到严格的完整 D5 账本：

```text
fixed low outputs and paid high state = 73
S3..S7/C8 joint residual target       = 29
complete target                       = 102/5/510
```

### 新的限定下界

- 固定 fast-negative paid-source 接口下，`S5/S6<=7/D6` 的 30 种 ordinary/Switch/XOR
  成本分解全部严格 `UNSAT`；这不排除跨 `S3..S6/C5/C7` 的联合重写。
- 慢 C7 paid-source `S7/C8` 联合尾部的 exact-cost-11 方程恰有 16 种合法 kind 分解；
  13 种由完整 CNF、余下 3 种由互斥完备的 `slot0-kind` 分片全部严格 `UNSAT`。因此，
  在当前真实三态、BUS conflict、physical-net partition、deadline=6、dead-component
  精确模型内，tail11 已全局封闭；这不是全局字节加法器下界，也不自动推出所有
  `cost <= 11` 均 `UNSAT`。
- 单独 `S4@D5` 的总成本 `<=8` 全部 `UNSAT`，首次 SAT 是 `9 gate` 且使用两只 Switch，
  证明高位 29 门必须跨输出共享，不能逐位独立拼装。

## 2026-08-04 / 提交：D5 高位十八门单源末端族局部下界

### 目标与严格范围

沿用 `fixed 73 + high residual 29` 账本，并固定已有 `S3/S4` 十一门 witness 后，
`S5/S6/S7/C8` 的剩余预算恰为 18。本轮只封闭下面这个显式受限的结构族：

```text
2 ordinary + 8 Switch = 2 + 8*2 = 18
ordinary kinds = NOT / AND / OR / NAND / NOR
ordinary 全部位于 Switch 之前，第二个 ordinary 可以读取第一个
ordinary 与 Switch 的每个有效输入 BUS 都恰含一个源
每个目标输出恰由两个私有 Switch driver 组成
ordinary output arrival <= 4，Switch output arrival <= 5
```

ordinary dead-component 约束被放宽，因而枚举集合比要求所有组件 live 的同拓扑更大。
对重复 truth table 只保留最早 arrival；较晚的重复源在全单源端口模型中不增加功能，
所以这是功能等价类商，不是漏枚举。

### 枚举终态与计数修正

权威 `domain_s34567c8_leaf()` 共 486 行，含常量在内共有 29 个 paid source。正式枚举
得到 1008 个唯一首门 truth，并检查 1,041,696 个 ordered 两门函数池。四个目标各自的
双 Switch cover 计数均为 0。

临时版本的 `1,041,648` 计数使用了 truth 首次出现的 witness arrival，其中 18 个 truth
并非最早到达。按最小 arrival 纠正后新增 48 个网络；新增网络已全部检查，结论不变。

更强地，把末端单源 Switch driver 数量放宽为任意多个，所有合法 driver enable 的并集
仍不能覆盖完整 486 行：

```text
任意 driver 数可解源池：S5=0, S6=0, S7=0, C8=0
双 ordinary 最大覆盖行：S5=414, S6=426, S7=484, C8=485
```

快速 profile 与朴素 `(enable,data)` driver-pair/全集 enable 并集枚举交叉检查 1148 个
确定性样本，两类 mismatch 都为 0；结果 JSON 连续两次重放 SHA 完全相同。

### 不能外推的边界

该结论**只能**表述为“前置 ordinary + 全单源端口末端 Switch 族局部 UNSAT”。它不覆盖：

- ordinary 读取已经 resolved 的 Switch BUS；
- ordinary/Switch 交错多层结构；
- ordinary 或 Switch 输入为多源 BUS；
- ordinary 直接驱动最终输出或每输出非对称 driver 分配；
- XOR 或其他 ordinary/Switch 成本分解。

因此不能把本结果外推成完整 `o2/s8`、完整成本 18 或完整高位 29 门下界。下一步专门
搜索 ordinary 读取 resolved BUS 的交错族，以及依赖多源 BUS 解析的结构。
