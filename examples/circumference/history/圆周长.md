# 圆周长

## 2026-08-01 / 提交：功能：建立三十一门专用 ASIC

### 关卡契约

最新版 `campaign/circumference/test.si` 的完整判定只有：

```text
radius = random(41) + 1
output == radius * 6
```

因此输入严格为 `1..41`，共测试 41 个半径；输出范围为 `6..246`。本关不要求 ISA、程序、
寄存器、循环或通用处理器。现代方案直接实现固定乘六组合逻辑，`42..63` 可以作为高位输出
的不关心项。

### ASIC 决策

低位严格实现：

```text
6r = (r << 2) + (r << 1)
```

位 0 恒为 0，位 1 直接连接输入位 0。位 2 到位 5 对所有低位组合都必须精确；只有位 6、
位 7 利用 `r <= 41` 的范围约束化简。把精确低位与范围特化高位一起进行多输出技术映射后，
得到 25 个实际逻辑元件：

| 元件 | 数量 | 单元成本 |
| --- | ---: | ---: |
| NOT | 3 | `1/1` |
| AND | 7 | `1/1` |
| NAND | 6 | `1/1` |
| OR | 4 | `1/1` |
| NOR | 2 | `1/1` |
| XNOR | 3 | `3/2` |

总成本为 `22 + 3 * 3 = 31 gate`，关键路径为 `5 delay`，能耗为 `155`。这与当前公开榜的
`31/5/1/155` Pareto 点一致；更低延迟前沿为 `33/4/1/132`，后续继续针对多输出共享和并行
进位搜索，不回退到处理器优化。

### 离线验证

- 穷举 `1..41`，全部满足 `output = radius * 6`。
- 独立重算每个节点的 TC 成本与到达时间，得到 `31 gate / 5 delay`。
- v15 编码后完整反解析与原对象一致。
- 8 位拆分器的位 6 直接提供恒零输出；仅位 7 保持未连接，验证器精确白名单化该输出。
- 除上述无接收端的高位输出外，无悬空输入、无多驱动、无位宽冲突、无组合环。
