# 字节逻辑右移

## 2026-08-01 / 提交：功能：生成第三批候选并校正一位非门

## 灵感

通关后使用一个 8 位 LSR 直接处理 Input 与三位 Shift，替代基线的三级 MUX barrel shifter。

## 布局

- Input 和 Shift 分别沿上、下通道进入 LSR 的 `(-1,-1)`、`(-1,1)`。
- 结果从 `(2,0)` 水平直连固定输出。
- 三位 Shift 接入 8 位 shift 端口是当前关卡的零扩展用法，保留一个已知位宽差异。

## 离线验证

- 穷举 256 个字节与 8 个位移量，共 2048 组。
- 所有引脚连接，无多驱动和组合环；声明目标 `70/3/210`。
