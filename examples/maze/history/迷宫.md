# 迷宫

## 2026-08-01 / 提交：功能：重制迷宫榜首 ASIC

### 灵感

最新版关卡的 `test.si` 明确规定输入只有“前方是否为墙”，输出只有左转、前进、右转。
因此不再修复或优化 Overture、LEG 或任何通用处理器，而是直接综合控制机器人的最小状态机。

对 1、2、3 状态 Mealy 机穷举后，2 状态已经可以通过全部 8 张迷宫。其中与当前公开榜首
`6 门 / 5 延迟 / 373 周期` 完全一致的状态转移为：

| 当前状态 `q` | 前方 `wall` | 动作 | 下一状态 |
| ---: | ---: | --- | ---: |
| 0 | 0 | 前进 | 1 |
| 0 | 1 | 左转 | 0 |
| 1 | 0/1 | 右转 | 0 |

化简后只有两条等式：

```text
q_next = NOR(q, wall)
command = {q, q_next}
```

这等价于：遇到墙时持续左转；找到空路后前进一步；下一拍右转，重新优先贴左侧搜索。

### 修改点

- 新增独立的现代 v15 架构候选，不读取旧 Overture/LEG 电路实现。
- 使用一个 `NOR` 和一个位延迟线；位拼接器、常零、架构端口不增加门数。
- 补齐最新版架构切换输入、切换输出和位延迟线的真实引脚位置。
- 内置 8 张当前迷宫并逐张离线模拟，周期为
  `347, 161, 263, 207, 167, 373, 325, 123`。
- 生成目标为 `schematics/architecture/CODEX-MAZE/circuit.data`，当前阶段只写项目候选，
  不写正式存档。
