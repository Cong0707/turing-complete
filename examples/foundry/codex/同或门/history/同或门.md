# 同或门

## 2026-08-01 / 提交：功能：生成异或与同或Codex元件

### 结构

```text
p = A AND B
q = A NOR B
Out = p OR q
```

AND 与 NOR 并行，第二层 OR 合并，得到 `3 门 / 2 延迟 / 6 能耗`。该方案避免使用成本更高
的原生 XNOR 元件，并由现代逻辑物理布局器直接生成当前 v15 Foundry 电路。

### 验证

- `00 -> 1`、`01 -> 0`、`10 -> 0`、`11 -> 1`；
- 所有引脚连接，无多驱动、位宽冲突或组合环；
- 不依赖 `OVERTRUE`、`LEG`、完整 `Overture` 或 RV64；
- 只生成项目候选，未写正式存档，最终成绩由用户在游戏中验收。

## 2026-08-01 / 提交：修复：恢复现代自定义元件预览网格

本候选的 `design` 由全零改为当前 v15 工坊预览层：两个 Foundry 输入、一个输出和三个基础门
按内部坐标写入 `32x32` 网格。预览数据不参与同或逻辑，稳定 ID、接口、`3/2/6` 成本及四组
真值表结果均未改变。
