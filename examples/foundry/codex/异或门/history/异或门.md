# 异或门

## 2026-08-01 / 提交：功能：生成异或与同或Codex元件

### 结构

```text
p = A AND B
q = A NOR B
Out = p NOR q
```

三个单位门分成两层，得到 `3 门 / 2 延迟 / 6 能耗`。该结构由现代逻辑物理布局器从命名
布尔网络确定性生成，接口为当前 v15 三格 Foundry 输入输出。

### 验证

- `00 -> 0`、`01 -> 1`、`10 -> 1`、`11 -> 0`；
- 所有引脚连接，无多驱动、位宽冲突或组合环；
- 不依赖 `OVERTRUE`、`LEG`、完整 `Overture` 或 RV64；
- 只生成项目候选，未写正式存档，最终成绩由用户在游戏中验收。

## 2026-08-01 / 提交：修复：恢复现代自定义元件预览网格

按内部坐标写入 `32x32` 网格。预览数据不参与异或逻辑，稳定 ID、接口、`3/2/6` 成本及四组
真值表结果均未改变。
