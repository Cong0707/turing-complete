# 二位解码器

## 2026-07-31 / 提交：功能：扩展多输入验证并生成第二批候选

## 灵感

通关后可直接使用 `com_decoder_2`。低位连接 `select0`，高位连接 `select1`，四个输出按
顺序直连关卡输出，恰好得到 `1 << Input`。

## 布局

- 解码器放在输出四根引脚的同一水平带上，四条输出全为平行直线。
- 两根选择线在左侧分层收口，避免落到同一端点。

## 离线验证

- 完整验证 `00 -> 0001`、`01 -> 0010`、`10 -> 0100`、`11 -> 1000`。
- 12 个引脚全部连接，无组合环；声明目标 `4 gate / 2 delay / 8 energy`。
