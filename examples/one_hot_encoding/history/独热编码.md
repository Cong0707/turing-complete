# 独热编码

## 2026-08-01 / 提交：功能：生成第三批候选并校正一位非门

## 灵感

将常量 1 左移 Input 指定的位数，再用 8 位 Splitter 展开，正好得到 `1 << Input`。方案只含
Always On、8 位 LSL 和 Splitter 三个可放置元件，满足关卡元件数量限制。

## 布局

- 常量 1 接 LSL 数据输入，三位 Input 从下方接位移输入。
- LSL 输出接 Splitter，八条输出线水平平行连接关卡八路输出。
- 当前 LSL 引脚按 `in=(-1,-1)`、`shift=(-1,1)`、`out=(2,0)` 使用。

## 离线验证

- 穷举 Input `0..7`，输出依次为 `0x01..0x80`。
- 22 个引脚全部连接，无多驱动、位宽冲突和组合环。
- 声明目标 `70 gate / 3 delay / 210 energy`。
